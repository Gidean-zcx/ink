# games-2：记忆翻牌和贪吃蛇（照两个 MIT 开源小游戏的规则移植）

总规则先读 `docs/tasks/codex-rules.md`（第 9、10 节优先）和 `docs/tasks/vendor-common.md`（第 11、12 条）。

用户在功能清单里勾了“小游戏：五子棋（人机、双人）、贪吃蛇、记忆测试”。五子棋已由 `games-1` 移植合入（`system/apps/gomoku/`，看它的结构、能力和测试写法，照着做）。另外两个在 CrossPoint 一系的固定副本里没有，`games-1` 找到两个 MIT 项目，主会话已固定只读副本：

- `$INK_DEPS/../ink-hw/upstream/oss/memory-game`（taniarascia/memory，提交 4c991dd，MIT）：翻牌配对的规则（洗牌、两张一组、配对成功留下、失败翻回、计步和计时）；
- `$INK_DEPS/../ink-hw/upstream/oss/JavaScript-Snake`（patorjk/JavaScript-Snake，提交 3243086，MIT）：贪吃蛇的规则（移动、吃到变长、撞墙或撞自己结束、计分）。

它们是浏览器 JavaScript，没有 C 引擎可以拷：**照它们的规则和流程把游戏逻辑移植成 C**（逻辑部分逐条对应上游函数，`SOURCE.md` 写清每段对应上游哪一段、提交号、许可证），界面用 LVGL 和我们的主题令牌重做；上游的图片素材不拷，用我们现有的图标或简单图形。

## 要做的

1. **记忆翻牌**（`system/apps/memory/`）：4×4（可选 4×5）卡牌，图案用现有图标集；点开两张，配对留下、不配对稍停后翻回；计步、用时、最好成绩按家人存；墨水屏只刷翻动的那张牌（D-127）。
2. **贪吃蛇**（`system/apps/snake/`）：墨水屏适合的慢速版——每步 0.5 秒左右（可选“慢/中”两档），用快速刷新只刷变化的格子；方向用屏幕上的四个方向键和硬件翻页键；暂停、继续、重开；最高分按家人存。如果实测刷新跟不上，报告写清，保留慢速档即可。
3. **AI 接入**（人和 AI 共用，照五子棋的 `games.*` 能力族）：开始、状态（棋盘或蛇身、分数）、操作（翻哪张、往哪转）、重开；页面快照给可见状态。走现有孩子应用名单和时段规则。
4. 两个应用注册进应用列表（应用数量相关的测试断言照实更新）。

## 范围和预算

- 只改：新增 `system/apps/memory/`、`system/apps/snake/`、`CMakeLists.txt` 和固件 `ports/esp32s31/main/CMakeLists.txt` 里它们自己的几行、注册应用那一处、`tests/integration/apps.c` 和 `tests/integration/ai_surface.c` 里登记的几行、新增测试、`assets/i18n/en.tsv`（只加本任务新文案的英文）、生成的 `docs/system/capabilities.md`、`docs/tasks/games-2/`。不碰别的任务在改的文件。
- 两个游戏合计新增不超过 600 行（含逻辑）；不新增常驻任务（贪吃蛇的步进用现有定时机制，离开页面就停）。固件应用分区只剩约 8%，报告写增大多少，尽量小。

## 验收

1. 测试：记忆翻牌的配对、翻回、计步、通关和最好成绩；贪吃蛇的移动、吃食物变长、撞墙/撞自己结束、暂停继续、最高分；两个家人成绩不串；AI 调能力和页面一致；离开页面贪吃蛇停止；反向对照。
2. 主工程普通全量 ctest 过；S31 编译通过、无新警告。
3. 截图（两个游戏的开始、进行中、结束，常规和 120%，`docs/tasks/games-2/`，单张不超过 300 KB）。
