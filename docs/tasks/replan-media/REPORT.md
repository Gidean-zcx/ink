# 锁屏、桌面、声音与小游戏：候选排名

查阅日期：2026-11-12。基线：`d09b79195e2dc57908e33219216048e529e082c6`。

**结论：按模块择优有依据可行；现有证据不足以支持直接换成一套社区固件。** 新发现：Mogo、墨集都有自身源码；固件口袋的S3、Plus源码包均能展开；GB不应再因GPL排除retro-go；M4B有章节解析来源，但尚未核实一套适用于Plus的完整开源成品。

建议：锁屏以**Mogo**为主要底子；桌面/市场参考**墨集**，系统内应用/AI工具参考**BoBoOS和AgentUI**；曲库、歌词、续播取**kiikoread改版**，有声书体验追**ModernClassicOS**；GB先评估**retro-go/gnuboy**，Peanut-GB作性能备选。这些是调研建议，没有改变产品决定。[源码和原文出处](SOURCES.md)

排名依据为功能闭环、操作连贯性、恢复行为及已知限制，移植工作量仅用于打平。**排名均为【估算】，不是实机体验评分**；事实分别标【实现】和【文档】。源码可得性单列，不因闭源直接排最后，不按许可证筛掉候选，不默认原厂。未体验过的闭源项目，实际质量仍可能改变排序。

### 分项、底子与标杆

| 分项 | 优先顺序及理由 | 缺口 |
| --- | --- | --- |
| 时钟 | Mogo → CrossMux → ModernClassicOS；前两者可核更新逻辑，后者仅声明 | 没有整夜功耗、漂移和残影实测，不能凭画面预测续航 |
| 月历/老黄历 | Mogo → CrossMux → 小智畅享版；Mogo生成器实际调用lunar-javascript的宜忌、神煞等规则 | Mogo民俗规则不等于权威历书，其日历不自动跨日；CrossMux宜忌过于简化。[S01/S02](SOURCES.md#s01) |
| 待办 | Pixel作体验标杆，原厂作已核代码来源 | Pixel的Plus对等性、待办完成后的刷新未知 |
| 阅读组件 | Mogo → CrossInk；前者两个可配置首页插槽、最多五本迷你书库，后者擅长统计展示 | 都不能直接当作锁屏任意安装组件的机制；首页/锁屏须区分 |
| 句子锁屏 | PageRest作**主动选句**标杆，Mogo可复用书摘生成和票根显示 | 自动抽句不等于用户收藏句，二者分别验收 |
| 阅读小票 | Mogo → Pixel | PageRest本次只确认句子锁屏，不补认票根；无封面/书摘和跨成员行为待验证 |
| 壁纸 | Crosslink2透明PNG、原厂透明叠加列第一档；Mogo透明/封面票根背景列第二档 | **透明票根背景不等于透明PNG解码**。[S04](SOURCES.md#s04)、[W03](SOURCES.md#web) |

**推荐开源底子**：Mogo的票根/拼贴/时钟/日历；民俗表生成看其lunar-javascript链路；CrossMux取表盘/更新组织，CrossInk取统计组合。**闭源标杆**：PageRest主动选句、Pixel待办/阅读信息、Crosslink2透明PNG。原厂是具体实现来源，不能因此替代更好的内容体验。

| 3 | **固件口袋** | 【实现】扫描、安装、切换、保存返回、异常恢复及公开交接契约，Plus明确适配 | TF卡+固定应用槽，写镜像后重启；未核在线市场，不是多App同时运行。[S09](SOURCES.md#s09) |
| 4 | **AgentUI** | 【实现】外部应用SDK及radio/recorder示例，使用宿主音频/界面API，接近系统内应用 | P4目标，`.eapp`/ELF不能直接装S31。[S10](SOURCES.md#s10) |
| 5 | **Launcher / M5Launcher** | 【实现／文档】SD/Web/在线安装及管理生态广，是墨集的通用上游 | 墨集已补E-Ink4桌面/契约；通用Launcher不能代替这些设备体验。[S08](SOURCES.md#s08) |
| 6 | **原厂** | 【实现】主屏有分页、入口和不同布局，找内置功能有完整入口 | 所查是编译期应用表，不是第三方市场/运行时；多页不能证明可安装App。[S04](SOURCES.md#s04) |
| 7 | **lnkboot** | 【文档】多固件切换、卡刷入口 | 安装校验/返回/恢复细节未知，未取得源码；不代表实测比原厂慢。[W07](SOURCES.md#web) |

子场景：多固件容器为**墨集 → 口袋 → lnkboot**；系统内应用优先研究BoBoOS产品流程与AgentUI源码。BoBoOS第二是基于公开流程的暂定判断，不是实现已审计。

- **Launcher身份：`bmorcelli/Launcher`（M5Launcher代码线）。** 墨集README承认源自Launcher；本次固定Git树有**220个同路径同blob文件**，包括板级代码、接口及工具。墨集单个初始化提交发布，GitHub未标fork，故无法声称找到当年的精确fork点。不是Android或桌面电脑Launcher。[S07/S08](SOURCES.md#s07)
- **S07包内容查清**：固定提交90150a24中，S3 `firmware-pocket-1.0.7-s3.20-source.zip`：1,566,126字节/142项；Plus `firmware-pocket-plus-1.0.7-plus.16-source.zip`：2,018,663字节/203项。已读核心、镜像、交接、恢复、界面、分区和许可，**不是只有驱动的重链接包**。两包带字体/锁屏位图，只提取文本，未执行脚本；未见五子棋、录音机、森林里的朋友等应用源码。[S09](SOURCES.md#s09)
- **版本不对齐**：商城Plus名为v1.0.8-plus.15，备注又提plus.16；源码包是1.0.7-plus.16。README区分“指南修订1.1”和“FPOCKET ABI 1.0”，不能写成ABI 1.1，也不能视作已与线上二进制一一对应。

**推荐开源底子**：墨集的清单/校验/市场/分页；需要容器时再看口袋；AgentUI研究宿主API和退出清理。**闭源标杆**：BoBoOS浏览→详情→安装/更新→保留数据→AI工具可发现。缺口：S31实际加载/退出/回收、成员隔离、AI覆盖。本次未批准替换ink框架或改分区。
