# 用户试用反馈 4（2026-11-11 19:4x）：界面和交互（三个任务共用的背景）

用户原话：“键盘按钮大大小小的很奇怪   发短信还需要添加联系人也很奇怪  添加联系人还需要先进入打电话也很奇怪  各种交互都不符合业界的设计  功能和功能列表也是   然后键盘的语音按钮太大太难看了  短信也貌似没有成功发出 因为我另外一个手机也没有收到 计时器应该按秒吧  怎么会按分钟来显示相机低频好像也太低了  卡的不行  还有各种输入框 短信各种界面完全就不符合现代UI/UX 设计 大大小小的输入框  我要求每个功能和页面都参考现代UI的设计审计   我非常不满意   这些都要重新搞”。

共同的设计基准（三个任务都照这个）：

- **业界做法优先**：手机系统（iOS HIG、Material 3）和主流墨水屏阅读器（Kindle、文石 BOOX、掌阅 iReader 等）的通行做法。用户认得的流程和控件，不发明新的。
- **墨水屏的约束照样遵守**，但只改“怎么做”，不改“做什么”：没有动画、分页代替连续滚动、黑白高对比、尽量少刷新（D-127）、触控目标不小于约 9 mm。
- **一致**：同一种控件全系统只有一种规格（尺寸、内边距、字号、边框、圆角），出自 `system/ui/ink/ui_theme.h` 的令牌，不在页面里另写数字（`ui-scale` 检查会管）。放大字号时整体按同一比例放大（用户要求过“一起放大”）。
- **简单**：用户偏好乔布斯式的简洁，一件事的路径要短，常用操作一步到位。
- 能力表、AI 能调用的原子能力、成员隔离、确认卡规则（D-105：只在高风险时弹卡）不变；页面改了，AI 的页面快照和操作也要跟着对上。
