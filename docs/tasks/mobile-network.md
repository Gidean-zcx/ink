# mobile-network：接入点、流量统计、漫游开关

总规则先读 docs/tasks/codex-rules.md，第 7、8、9 节优先。报告写到 docs/tasks/mobile-network/REPORT.md。要等 sms-multipart-2 合入后再开始，两个任务都改通信服务和 NT26 模型。

## 背景

D-125 定了：手机网络要补接入点设置、流量统计和漫游开关。查过原厂代码：它不设接入点，用模组默认的；也不统计流量，没有漫游设置（`main/boards/common/board/uart_eth_modem.cc`）。所以这三样都是我们新加的。

## 要做的

预算：产品代码不超过 300 行。

1. **移动网络页**：设置 → 网络里加“移动网络”页，有三部分：
   - 接入点：“自动”（默认，用模组和运营商的默认值）或“手动”，手动时填名称、用户名、密码。密码框照现有规矩：内容不给 AI、不进日志、快照里只说“有”。
   - 漫游：开关，默认关。关的时候，在漫游网络上不用移动数据。注册状态从模组读（`+CEREG` 的漫游状态），模拟器能注入漫游状态。
   - 流量统计：本月用了多少、上个月用了多少，可以清零。按月从每月 1 日起算，用设备时区。数字来自 4G 网络接口的收发字节，不是估算，写清从哪里取。每天落盘一次，掉电最多丢当天的。
2. **能力**：`net.apn_set`、`net.roaming_set`、`net.usage`、`net.usage_reset`，按钮和 AI 共用。AI 读不到接入点密码。改接入点会让移动数据重连，按 D-105 判断要不要确认，写清楚。孩子不能改这三样。
3. 模拟器的 NT26 模型：支持设接入点（`AT+CGDCONT` 一类，依据写 3GPP 27.007 的条款号）、漫游注册状态、网络接口的字节计数（只模拟硬件行为）。
4. 中英文都要有。

## 验收

1. 测试要覆盖：
   - 手动接入点保存后，模型收到正确的命令；切回自动后恢复默认；快照、日志里都没有密码；
   - 漫游开关关闭时，注入漫游注册，移动数据停用；打开后恢复；
   - 流量：模拟收发若干字节，本月数字对；跨月以后上个月的数字对；重启后数字还在；清零后归零；
   - 孩子改不了。
2. 原有网络、通信、飞行模式的测试照原样通过；全量测试和内存检查通过；S31 能编过；gcccheck 通过。
3. “上机要核对的”：在真机上设接入点，就是写模组的配置（可能存进模组的非易失存储）。按项目规矩，**不经用户同意不在真机上设接入点**。上机只做只读查询，例如 `AT+CGDCONT?`、`AT+CEREG?`；流量字节从哪个接口读，也要上机确认。
4. 报告里给出中英文截图的路径。
