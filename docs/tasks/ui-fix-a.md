# ui-fix-a：结果说清楚——恢复、确认卡、传文件、恢复出厂四处页面照审计整改

总规则先读 `docs/tasks/codex-rules.md`（第 9、10 节优先）和 `docs/tasks/vendor-common.md` 第 11 条（只在明显冲突处改界面，用我们的主题令牌和统一组件）。

用户 2026-11-11：“我要求每个功能和页面都参考现代UI的设计审计 我非常不满意 这些都要重新搞”。审计结果在 `docs/tasks/ui-audit-2/`；本任务做其中 `TASKS.md` 的 **UX04、UX05、UX11、UX23** 四项（每项约一小时，文件互不重叠），照各行的“具体交付和验收”和对应问题编号（U01～U06、X01～X09、U07～U11、X10～X11，详见 `PAGES-SYSTEM.md`、`PAGES.md`、`COMPONENTS.md`）。

## 要做的

1. **UX04 恢复完成和预览**（`system/ui/shell/backup_pages.c`）：预览写清所选家人和替换范围；需要重启时主按钮就是“重启”，不再返回主页；状态只显示服务已确认的阶段；完成和部分失败各一张图。
2. **UX05 确认卡**（`system/ui/shell/confirm_card.c`）：展示服务已有的身份、对象、有效期；秘密掩码；确认按钮用具体动词（“发送”“删除”，不是“确定”）；长中文在 120% 字号下翻到末页才能确认；AI 仍不能代确认。不改确认策略和分类，不增加确认次数（D-105：卡片只给钱、密码、不可恢复删除、身份和发出未提及的家人资料）；服务没给的金额或时限不编。
3. **UX11 传文件状态**（`system/ui/shell/transfer_pages.c`）：“收到了／接收中／可打开”分清；USB 忙时按钮如实说明能不能自动停下；关闭和断开的底栏稳定；一次性码继续对 AI 隐藏。不改传输协议。
4. **UX23 恢复出厂的后果**（`system/ui/shell/factory_pages.c`）：明确会删什么、不动什么，默认不动 SD 卡，写清备份状态和退出路径；测试只用合成的隔离数据，不执行真正清空；保留本人验证。

## 范围和预算

- 只改上面四个文件、各自专用的测试（新增测试文件，或这几个页面已有的测试）和截图基线、`docs/tasks/ui-fix-a/`。不改共享主题、`navigation.c`、CMake 里别人的部分（新增测试的注册行可以加）、公共测试文件。

3. 报告逐项写对应的审计编号、改了什么、没改的低优先项。
