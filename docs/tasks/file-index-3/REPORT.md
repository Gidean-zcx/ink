- BG 扫描游标与既有服务计时器上的卡检测（1 秒）：任务书明确要求开机、插卡后台索引；不增加线程。

- `file.index_ready` 完成记录：任务书要求按卡标识和索引版本复用；沿用已有数据库和 `index_rec_t` 格式，按卡分别记录成员集合和索引版本，不增加文件格式。

- 索引批次遵守已有实时会话暂停、避开已有存储请求：防止日志折叠写 Flash 时持有文件编辑锁；复用同一 BG 节点和计时器，不另设队列或重试任务。
