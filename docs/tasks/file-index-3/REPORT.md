## 新增的机制

- BG 索引作业与既有服务计时器上的卡检测（1 秒）：任务书明确要求开机、插卡后台索引；不增加线程。
- 扫描期间的 PSRAM 临时查重表：任务书要求消除逐文件遍历；扫描结束即释放。
- `file.index_ready` 完成记录：任务书要求按卡标识和索引版本复用；沿用已有数据库和 `index_rec_t` 格式，记录成员集合，不增加文件格式。
- 后台与显式首屏扫描共享互斥标志：避免两种现有入口交叉写入相同路径；数据库落盘和查重准备在编辑锁外进行。
- 索引批次避开已有存储请求：防止日志折叠写 Flash 时持有文件编辑锁；复用同一 BG 节点和计时器，不另设队列或重试任务。
