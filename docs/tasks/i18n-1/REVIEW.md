# i18n-1 复核（主会话，2026-11-10）

结论：**合入。** 机制满足 R-069“以后加语言不改页面代码”：中文原文作键、一种语言一个 tsv、构建时检查占位符和缺字、查不到回落中文并计数，表在 flash 里不占内部 RAM。

## 看了什么

- `ink_tr()` 保留 gcc 的格式检查，译文表的占位符种类和顺序在构建时核对，9 种坏表都会失败。
- 切换语言走改字号的同一条重画路径；AI 请求带 `lang`，中枢和替身都按语言回答。
- 英文设置首页截图：行名短而整齐，没有截断；家人名字是用户数据，保持原样。
- 语言行放在“关于和更新”页：手机通常把语言放在“系统”里，这里“关于和更新”就是这个位置，而且不会把中文设置首页挤到第二页。主会话认可这个放法，告诉用户，用户要放别处再改。
