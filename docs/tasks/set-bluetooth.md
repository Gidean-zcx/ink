# set-bluetooth：蓝牙设置页

总规则先读 docs/tasks/codex-rules.md，第 7 节优先。报告写到 docs/tasks/set-bluetooth/REPORT.md。

## 背景

画板 `$INK_DESIGN/png/SetBluetooth.png`：蓝牙开关、耳机列表（名字、已连接或没连接、打勾）、“搜索耳机”按钮。现在设置里蓝牙那一行没有页面；phone-2 的报告也写了，耳机没连时通话页只能提示先连耳机。蓝牙服务已有扫描、配对、连接、忘记（`bt.*` 能力）。

## 要做的

预算：产品代码改动不超过 250 行（增删合计）。

1. **页面**：按画板。开关关掉蓝牙（服务没有开关的话补一个设置项：关掉时断开耳机、停止扫描）；列表显示已配对的耳机和连接状态，点一下连接或断开；能“忘记”一个耳机。“搜索耳机”进入搜索：列出搜到的设备，点一下配对并连接；配对失败、超时、没搜到各有状态。
2. **入口**：设置的蓝牙一行、通话页的耳机按钮（没连耳机时）、声音页的“蓝牙耳机”一行都能进这个页面。
3. 按钮和 AI 走同一组能力，页面有 AI 快照（G2）；孩子成员能不能改，按已有规则，写进报告。
4. “当音箱用”“翻页器”用户还没定，这次不做，已有接口不要删。

## 边界

- 用模拟器已有的耳机模型（脚本 `headset add|on|off|in|out`），不改它的硬件行为。
- 同时在做的有 ime-lexicon、index-cost，稍后还有 batch7 审计的修复；navigation.c 等共用文件只加最少的行。

## 验收

1. 测试：开关、搜索、配对成功和失败、连接和断开、忘记，以及从通话页、声音页进入。
2. 截图，与画板对照的分数照报（界面统一放大 1.2 倍造成的差异不算问题，写明即可）。
3. 全量测试和内存检查通过。
