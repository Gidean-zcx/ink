# reader-continue 复核（主会话，2026-11-10）

结论：**合入。** 只改了阅读器一个文件，卡片、主屏继续、AI 三条路收成一个能力，测试覆盖重启、两位家人、删书和拔卡。

## 看了什么

- `reader.last` 跟着原有的位置保存定时器写（不是每翻一页写一次），一次多一个很小的原子写；书名和页码放在一起，卡片不用再读每本书的位置文件。
- 换家人后的读取：先预读进缓存，300 毫秒后在界面任务上读。预读没完成时这次读仍会同步等，属于取舍；应用框架不给应用后台执行器，这是现有边界下最小的做法。以后框架有应用能用的异步读，再换掉这个定时器。
- 卡片每次被要时会查一次书在不在卡上（卡上的一次文件大小查询），开销小。
- 原来卡片动作缺书名、点进去参数不合法，这次顺带修好，对。
