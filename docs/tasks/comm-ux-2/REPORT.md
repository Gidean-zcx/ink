短信：会话列表显示名字或号码、最后一条摘要、时间和未读点，右上角新建。新建页顶部直接输入收件人，下面提示一个匹配联系人，`+` 打开完整联系人选择；底部正文、展开长文、发送共用一排。会话用左右对齐的气泡和分页，底部直接回复；发送中有状态，成功进入会话，明确未发出可点按重新编辑和发送，结果未知保留核实提示。打开会话经既有 `notify.read` 标记已读。

联系人：独立 `contacts` 应用，位于应用列表首屏“记和联系”组。列表按姓名的 UTF-8 字典序排序，姓名或号码子串搜索；详情提供打电话、发短信、编辑；新建和编辑都有姓名、号码、备注。沿用 `phone.contacts` 集合和原 `contacts.*` 能力，备注为旧 JSON 记录上的可选字段。

电话：拨号、最近、联系人三个分段入口；保留 `INK_DIGIT` 大拨号键，拨号键左边显示匹配联系人，可点入详情；通话中和来电沿用原有布局与接听、拒接、挂断等能力。

步数按任务书的操作环节口径：陌生号码短信“新建 → 输入号码 → 正文并发送”共 3 步；新建联系人从应用列表到表单 2 次点按。从联系人列表看详情 1 步、进入编辑 2 步、发短信或打电话 2 步；电话页切最近或联系人各 1 步，输入号码后拨号共 2 个环节。字符输入及键盘完成包含在各输入环节。
