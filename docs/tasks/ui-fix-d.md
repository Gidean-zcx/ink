# ui-fix-d：网络列表、首次设置、备忘三处页面照审计整改

总规则先读 `docs/tasks/codex-rules.md`（第 9、10 节优先）和 `docs/tasks/vendor-common.md` 第 11 条（只在明显冲突处改界面，用我们的主题令牌和统一组件）。

用户 2026-11-11：“我要求每个功能和页面都参考现代UI的设计审计 我非常不满意 这些都要重新搞”。审计在 `docs/tasks/ui-audit-2/`；本任务做 `TASKS.md` 的 **UX01、UX03、UX21**（它们等的输入框任务 `textfield-1` 已合入，先读合并后的代码，已经修好的行跳过），照各行的“具体交付和验收”和问题编号（T07～T11、S02、H01；N03、N09；O01～O12，详见 `PAGES.md`、`PAGES-SYSTEM.md`、`PAGES-APPS.md`、`COMPONENTS.md`）。

## 要做的

1. **UX01 网络列表**（`system/ui/shell/navigation.c`）：扫描结果和失败重试在同一页呈现，大字号下扫描按钮不被挤掉；照 iOS/Android 的 Wi-Fi 列表：已连接的在最上、信号强度图标、加密的有锁标记、点一个就连（要密码时弹出密码框）。另外修 `textfield-1` 留下的问题：Wi-Fi 密码输入条浮在键盘上方时盖住了半行“上网方式”标题（见 `docs/tasks/textfield-1/screenshots/after-100/WifiPassword.png`），浮起的输入条要有完整的白底和清楚的上边界，或让页面内容让出位置。儿童可见的图标紧凑排布。
2. **UX03 备忘保存**（`system/apps/memo/memo.c`）：草稿和备忘的保存说法统一，失败画面不再一边说没存上一边笼统成功；详情底栏留间距；故障后文字保留。另外：切换键盘布局（全键盘、九宫格、数字）时页面要按新的键盘高度重新排版，不能保持上一次的挤压状态（见 `docs/tasks/ime-reuse-1/` 的九宫格截图）。
3. **UX21 首次设置**（`system/ui/shell/boot_flow.c`）：没有备份可以直接用、连接错误按真实原因说、电脑加入码只在展开时显示、每页主次按钮明确（一个主按钮）。“直接进示例”是没采纳的建议，不做。
