# ui-fix-e：家人和孩子规则、AI 对话记录、文件和选取器三处页面照审计整改

总规则先读 `docs/tasks/codex-rules.md`（第 9、10 节优先）和 `docs/tasks/vendor-common.md` 第 11 条（只在明显冲突处改界面，用我们的主题令牌和统一组件）。

用户 2026-11-11：“我要求每个功能和页面都参考现代UI的设计审计 我非常不满意 这些都要重新搞”。审计在 `docs/tasks/ui-audit-2/`；本任务做 `TASKS.md` 的 **UX09、UX15、UX18**（它们等的输入框任务 `textfield-1` 已合入，先读合并后的代码，已经修好的行跳过），照各行的“具体交付和验收”和问题编号（T32、T35～T39；A11～A13；F01～F10，详见 `PAGES.md`、`PAGES-SYSTEM.md`、`PAGES-APPS.md`、`COMPONENTS.md`）。

## 要做的

1. **UX09 家人和孩子规则**（`system/ui/shell/settings_family.c`）：当前选中的是哪位家人明确；删除按钮写清只删活动记录；时段的开始和结束在同一块连续编辑；开关语义和“电话、短信、联系人不限时”的例外写清楚（联系人已是独立应用，`comm-ux-2` 已把它加入例外）。不实现后台记忆或日志服务，不改存储格式。
2. **UX15 AI 对话记录**（`system/ui/shell/ai_chat.c`）：空的时候“清空”禁用；历史里的问题和来源能分辨；底部的语音和文字入口一致（照 `ime-reuse-1` 合入后的键盘：语音键在候选条右侧）。不改问题输入组件的尺寸，不加会话搜索或新数据格式。
3. **UX18 文件和选取器**（`system/apps/files/files.c`、`system/ui/file_picker.c`）：多选有勾和数量、操作写明对象名、空和出错分开说、选图片时能认出是哪张（用现有缩略图接口）；照 iOS“文件”和 Android 文件管理器的列表做法。不加文件缓存、新格式或批处理机制。

## 范围和预算

- 只改上面四个文件、各自专用的测试（新增测试文件或这几个页面已有的测试）和截图基线、`assets/i18n/en.tsv`（只加本任务新文案的英文）、`docs/tasks/ui-fix-e/`。不改共享主题、`textfield.c`、`keyboard.c`、公共测试文件；别的任务在改的文件不碰（传书在改 `transfer`，阅读设置在改 `apps/reader`，`ui-fix-d` 在改 `navigation.c`、`memo.c`、`boot_flow.c`）。
- 产品代码合计不超过 300 行；不新增机制、状态机、文件格式。

## 验收

1. 每项附常规和 120% 字号的前后截图（`docs/tasks/ui-fix-e/`，单张不超过 300 KB）；每项有针对性测试和撤掉修复会失败的反向对照。
2. 主工程普通全量 ctest 过（含 `ui-scale`）。
3. 报告逐项写对应的审计编号、改了什么、没改的低优先项。
