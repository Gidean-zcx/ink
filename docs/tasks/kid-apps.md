# kid-apps：孩子的应用名单和禁用时段

总规则先读 docs/tasks/codex-rules.md，第 7、8 节优先。报告写到 docs/tasks/kid-apps/REPORT.md。

用户 2026-11-10 定（D-126）：做“孩子的应用名单和禁用时段”——家长指定孩子能用哪些应用、几点到几点不能用。已有基础：kid-1～kid-3（孩子主页、用时策略“每天能用多久”、SetKid 页），见各自的 REPORT.md。

## 要做的

预算：产品代码不超过 300 行。

1. **应用名单**：每个孩子一份“能用的应用”名单（默认：系统认为适合孩子的那些，和现在孩子主页上看到的一致）。名单外的应用在孩子主页和“全部”页都不出现，AI 和按钮都打不开（回执说明“家长没有打开这个应用”）。系统必需的（电话里的紧急呼叫、设置里孩子能用的部分）不受名单影响。
2. **禁用时段**：每个孩子可以设几段禁用时段（例如睡觉 21:00–07:00、上课 08:00–16:00，可按星期几选），时段内孩子只能用名单里标为“禁用时段也能用”的少数应用（例如电话、闹钟），其余显示规范里的“时间到了”页（kid 已有 KidTimeUp 页可复用）；跨午夜的时段要对。和“每天能用多久”同时生效，取更严的。
3. **设置**：SetKid 里两项（应用名单、禁用时段），只有大人能改；页面照规范和现有组件（没有画板，D-117）。孩子自己和孩子的 AI 都改不了。
4. 按钮和 AI 走同一套能力，能力表重新生成；新字符串用 `TR()` 并补英文。

## 验收

1. 测试：家长把某应用移出名单后，孩子主页、“全部”页看不到，AI 打开被拒并说明；禁用时段内只有标为可用的应用能开，其余显示时间到了；跨午夜时段；按星期几；和“每天能用多久”叠加取更严；孩子改不了设置；重启后名单和时段还在。
2. 原有 kid-1～kid-3、成员、主页测试原样通过；全量测试和内存检查通过；S31 能编过。
3. 报告列出 SetKid 两个新页面的截图路径。
