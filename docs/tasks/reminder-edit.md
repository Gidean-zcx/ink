# reminder-edit：手动添加、修改、删除提醒

总规则先读 docs/tasks/codex-rules.md，第 7、8 节优先。报告写到 docs/tasks/reminder-edit/REPORT.md。

`docs/tasks/settings-gaps/INVENTORY.md`：`reminder.add` 只有 AI 语音入口，`reminder.cancel` 没有入口，Upcoming（日历和提醒）的事项行只读不可点。用户 2026-11-10 定：没有画板的页面照规范自己设计（D-117）。

## 要做的

预算：产品代码不超过 300 行。

1. **添加**：Upcoming 里“加一件”：输入内容（短输入框，键盘托管）、选日期和时间（用规范第 1 节已有的组件做选择，不新造控件；同时在做的 time-settings 也会做日期时间选择，各自做、合并时由主会话统一，报告里写清你的选择控件在哪个文件），可选“重复”（不重复、每天、每周、工作日）。
2. **查看、修改、删除**：点事项进详情，能改内容、时间、重复，能删除（删除照现有的确认规则）；改了以后闹钟和日历按新时间。
3. 走现有的 `reminder.*` 能力（缺“修改”就补一个），按钮和 AI 共用；快照里有事项的内容、时间和可做的动作；能力表重新生成；新字符串用 `TR()` 并补英文。
4. 按成员隔离照旧；孩子能给自己加提醒、不能改大人的。

## 验收

1. 测试：手动加一个明天 8:00 的提醒，到点响；改成 9:00，8:00 不响、9:00 响；改成每天重复；删除后不再响；AI 加的提醒也能在这里改和删；换成员看不到别人的；重启后都在。
2. 原有日历、闹钟、时间服务、upcoming 相关测试原样通过；全量测试和内存检查通过；S31 能编过。
3. 报告列出“加一件”、详情、修改的截图路径。
