# ui-fix-b：设置一组页面照审计整改——通用设置、时间、密码和成员门、蓝牙列表

总规则先读 `docs/tasks/codex-rules.md`（第 9、10 节优先）和 `docs/tasks/vendor-common.md` 第 11 条（只在明显冲突处改界面，用我们的主题令牌和统一组件）。

用户 2026-11-11：“我要求每个功能和页面都参考现代UI的设计审计 我非常不满意 这些都要重新搞”。审计结果在 `docs/tasks/ui-audit-2/`；本任务做其中 `TASKS.md` 的 **UX08、UX10、UX16、UX24** 四项（文件互不重叠），照各行的“具体交付和验收”和对应问题编号（T16～T25、T26～T29、S19～S26、T14～T15，详见 `PAGES.md`、`PAGES-SYSTEM.md`、`COMPONENTS.md`）。照 iOS 设置和 Android 设置的列表做法：分组、当前值在右侧、开关和单选勾统一。

## 要做的

1. **UX08 通用设置控件**（`system/ui/shell/settings_pages.c`）：不支持的功能控件明确禁用并写原因；语言、唤醒名、自动备份的当前值能看出来；存储读失败有出口；120% 字号不截掉关键动作。先做这三个直接影响使用的问题，其余低项留后。
2. **UX10 时间设置**（`system/ui/shell/time_settings.c`）：当前值用单选勾，禁用写原因，标题短；现有输入组件支持数字时可以直接输年月日时分，保留加减微调。不改 `theme.c` 的公共日期选择器。
3. **UX16 密码和成员门**（`system/ui/shell/member_gate.c`、`member_pages.c`、`pinpad.c`）：当前在验证谁、4～8 位提示清楚，数字键位和确认键位置统一（照手机锁屏数字键盘：3×4、确认在右下或自动提交，选一种说明）；忘记密码如实说明怎么处理；三次错误等待、AI 不能碰秘密字段照旧。不实现找回机制，不改权限和冷却算法。
4. **UX24 蓝牙设备列表**（`system/ui/shell/bluetooth_page.c`）：发现、已配对、连接中分组；“忘掉”能找到；空态能手动扫描。只改列表呈现，不改蓝牙驱动（`port-bt-audio-2` 在改驱动）。

## 范围和预算

- 只改上面列的文件、各自专用的测试和截图基线、`docs/tasks/ui-fix-b/`。不改共享主题、`navigation.c`、`textfield.c`（`textfield-1` 在改）、`keyboard.c`（`ime-reuse-1` 在改）、公共测试文件。
- 产品代码合计不超过 280 行；不新增机制、状态机、文件格式。

1. 每项附常规和 120% 字号的前后截图（`docs/tasks/ui-fix-b/`，单张不超过 300 KB）；每项有针对性测试和撤掉修复会失败的反向对照。
2. 主工程普通全量 ctest 过（含 `ui-scale`）。
3. 报告逐项写对应的审计编号、改了什么、没改的低优先项。
