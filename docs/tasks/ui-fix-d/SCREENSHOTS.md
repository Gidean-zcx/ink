# 截图索引

【实测】无窗口模拟器，684×1216；前图仅替换对应页面为给定基线的源码，其余依赖一致。网络使用合成扫描回执，备忘只在测试中拒绝入库写入，首次设置使用合成服务回执；所有名称、地址和码均为假数据。

100% 和 120% 指成人字号；儿童按系统规则固定 110%。数字输入图表示“从数字输入会话进入备忘”，全键／九键使用真实键盘能力切换，不表示备忘新增了数字输入类型。单图均不超过 300 KB。
