# reader-continue：回到主页后“继续读”不消失

通用规矩：`ink-codex/briefs/subagent-rules.md`（仓库外，和仓库同级的工作目录）。

用户 2026-11-10 定：修。

## 现象

kid-3 报告记下的：阅读器回到主页就释放阅读状态，今日屏的“继续读”卡片随之消失（`apps/reader/reader.c`）。boot-flow 报告也记了“回到上次阅读位置没做”。

## 要做的

预算：产品代码改动不超过 150 行。

1. 每位家人各自记住最后在读的书和位置：落盘，断电重启后还在，换成员不串。回到主页、重启后，今日屏的“继续读”卡片仍在，显示书名和进度。
2. 点卡片（或 AI 调对应的能力）直接打开那本书，回到那一页和位置。书被删或卡被拔出时，卡片给出规范里的空状态或不显示，不崩溃。
3. 阅读器回主页时释放排版缓存的做法保留，只是“读到哪”不能跟着丢。

## 验收

1. 测试：读到第 N 页回主页，卡片在、进度对；点卡片回到第 N 页；重启后同上；两位家人各读各的不串；删掉那本书后卡片的表现；AI 快照里有这张卡片和能调的动作。
2. 原有阅读器、kid-3、今日屏相关测试原样通过；全量测试和内存检查通过；S31 能编过。
