# calendar-events：日历的独立日程（G8）

总规则先读 docs/tasks/codex-rules.md，第 7、8、9 节优先。报告写到 docs/tasks/calendar-events/REPORT.md。**只编译、跑宿主机测试，不碰设备。**

## 背景

最后一次缺口检查（`docs/tasks/phone-gap-3/REPORT.md` 的 G8）：月历（`system/apps/calendar/calendar.c`）和时间服务（`system/services/time/time_caps.c`）只管闹钟和提醒，没有不响铃的日程。用户 2026-11-11：“都并行做吧，你自己按最合理的、工作量较小的方式来补齐这些”。

## 要做的（取最小做法：日程就是不响铃的提醒）

1. 提醒加两项：要不要响铃（默认响，和现在一样）、可选的结束时间或全天。不响铃的就是日程，用同一套存储、同一个编辑页（编辑页加“响铃提醒”开关和结束时间），不另造一套。
2. 月历上日程和提醒都显示，样子能分开；点开一天能看到当天的日程和提醒。
3. 能力：现有的提醒增改删加上这两个参数；加一个按日期范围列出日程和提醒的能力，AI 可调。按成员隔离照旧。

预算：产品代码净增不超过 300 行。

## 验收

1. 测试覆盖：不响铃的到点不响、月历显示、跨天、全天、换人隔离、AI 列出和新增。每项有反向对照。
2. 模拟器全量测试和 ASan 版通过；能力清单重新生成并 `--check` 通过；S31 能编过；gcccheck 通过；ui-scale 0 违规；隐私扫描。
3. 报告写清和设计的差别、截图路径。
