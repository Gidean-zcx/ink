# 相册接口边界（UX19 / G03、G04）

| 功能 | 已有能力 | 缺能力 | 页面字段 | 本人例外 |
| --- | --- | --- | --- | --- |
| 手动重读相册 | `file.index`、`file.thumb`；页面已有媒体执行器读取流程 | 拟在本页登记 `gallery.reload`，仅重新运行现有读取流程，按钮和 AI 共用；不增加重试或索引格式 | 加载说明、空态、读取失败、当前页 | 无需确认；仍按当前家人读取 |
| 前后照片 | `photo.open {id}`、`gallery.prev/next`（后两项只翻网格，不能翻照片） | 提案 `photo.prev/next`：只在 Photo 内，沿当前家人授权相册的同一顺序换图；首末不提供动作。当前任务先不实现 | 当前文件名、相册内序号、总数；首末标志；返回后保留网格页 | 不新增确认；权限与当前照片读取一致；锁屏相机不能借此访问旧照片 |

【实现】现有文件索引只有路径、类型、大小、稳定 ID，没有拍摄日期。不能把文件序号或宿主文件时间写成拍摄日期；日期分组等待真实日期来源。

【实现】本任务仅为明确要求的手动重读登记 `gallery.reload`，不登记或假称已存在照片前后切换能力。照片问 AI 和删除继续分别使用 `photo.ask`、`file.delete`；删除保留现有不可恢复确认。
