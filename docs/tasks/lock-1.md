# lock-1：锁屏遮住上一页，换成时钟、下一件事、通知汇总和家人头像

总规则先读 `docs/tasks/codex-rules.md`（第 9、10 节优先）。

## 为什么

用户 2026-11-12 选了外壳预览页的“遮住上一页，用新锁屏”（D-135，“都按推荐推进”），改掉 D-38 的默认“这一页加小标记”。现在锁屏后屏幕上还是刚才那一页，别人拿起来能看到内容。预览页示意图：https://claude.ai/artifact/XuRj3y8DCZv4S5zxrQVJWS （“3. 锁屏”）。参照：iOS 锁屏的时钟、小组件和隐藏通知内容，MuditaOS 的按类别汇总，Kindle 的锁屏，Fire 平板在锁屏点头像换人（`shell-research-1` 的 DESIGN.md 第 3 节和另一路调研）。

## 要做的

1. **锁屏画面**（`system/ui/lock_mark.c` 等）：大时钟和日期居中；下面一行“下一件事”（今天有提醒或日程才显示）；通知按类别一行一个只写数量（“短信 2”“未接来电 1”），**不显示内容**；最下面一排家人头像加名字，点自己的头像进入（大人走现有的密码验证，D-95 的两分钟内直接回原页照旧）。没有通知、没有下一件事时这些行都不画，不写“0 条通知”。
2. **紧急呼叫和相机**：紧急呼叫放在输密码那一页（D-119，不用解锁）；锁屏相机照 D-121（只能拍、只能看这次拍的），入口放在输密码那一页。
3. **刷新**：时钟每分钟只刷数字那一块（现有的分钟刷新机制照用，D-96）；通知数变化只刷那一行；按 D-127 少刷新。
4. **孩子**：孩子的锁屏同样结构，点自己的头像直接回原页（孩子不需要密码，照现有规则）。
5. 现有的“壁纸”“时钟和待办”锁屏样式保留为可选项；Mogo 的锁屏样式以后由 `lock-styles-1` 加进来。

## 范围和预算

- 只改：`system/ui/lock_mark.c`、`system/ui/shell/off_picture.c`、锁屏相关的测试、`docs/tasks/lock-1/`；能力表重新生成后提交。
- 不碰：主屏、控制中心、设置的文件（`home-1`、`control-1`、`settings-1` 同时在做）。
- 产品代码不超过 300 行。
