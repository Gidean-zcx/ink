# audit9-fix：修 batch9 审计的 B9-01～B9-03

总规则先读 docs/tasks/codex-rules.md，第 7 节优先。报告写到 docs/tasks/audit9-fix/REPORT.md。

审计报告是 docs/audits/batch9/report.md，每条有位置、复现和建议修法，先读它。报告里的实验驱动在审计自己的构建目录里，这里没有；复现要自己写成测试。每条配一个测试（修之前失败、修之后通过），产品代码净增不超过 120 行。

## 要修的

1. **B9-01（中）AI 重新打开蓝牙后，页面还显示“蓝牙已关闭”**：在现有的设置变化回调里同时处理开和关，打开时替换掉旧的关闭提示，不依赖触摸操作的回执。测试：页面开着时，AI 关蓝牙、再开蓝牙、再配对连接，快照和屏幕都不再出现“蓝牙已关闭”。
2. **B9-02（中）长候选把“更多”挤出屏幕，快照却说看得见**：候选栏给“更多”（和话筒）留固定的可见位置，折叠状态下候选的总宽度受约束，放不下的进展开页；快照只列实际显示出来的候选和按钮。单纯恢复原来的均分样式会重新裁切长候选，不算修好。测试：正式词库下输入 `zhrmghg`、`nh`，以及最大字号下的 `nh`，“更多”完全在屏幕内且点得到，快照与屏幕一致。
3. **B9-03（中）词库里有字库显示不了的字**：生成词库时按随包字体（`ascii,punct,pinyin,gb2312`，见 CMakeLists.txt 的字体规则）的字符集过滤词条，再按原规则裁剪到 1 MB 以内并重新计量。加一项检查：词库里每个候选的每个字都在随包字体里有字形。报告给出过滤前后的词条数和 90 条测试集的首选、前五命中率。

## 边界

- 只修这三条，不顺手重构。
- 同时在做的有 batch10：ime-quality（也改 tools/imedict 的生成工具，加简拼权重；你只加按字体过滤那一步）、index-compact、settings-gaps。共用文件只改你那几处。
