## UF-M1（中）：图标白底和分隔线按页面特判

`navigation.c` 的 `group_row` 里用 `N.page_id == PAGE_SETTINGS` 只给设置首页加图标白底圆和行分隔线；`factory_pages.c` 里单独去掉装饰图标的描边、去掉开关的白色方底。画板里所有分组列表（Settings、SetSound、SetDisplay、SetNetwork、SetStorage 等）都是同一个样式，按页面特判会让同一种控件在不同页面长得不一样，以后每页都要再特判。

要做的：

1. 把“分组行的图标白底圆、行与行之间的分隔线、不能点的装饰图标不画描边、开关不画白色方底”做进共用的控件（`ink_ui_list_row`、分组卡片、`ink_ui_circle`、`ink_ui_toggle` 这一类），所有分组列表一致，去掉页面特判。要点的按钮（可以点的圆）保留描边，按规范 §1 区分。
2. 重新出受影响页面的分数（修前、修后），测试改成检查共用控件，而不是只检查某一页。
3. sound-clock 正在改 SetSound 的行内容，你只改共用控件的样式，不改 SetSound 分支。
