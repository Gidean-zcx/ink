# port-hal-1 复核（主会话，2026-11-10）

结论：**合入。** 只改了 S31 端口目录和一个宿主机单元测试；没有连设备，也没有读 ink-hw。

## 看了什么

- 中断：ISR 只给任务置位通知，处理（I2C 读）在任务里；线一直低时退避复查，避免卡死或空转；先登记再开中断，已低的线立即处理一次。
- I2C：设备表有锁，超时和错误码映射和模拟器一致，映射放在宿主机可测的头文件里并有反向对照。
- 板级初始化顺序照模拟器；每个 GPIO 编号都注明出处，只有一份。
- 屏幕输出层只写了设计和工作量（约 14 个一小时任务，4～5 个要上机），按 D-124 自己写、不看 EPDiy 源码。
