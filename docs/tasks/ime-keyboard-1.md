# ime-keyboard-1：键盘照设计稿补齐：中英切换、中文标点键、图标键

总规则先读 docs/tasks/codex-rules.md，第 7、8、9 节优先。报告写到 docs/tasks/ime-keyboard-1/REPORT.md。只编译、跑宿主机测试，不碰设备。

## 背景

用户 2026-11-11 在真机试用：“输入法没看到有中文输入呢”“输入法键盘我好像就没有看到中英文切换的按钮呢”。

- 没有中文：词库不在卡上，只剩内置 19 个字。这由主会话另改（词库放进闪存资源包），**本任务不碰** `system/services/text/pinyin.c` 和 `tools/asset_pack.py`。
- 没有切换键：设计稿 `$INK_DESIGN/png/ImePinyin.png`（生成脚本 `$INK_DESIGN/gen/layout.py`）。
  - 最下面一排是：符号、**中**（中英切换）、中文逗号“，”、空格、中文句号“。”、完成。
  - 第三排的大写和删除是图标（图标库已有 `shift`、`del`）。
- 现在的实现（`system/ui/shell/keyboard.c:347-369`）：第三排是“大写”“删除”两个字，最下面一排只有“符号/字母”、“空格”、回车。
- 输入逻辑（`system/services/text/text_service.c:441`）：普通输入框里小写字母一律当拼音，回车把字母原样上屏，所以要打英文只能打完按回车。
- 规格 `docs/product/system-ui-spec.md` §7.5：`ImeSymbols` 两页符号，英文模式用半角。

## 要做的

1. **中英切换键**：只在普通输入框（`INK_TEXT_PLAIN`）出现，键上写当前模式（中／英）。
   - 中文模式和现在一样走拼音；英文模式字母直接上屏，空格就是空格。
   - 切换时如果有没上屏的拼音，先原样上屏（和回车一样）。
   - 模式在换输入框后保留，重启后回到中文。
   - 密码、网址、数字、电话框不变：它们本来就不走拼音。
2. **标点键**：中文模式是“，”“。”（全角），英文模式是“,”“.”（半角）。符号页在英文模式用半角。
3. **大写、删除用图标**：用 `shift`、`del`，大小和间距照设计稿和 ui-scale 规则；有读屏用的文字标签。
4. **AI 也能用**：模式写进键盘的语义快照；切换走现有的 `keyboard.key` 能力（加一个切换键值），不另开旁路。
5. 设计稿和规格里没写到的细节，取最简单的做法，写进报告“和设计不一致的”。

预算：产品代码净增不超过 200 行。

## 验收

1. **宿主机测试**：
   - 切换后字母直接上屏；
   - 切回中文继续出候选；
   - 切换时没上屏的拼音原样上屏；
   - 两种模式下的标点；
   - 密码框没有切换键；
   - 换输入框模式保留；
   - AI 用 `keyboard.key` 切换，快照里模式跟着变。
   - 反向对照：英文模式仍走拼音、切换丢掉没上屏的拼音、标点不分中英，各改一处，测试都要失败。
2. 模拟器全量和 ASan 版通过；S31 编过，产品代码 0 警告；gcccheck 通过；ui-scale 0 违规；能力清单检查通过。
3. 截图：中文模式（对照 `ImePinyin`）、英文模式、符号页（对照 `ImeSymbols`），界面语言中文和英文各一套。逐张目视检查：无裁切、无遮挡，图标不盖文字。
