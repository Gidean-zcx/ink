# memo-record 复核（主会话，2026-11-10）

结论：**合入。** 编码按数字定为 Opus（D-112），录音备忘的整条路（录、取消、来电打断、AI 键、转写、播放、换家人、断电）都有测试和反向对照。

## 看了什么

- 编码对比：Opus 和 AI 语音共用一套编码，内部 RAM 不增加，文件和上传约为 ADPCM 的三分之一；12～16% 单核占用是成本模型的估算，标明真机待确认。
- 转写复用听写的 `asr.stream` 协议，中枢不用改；一次只转一条，联网等时机触发补漏，断电后把录了一半的文件收成备忘。
- 内部能力 `memo.voice` 不给 AI；`memo.record` 沿用 `audio.record` 原有的确认规则，没有放松。
- 截图：MemoRecord 和画板的布局一致（圆环、标题、说明、两个按钮）。
