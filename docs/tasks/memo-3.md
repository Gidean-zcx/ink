## 要做的

3. **篇内搜索**（照 Fossify `MainActivity:596-675`）：在一篇里搜，显示“第 2 处，共 5 处”，上一个、下一个。
4. **清单**（照 Fossify 的清单页）：一篇可以是清单；加一项、删一项、改一项；点整行勾选；勾完的移到下面（Fossify 有这个选项，做成每篇的选项或默认，写理由）；文本和清单可以互相转换（Fossify 有）。
5. **待办和提醒**（参考 Joplin `Note.ts`）：一篇或清单里的一项可以设到期时间，到期由现有的提醒能力负责（调现有提醒能力，不另做定时）；“从备忘里提取一个提醒”这类现有能力保留。

## 验收

1. **照参照路径走一遍**（`APPS.md` A09，模拟器脚本，每步截图并断言）：写一篇 2,000 字的长备忘 → 切到别的应用再回来，字都在、没按过保存 → 列表搜一个词，点结果定位到命中处 → 篇内搜索“第 1 处，共 3 处”，点下一个 → 新建一篇清单，加 5 项、勾 2 项，勾的移到下面，列表显示“2/5 已完成” → 给一项设明天 9 点到期，提醒服务里多了这条提醒 → 录一段音并转写（模拟器的中枢替身），转写进了这篇 → 让存储写失败一次，提示“草稿已存、备忘没存上”，字一个不丢，点“再试一次”成功。同一条路径用能力调用（来源是 AI）走一遍，结果一样。
2. **自动保存时机**：离开页面、锁屏、换家人前都保存了（各一条测试）；反向对照：去掉离开页面时的保存，这条必须失败。
3. **家人隔离**：A 的备忘、搜索结果 B 看不到。
4. **老数据**：老格式的备忘和清单读出来内容齐全。
5. **改前改后截图**：备忘列表、编辑页、篇内搜索、清单、录音页、保存失败提示，默认和最大文字大小各一套。
6. 主工程普通全量 ctest 过（含 `ui-scale`）；ASan 跑备忘相关测试和 `ui-scene-*` 过；S31 宿主机测试过；`ports/esp32s31/build.sh` 编译通过、无新警告。报告写固件增量、产品代码行数、`gcccheck` 结果、改过的已有测试（只改定位方式和页面结构，不改业务断言）、改名或删除的能力。
