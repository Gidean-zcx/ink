# 输入框和表单覆盖

【实现】执行 `rg -n 'ink_textfield_create|ink_textfield_long_create|lv_textarea_create|ink_ui_datetime_picker' system apps --glob '*.c'`，得到26行；扣除组件定义和内部转调4行，覆盖22个实际构造点。没有找到绕过组件的 `lv_textarea_create`。下面按构造点展开具体字段；密码盘、DTMF和计算器是额外的专用输入，不计作普通文本框。

规格 C03～C06、C12、C13 见 [COMPONENTS](COMPONENTS.md)。以下均为【实现】源码／阅图结论，不是表单交互实测。输入外观统一由 `ui-input-2` 负责；通信三个应用由 `comm-ux-2` 负责，本次不重复拆。
