【实测·目视核对】已查看全部 12 张总览，另查看主屏、设置、输入框完整原图。以下不是上述严格断言的“通过”结论：单行控件按原合同可用省略号，控件互相遮挡也未由该断言完整覆盖。

| 页面 | 从完整对比图看到的问题 |
| --- | --- |
| 主屏 | 自绘页指示的位置借用了浮层圆角，令牌减小后点与当前页胶囊挤在一起，默认与最大档都有。 |
| 设置 | 首页从八行变成两页，默认首屏显示前五行；大字时部分值仍省略。属于分页与容量变化，不能靠恢复八行断言解决。 |
| 短信、拨号 | 输入标签常显后，页面仍按旧输入高度给回复栏或拨号网格定位；大字“新建”“展开”“删除”等动作出现截断，部分输入边框被下方内容遮住。 |
| 联系人 | 搜索标签常显增加了总高，下面列表仍按旧位置开始，搜索框下半被遮住。 |
| 通话 | 大字“耳机未连接”等按钮文字仍省略；挂断仍由页面选用无底图标按钮，若需主按钮应在页面任务中接入。 |
| 备忘、键盘 | 原生键盘底行贴着画布下缘；键宽和部分键高不足 108，编辑工具栏七项也不能横放七个 108 宽按钮。 |
| 控制中心 | 两端减加已与轨道对齐，但交互仍是旧页面的绝对坐标换算；大字下“正在做的事”文字会省略，新两列开关格未接入。 |
| 关于 | 页面自绘连续行侧边仍保留，去掉共用外框后看起来像未闭合的括号。 |
| AI 面板、长文编辑 | 页面自己写的 `1/1` 仍是数字，没有改成共用圆点。 |

本任务未修改这些页面，未缩小文字、隐藏数据、放宽裁切断言或资源预算来得到通过。源文件定位见 [页面接续清单](PAGE-FOLLOWUPS.md)，具体不足 108 的控件见 [点按检查](HIT-TARGETS.md)。相机取景图来自模拟器的合成图案，不代表真机画质。
