# 截图说明

全部为本机模拟器实际渲染，使用合成成员和数据，不是实机或设计稿。每张小于 300 KB。

- `before/`：指定基线页面；真实回环 HTTP 客户端驱动的等待、接收中、已收到；`large` 使用系统最大文字设置。
- `after/transfer/100/`、`120/`：当前页面默认、最大文字；`snap-waiting` 等待授权，`snap-received` 为旧极简页面完成单文件的兼容态，`snap-received-native` 为原生服务器多文件回执。
- 生成方式：报告命令 D。网页浏览器截图因权限审查拒绝访问本机预览而缺失，未用设计稿或其他渲染代替。
