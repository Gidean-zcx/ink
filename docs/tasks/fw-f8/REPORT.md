## 和设计不一致的

【实测】对照分数：TodayEdit 45.104/255、IconMenu 46.353/255，均超过 12。证据在 `build/fw-f8-evidence/compare/`，命令：`python tools/ui_compare.py --build build --design "$INK_DESIGN" --out build/fw-f8-evidence/compare --scenes TodayEdit IconMenu --reuse`。

【实现】TodayEdit 使用已有分页列表，增加“第几张”和“上移”，行间距、描边、固定读书行与参考图不同；实际卡片来自应用，未硬编码画板六个示例。IconMenu 按任务只在“全部”页打开，参考图底图是主屏；控件用现行规范尺寸和灰度，面板因完整容纳关闭按钮而更高。已检查并修掉标题与顺序文字重叠、关闭按钮裁切。
