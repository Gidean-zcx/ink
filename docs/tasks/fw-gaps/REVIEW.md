# fw-gaps 主会话复查（2026-11-10）

结论：成立，直接合入。应用可以用 `ink_app_db_open_async` 在后台以调用时的家人身份打开集合，完成后回到界面任务；页面已关或家人已换就不回调并关掉句柄。状态、设置、能力事件三种订阅都有了可退订的版本（`*_handle` 返回句柄，`ink_state_unwatch`、`ink_settings_unwatch`、`ink_cap_unsubscribe` 退订），只在界面、媒体、后台三个串行执行器上保证退订后不再回调；旧接口不变。examples/jot 和说明都改成用这两样。

## 合入时主会话改的

- 合到最新主线（已有 storage-order、phone-2）后，`integration-dictation` 有一项稳定失败：听写断网时文本框里是“断之前的。断之”，测试要求只有“断之前的。”。按 `voice_input.c` 的 `fail_with`，断网时已经听到的半句本来就要留下；这条检查默认断网那一刻第二句还没出字，订阅表多出的几次加锁让时序稍有变化后就不成立。检查改成按设计判断：前面是完整的第一句，后面为空或是第二句的开头；“下一次连接什么都不知道”的检查不变。
