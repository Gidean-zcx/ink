# phone-3：电话照 Fossify Phone 重写——输号码就列出匹配的联系人、最近通话按人和时间归组、通话中的控制和真实状态；匹配规则对照 Lineage Dialer

总规则先读 `docs/tasks/codex-rules.md`（第 9、10 节优先）和 `docs/tasks/vendor-common.md`（第 11 条）。

## 为什么

用户 2026-11-12：“所有的应用和系统应用都是移植的最优秀的三方项目吗 我怎么感觉不太像呢”；“好不好不是看移植工作量小 是看功能成熟度 用户使用体验 这些”（D-129）；“我需要你先把当前的壳和现有已有的应用移植或参考重写搞到成熟可用”（D-131）。

调研（`docs/tasks/replan-sysapps/APPS.md` A01、`CURRENT.md` A01）：现在的电话（`system/apps/phone/phone.c`）有拨号、按号码匹配一个联系人、最近通话、通话页、静音和声音去向、拨号键盘、锁屏紧急呼叫，也分清了“拨出”和“接通”；缺的是成熟拨号应用的“边输边列出多个候选”、按人归组的最近通话、通话结束后的结果，通话记录按分钟存时长（短通话看不出）。已知问题：拨号页的提示文字压住键盘。

## 要做的

1. **拨号页**（照 Fossify `DialpadActivity`）：号码框在上，拨号键盘在下，中间是边输边更新的候选列表（多个，不是只给一个）：号码里任意位置包含所输数字的联系人（Lineage 号码匹配规则），以及最近通话里匹配的号码；点候选填入并可直接拨。中文名字的按键匹配：先查系统里有没有现成的汉字转拼音（例如文本服务的词库能否反查单字）；有就支持按姓名拼音首字母匹配（“张三”按 9、7），没有就只做号码匹配，写进报告。修好提示文字压住键盘的问题。
2. **拨出到挂断**（照 Fossify `CallActivity` 和 Lineage `CallCardPresenter`）：拨号受理后显示“正在拨号”；模组报接通后才显示“通话中”和按秒走的时长；对方拒接、没人接、号码不通各有自己的结束说明；挂断后显示“通话 1 分 05 秒”这样的结果，再回到最近通话。**模组回了 OK 不能显示成已接通**。通话中：静音、声音去向（扬声器、蓝牙耳机，照现有能力）、拨号键盘（发按键音）、挂断。
3. **最近通话**：同一号码同一天连续的记录归成一组（Fossify 的做法），用文字写清“未接”“打进”“打出”（不靠颜色），有联系人名字就显示名字；点一行回拨，点右边进详情（这个号码的历史、打电话、发短信、加为联系人或查看联系人）。通话时长改成按秒存（`phone.calls` 记录版本加一，老记录按分钟乘 60 读）。删一条记录照现有删除规则（能撤销就给撤销，找不回来的才确认，D-105）。
4. **快捷拨号**（Fossify 有）：长按 2～9 拨给设好的联系人，每位家人自己设。时间不够就不做，写进“没做到的”。
5. **选卡**：我们是在设置里手动切卡（D-128），拨号不弹选卡；拨号页写当前用的是哪张卡。
6. **紧急呼叫**（D-119）：锁屏不解锁、飞行模式下都能拨 110、120、119 的现有流程和限制不变，只换样式。

## 共同要求（页面任务都一样）

- 来源：功能、页面、状态、出错处理照上面的来源一个不落，不自己发挥；`docs/tasks/phone-3/SOURCE.md` 写每一页对应来源的哪个文件和行号，哪些没照搬、为什么（例如安卓 Telecom 才有的保持通话、多方通话）。
- 新设计语言（`design-lang-1`）：只用令牌和共用控件（`system/ui/ink/ui_theme.h`、`system/ui/ui_list.c`、`system/ui/textfield.c` 里的按钮、输入框、列表行、开关、分段、空状态）；能点的不小于 108 px；一屏最多一个主按钮（拨号页的主按钮就是“拨打”）；行间细分隔线、组间留白；图标不套圆圈；没内容的区块不画，整页空才用共用空状态。不写死像素和颜色（`ui-scale` 检查）。旧画板的对照分数（`tools/ui_compare.py`）不作验收。
- 能力：每个用户操作都是能力（`system/include/ink/sys/cap.h`），按钮和 AI 调同一个；页面快照列出可见内容和能做的动作，跟页面一致。现有能力名（`phone.*`、`call.*`、`contacts.selected`）尽量不改，改了或删了的逐条列进报告（AI、短信和联系人应用都在调）。
- 不变的规矩：家人隔离（通话记录按家人分开）、孩子模式（孩子能打谁照现有规则）、确认卡只给 D-105 的高风险动作（人自己按拨打就直接拨；AI 替人打电话照现有策略）、少刷新（D-127：通话时长只刷数字那一块）、按下反馈 D-31、密码不给 AI 不进日志。
- 文字大小：跟系统“文字大小”一起缩放（`ink_ui_px`），默认和最大一档各出一套截图；放不下就分页或换行，不缩字、不裁按钮。
- 原地重写（分支里替换旧页面，旧页面代码删掉，不留两套）；合不合入、新旧怎么换，等用户看预览后由主会话定。
- 共享文件：`docs/system/capabilities.md` 用 `python3 tools/capabilities.py` 重新生成后提交；新能力进 `tests/integration/ai_surface.c` 的两张表（给 AI 的写清必填参数，不给 AI 的写理由），新文案的英文加进 `assets/i18n/en.tsv`，这两个文件都只在末尾追加本任务的行；合并冲突由主会话处理。
- 截图放 `docs/tasks/phone-3/`，单张不超过 300 KB，先看干净的整页图（没有调试框）。

## 验收

1. **照 Fossify 的参照路径走一遍**（模拟器脚本，每步截图并断言）：拨号页输 `138` → 候选列表出现两个以上匹配的联系人 → 再输两位，候选变少 → 点其中一个 → 号码填好 → 拨打 → 显示“正在拨号”（这时模组已回 OK，但页面**不能**显示“通话中”）→ 模拟器让对方接通 → “通话中”、时长按秒走 → 静音、切到蓝牙耳机、打开拨号键盘按 1 → 挂断 → 显示“通话 x 分 x 秒”→ 回到最近通话，最上面一条是这次、时长按秒。另走两条：对方拒接、没人接，结束说明各不相同。同一条路径用能力调用（来源是 AI，按现有策略）走一遍，结果一样。反向对照：把“模组回 OK 就算接通”放回去，接通前的断言必须失败。
2. **最近通话**：同一号码同一天打了三次，显示成一组带次数；点一组回拨；点详情看到三条历史和“发短信”“加为联系人”。老格式的记录（按分钟）读出来时长正确。
3. **家人和孩子**：A 的通话记录 B 看不到；孩子拨号照现有限制。
4. **紧急呼叫**：锁屏下进紧急呼叫页拨 110 的现有测试照过。
5. **改前改后截图**：拨号页（空、输入中带候选）、通话中、通话结束、最近通话、通话详情，默认和最大文字大小各一套。
6. 主工程普通全量 ctest 过（含 `ui-scale`）；ASan 跑电话、联系人匹配和 `ui-scene-*` 过；S31 宿主机测试过；`ports/esp32s31/build.sh` 编译通过、无新警告。报告写固件增量、产品代码行数、`gcccheck` 结果、改过的已有测试（只改定位方式和页面结构，不改业务断言）、改名或删除的能力。
