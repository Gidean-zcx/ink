# design-lang-2：让新设计语言能合进主线——修完它带来的 32 项测试失败和页面毛病

总规则先读 `docs/tasks/codex-rules.md`（第 9、10 节优先）。

## 背景

`design-lang-1`（本分支的前面几个提交，报告 `docs/tasks/design-lang-1/REPORT.md`）把新设计语言做进了主题令牌和共用控件：去掉粗框和圆圈、能点的统一 108、三种按钮、一种输入框、细分隔线。截图看效果是对的（`docs/tasks/design-lang-1/overview-*.png`）。但它还不能合进主线：普通全量 423 项里 32 项失败（清单在 `docs/tasks/design-lang-1/VALIDATION.md` 第 14 行起），截图里还有几处毛病（`PAGE-FOLLOWUPS.md`、`LAYOUT.md`）。明天的页面任务（控制中心、设置、电话、短信、联系人、备忘、时钟、文件、计算器）都要在新设计语言上做，所以这个任务在关键路径上，今晚要做完。

## 要做的

1. **把 32 项失败逐项修到通过**：
   - 页面被裁切、重叠、越界（大字今日、孩子今日、来电、日历、天气、出厂设置、确认页、文件、通知管理、设置小项等）：在页面里改用令牌和共用控件，让内容在默认和最大文字大小下都放得下（放不下就分页或换行，照成熟应用的做法），不缩字、不把点按范围改小。
   - 英文文案放不下（`i18n-*`）：用换行、缩写不了就分两行；不删文案、不放宽检查。
   - 阅读的三个性能场景（`scenario-reader_continuous`、`_rapid`、`_empty`）：查清翻页变慢、动作缺失的原因并修好（共用字体实例合并或行高改动都可能是原因），**不许放宽预算**。
   - 测试断言里写死了旧尺寸、旧边框的，只在新规格确实有意改变的地方更新，并在报告里逐条写“改前 → 改后、为什么不是放宽”。
2. **截图里的毛病**：主屏指示点挤在一起；“关于”页右边多出一条竖线；联系人搜索框被列表盖住；短信回复框和拨号盘还按旧输入框高度定位；短信空页的页码点。
3. **共用控件的点按范围**：共用的按钮、行、开关、滑杆 − + 都不小于 108×108。键盘上的单个按键和月历格子这类页面自有的小格不在本任务（由页面任务定），在报告里列出。
4. 改完重新出一遍 `design-lang-1` 那套 30 页改前改后截图（覆盖原图），给用户看最终效果。
