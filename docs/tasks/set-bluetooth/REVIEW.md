# set-bluetooth 主会话复查（2026-11-10）

结论：成立，合入。蓝牙设置页按画板做了：开关（新设置项 `bt.enabled`，默认开，关掉时断开耳机、拒绝搜索和配对）、已配对耳机列表（点按连接或断开、长按忘记）、搜索后点按配对并连接（`bt.pair` 加了可选的 `connect`），各种失败状态都有。设置的蓝牙一行、通话页的耳机按钮（没连耳机时）、声音页的蓝牙耳机一行都能进来。孩子沿用 `bt.*` 原有的 `child_ok`。

合入时主会话改的：S31 的 gcc 报 `bluetooth_page.c` 把回执的 `say`（160 字节）写进 96 字节的状态行可能截断（Linux CI 也会报），状态行改成和 `say` 一样大。

留下的：硬件接口只有阻塞的扫描，关掉蓝牙时在途的扫描要等它自己结束（模型里最多 1.5 秒），结果会被丢掉。“当音箱用”“翻页器”没做，接口保留。
