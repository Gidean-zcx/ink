## 新增的机制

任务要求的原厂 HTTP 服务器（16 KiB 栈）和两个原厂请求任务（各 16 KiB PSRAM 栈及 8 项队列），均随传书启停；任务要求的授权会话 cookie；一把保护授权与文件回调的互斥锁。未新增后台重试、持久格式或常驻任务。

采用 HAL 的 native start/stop 加一个授权回调和一个文件回调：S31 返回 1 接原厂服务器，模拟器返回 0 保留逐字节实现。系统只保留一份成员、授权、到期和能力策略。超过 100 行是因为还需替换原厂文件/目录接口及接入二维码和构建；直接把原厂 POSIX 写卡接口留下不能满足成员和存储边界。
