# almanac-2 对照表

本任务是“搬代码”的数据任务，没有自己的页面。参照是 Mogo（`mogo-e4p` 提交 `864f2f9`）的离线历法模型 `main/time/calendar.c/.h`、生成器 `tools/generate_calendar_data.cjs`、原测试 `tools/calendar_host_test.py` 和说明 `docs/development/guides/CALENDAR.md`。所以每行是参照的一个接口、操作或状态；Mogo 用这些数据画的页面（老黄历单日锁屏、万年历月格）也各列一行，标明归哪个任务。replan 调研的出处：`docs/tasks/replan-media/REPORT.md:48`（月历/老黄历行），`docs/tasks/replan-media/SOURCES.md:15`（生成器调 lunar-javascript）、`:263–264`（宜忌按月干支和日干支查）。`docs/tasks/replan-sysapps/APPS.md` 里没有单独的老黄历条目（日历条目归 `calendar-3`）。

下面的行号都按 v1 拷进来的原文（和上游固定提交逐字节一致）核对过：`calendar_date()` 在 `calendar.c:38–69`；农历月查找 `:43–46`，月干支查找 `:47–53`，宜忌 `:54–55`，神煞、建除、值神 `:63–67`；`CALENDAR.md` 第 9 行讲北京时间和“请校准时间”，第 12 行讲日粒度规则，第 25 行讲数据和重生成。

墨水屏四项（刷新、灰阶、触摸、离线）对本任务的结论：没有页面，刷新 0 次，不涉及灰阶和触摸；完全离线，规则数据不会过期，所以没有“多久以前的”提示。
