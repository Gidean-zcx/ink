# airplane-mode 复核（主会话，2026-11-10）

结论：**合入，合并时补跑全量。** 飞行模式按“一个设置带动 Wi-Fi、蓝牙两个设置”来做，所以手机那样的“飞行中单独再开 Wi-Fi”自然成立；射频关在模组上（模型里确认），重启后也立刻关。

## 看了什么

- 网络服务：选网同时看 `wifi.enabled` 和 `net.airplane`；打开前的状态先落盘再关，关闭时照文件恢复；AI 或远端打开时先回执、2 秒后才真正关（期间再改会取消定时）。
- AI 服务两处改动：`ink_ai_note` 走和回答文字同一条追加路径并结束这一轮；“本轮已结束不再显示错误”只挡住结束以后才到的错误（回答已经完整），超时等错误都在结束之前，不受影响。合并时和 ai-answer-long 的截断代码会碰在一起，按“提示也走截断后的追加”合。
- 拒绝打电话、发短信放在最前面（短信在存草稿之前），回执说明原因；统一面板靠回执里的固定说明识别，以后改文字要两处一起改。
- 改已有测试两处：设置表缓冲（多了设置放不下）和能力登记，都是必须跟着变的。

## 主会话复验【实测】

合并到 `claude/system-layer` 后跑全套（见合并提交）。

## 留下的

- 紧急呼叫例外（D-119）在任务 `emergency-call` 做；`CFUN=4` 真机行为、Wi-Fi 和蓝牙真正断电、开机窗口期要上机核实。
- 顺手发现的状态栏 `"mobile"`／`"lte"` 不一致，主会话合并时修；拨号页提示压住键盘、点“关闭飞行模式”后面板不自动收起，记进 backlog。
