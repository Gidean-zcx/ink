## 要修的

1. **B7-01（高）旧通话的拨号音确认用在下一通**：通信服务给每通电话一个代次（以及对方号码）。`call.dtmf` 进入确认前绑定这一代次，执行时核对；通话结束，这通电话的待确认请求失效（回执过期，确认卡不再能执行）；确认说明写明是发给谁。测试：待确认期间挂断、接通另一通，再确认原请求 → 模组收不到按键、回执是过期。
2. **B7-02（高）通话键盘的按键进了 AI 上下文**：快照里已按的序列按秘密字段处理（只导出有没有、几位，不导出值）；`call.controls` 事件不带按键值；活动记录、日志也不记按键值。AI 自己发按键仍走确认（D-105）。测试：真实点按 `246802` 后，AI 上下文、事件负载、活动记录里都找不到这串数字。
3. **B7-03（中）电脑归还存储卡后马上断电，索引仍当已建好**：把卡借给电脑之前，在卡上写好 index-durable 的“索引不全”标记；归还后照现有流程补建、清除。测试：照审计的步骤（借出、电脑新增文件、归还后立刻断电、重启），新文件有编号、`file.usage` 是新数。
4. **B7-04（中）改目录名时逐个文件读卡**：`index_edit` 改路径时沿用原记录里的大小和修改时间，不在编辑锁里读卡（改名不改变这两个值）。测试：300 个文件的目录改名，持锁回到改动前的量级（审计测得 189 ms 变成 8.78 s），给前后对照。
