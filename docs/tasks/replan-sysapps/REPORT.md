## 顺手发现

- 旧ui-audit-2不能照抄：当前已支持联系人独立入口/搜索/详情、短信直输号码、相机按空闲调度、备忘保存状态区分，见CURRENT。计时器分钟显示仍在，秒表却已有按秒刷新。
- Brookesia当前v0.8和历史phone demo分工已变；源码还说明Wi-Fi列表实例的PSRAM开销。框架同为LVGL不等于低资源，交架构任务作为有证据的线索。
- 真实网页交互与远程像素客户端不是同一层；noVNC/Guacamole能改善图像/输入传输，也不能自动补网页语义或保护密码输入上下文。
