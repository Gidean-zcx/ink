# 14类应用的候选与重做参照

结论：不支持“我们的已经最好”或“原厂默认第一”。下面每类按功能覆盖与日常工作流给2～3个优先比较对象；成熟手机应用排前，功能较窄的嵌入式实现明确标出局限。不是全球穷尽排名，也没有把仓库热度、移植容易、许可证当作成熟度证据。

固定提交、语言/框架及原文件行号都在 [SOURCES](SOURCES.md)；现状依据在 [CURRENT](CURRENT.md)。功能存在标为【实现】，引用README的标为“上游说明”；交互价值、排序、墨水屏适配和建议均为【估算】，没有本次运行/真机体验证据。

“搬交互”表示按其工作流和行为重做，不表示Kotlin/Java/Dart代码已经能在S31运行；“可搬代码”只指已找到的代码段，还需要适配并复验。所有候选的物理触控尺寸、中文大字号、残影和功耗均未实测。
