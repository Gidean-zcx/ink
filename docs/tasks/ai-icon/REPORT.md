## 第四轮怎么定的参数

- 用真实管线 `ink-icon-raster` 转成 16 级 INKI，沿每条被压线条的中心线量断头到交叉线之间最长一段浅色（墨量 ≤85/255），取所有断口里最小的。
- line 2.4 / 断口 4.2：34 px 2.10 px、43 px 2.20 px、53 px 3.23 px；solid 3.2 / 4.2：34 px 2.26 px、43 px 3.51 px、53 px 3.30 px。第三轮原版（line 2.8、solid 4、断口 2.4）只有 1.04～1.70 px，所以看着像合上了。
- 扫参：line 线宽 2.2～2.8、solid 2.8～4.0、断口 2.4～4.2；34 和 43 px 都 ≥2 px 的组合里取最轻、不比电话、短信、铃铛显重的一组。断口加大后短于 3 个网格单位的碎段被丢掉，在 150 px 大图上逐段核对，留下的线段和原版一样。
