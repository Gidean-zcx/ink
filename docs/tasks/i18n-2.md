# i18n-2：英文全覆盖之壳的页面

总规则先读 docs/tasks/codex-rules.md，第 7、8 节优先。报告写到 docs/tasks/i18n-2/REPORT.md。

要等这批页面上的功能任务合入后再开始，免得和它们改同一批文件。

## 背景

i18n-1 做好了多语言机制（`docs/tasks/i18n-1/REPORT.md`）：
- 代码里写 `TR("中文")`，数组里先用 `TR_NOOP` 做标记，用的时候再翻译；
- 译文表是 `assets/i18n/en.tsv`，构建时检查：占位符一致、没有重复键、页面里的 `TR()` 都有译文；
- 新加 `TR()` 的源文件要加进根 `CMakeLists.txt` 的 `INK_I18N_SOURCES`；
- 英文下的排版检查：标签不截断、不重叠、不出屏。

后来又迁了 time_settings、calendar、files、file_caps、settings_family。用户要的是中英文两种语言都完整（R-069、D-116）。这一项负责下面这批源文件里用户能看到的字：页面标题、按钮、提示、状态值、快照里的字段名，以及回执和通知里给人看的句子。给 AI 看的能力说明（能力表的 title）不用翻。

## 要做的

预算：产品代码不超过 300 行，不算译文表；改动主要是给字符串套上 `TR()`。

范围：
`system/ui/shell/` 下还没迁的文件：activity_card、ai_chat、ai_pages、ai_panel、airplane_card、backup_pages、bluetooth_page、confirm_card、factory_pages、interrupt_card、keyboard、kid_pages、member_gate、member_pages、off_picture、pinpad、power_menu、power_pages、settings_pages（补全）、transfer_pages、update_pages、wallpaper；以及 `system/ui/` 下的 app_registry、file_picker、lock_mark、search、textfield、ui_list、ui_semantics 里给人看的字。

1. 范围里用户能看到的中文都走 `TR()`/`TR_NOOP()`，在 `en.tsv` 里补英文。英文照手机系统的常用说法写，尽量短，和 i18n-1 用词一致。
2. 有格式化的句子保持占位符一致；中英文语序不同的，用整句模板，不要拼接片段。
3. 确认卡、打断卡里的说明来自能力的 `ask` 模板，模板在各服务里：这一项只负责卡片自己的字，模板留给 i18n-4。键盘的候选和拼音不翻。
4. 每一页在英文下都过排版检查，放不下就照界面规范改（不缩小字号），写清改了哪里。

## 验收

1. 测试：范围里每一页在 English 下截图并过排版检查；切回中文和原来一致；`i18n.missing` 计数在这些页面上为 0。
2. 原有测试照原样通过（中文是默认语言，快照不该变）；全量测试和内存检查通过；S31 能编过；gcccheck 通过。
3. 报告列出范围里每个文件迁了多少条、哪些故意不翻和原因，给出英文截图路径。
