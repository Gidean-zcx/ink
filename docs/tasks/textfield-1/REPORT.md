- 【实现】旧函数和参数签名均保留；原接口没有尺寸参数，旧调用方的 `lv_obj_set_size/width/height` 不再决定组件尺寸，由布局回调恢复容器宽与内容高。未显式选规格的短输入保持旧的无外标签高度，避免影响并行的通信／阅读任务；本任务列出的页面全部显式选规格。
- 【实现】原短输入聚焦入口也接受旧的未绑定字段，位置／样式先设好再聚焦；成员检查、能力、密码禁用 AI、文本和页面快照均保留。非秘密短输入的清除调用现有 `text.select`／`text.insert`；密码和长文沿用原删除路径，没有新服务或能力。
- 【实现】删除手绘光标、占位、密码掩码；使用 `lv_textarea_set_one_line`、`set_placeholder_text`、`set_password_mode`、`set_cursor_pos` 和原生标签选区。密码显示时间为零；按墨水屏要求关闭光标闪烁并立即完成原生光标滚动。
