## 要做的

1. **四个页签**（照 Fossify）：闹钟、世界时钟、秒表、计时器，用共用分段选择切换，进来回到上次的页签。
2. **闹钟**：列表每行写时间、重复（“工作日”“每天”“周六、周日”“只响一次”）、名字，右边开关；编辑页：时间（共用日期时间选择器）、按星期几重复（七个可点的格，照 `EditAlarmDialog`）、名字、贪睡。列表顶上写“下一个闹钟：明天 7:00，还有 9 小时”（Fossify 有）。响铃、贪睡、关掉照现有的时间服务和来电卡式的打断（勿扰时闹钟照响，`notify-svc-1` 不改这条）。
3. **计时器**：可以同时开多个，每个有名字和时长（时、分、秒分开输入，照 InfiniTime 的大按钮加减和 Fossify 的编辑框）；每个独立开始、暂停、继续、重置；到点响铃并显示是哪一个。时间服务能不能同时挂多个计时，先查；不能就写进报告，不改时间服务（`notify-svc-1` 这时也在动它）。
4. **秒表**：开始、计次、暂停、继续、清零；计次列表每行写“第 n 圈、这一圈用时、累计”，最快和最慢用文字标出（不靠颜色）；运行中只刷数字那一块，每秒最多一次；暂停后显示到 0.01 秒（现有行为保留）。
5. **世界时钟**：上面是本地时间和日期；下面每个城市一行，写城市名、时间、和本地差几小时、“今天/明天/昨天”；加城市照 `AddTimeZonesDialog` 能搜、能一次选多个；删城市照现有删除规则。城市表用现有的，夏令时现有代码没处理的写进报告。时间按分钟变化，只刷时间那一列。
6. 每位家人的闹钟、计时器、城市照现有归属规则（时钟数据按家人分开的保持分开）。
