# audit10-fix 主会话复查（2026-11-10）

结论：B10-02 由 Codex 修好；B10-01 它按任务书停下（最小改法和原 `sms` 测试冲突），由主会话改完。两条都合入，全量 301 项通过，真 gcc 检查无发现。

- **B10-02**：网络设置记下“忘掉这个网络”按钮实际所在的页，快照只在那一页列出这个动作。
- **B10-01（主会话改的）**：短信页对 `message.received` 的订阅改回后台（通信服务的入库订阅先注册，后台按顺序执行，页面的处理排在入库之后）。原 `sms` 测试失败的原因是：迟到的刷新任务哪怕最后不重画，在界面执行器里排队也算界面忙（`ink_ui_busy` 看 `ink_exec_waiting(INK_EXEC_UI)`），截图就判不稳。改成页面记下它读到的 `sms.messages` 版本（开着时非 0，原子读写），后台收到事件时先比版本：页面已经显示这个版本就不往界面投任务，有变化才投刷新。这样页面开着时新短信马上出现（`audit10-b10-01`），先打开列表再截图的原测试也不会被迟到的通知打扰。index-compact 当初为了截图稳定改成直接执行，实际是靠“入库后从不刷新”这个毛病过的。
