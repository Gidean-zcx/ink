# files-3 对照表

参照版本：Amaze `5f1aea6`、Fossify File Manager `1e43648`、Flipper `3060cee`（行号都按这三个提交核对过）。

“我们”一列只有三种写法：照做、按设备改、不做。凡是少做功能的“不做”，都列进 brief 的“要用户定”。

“验收”一列写测试名或截图名。测试名是 `tests/files3/` 里的检查（`files3-*`）或宿主测试 `flipper-*`，截图在本目录，文件名后缀 `-default`、`-max`、`-child` 是三套字号和身份。

开工核对时按代码改过的地方（和草稿不同）：

- D34、A7、K67：Flipper 原文 `archive_is_known_app()` 对文件夹返回假，所以原文的菜单里文件夹没有 Pin，`on_event` 的 Pin 分支也不收文件夹。brief 要文件夹能收藏，这一项放在 `render_item_menu` 末尾追加的我们的菜单项里（“收藏文件夹”），收藏动作调原文的 `archive_add_to_favorites` / `archive_favorites_delete`，不改原文的判断。
- K67、K68：收藏标签里原文把第三项写成“Move”（调收藏顺序）、第四项“---”（不能删）。调顺序不做，所以“Move”不画；在收藏标签打开的文件菜单没有“删除”，这是原文的行为，照做。
- D35：`mogo.open` 在 `apps/mogo/mogo.c:144`，只收 `/me/` 下的路径；`/family` 下的书不给“用阅读打开”。
- A3：页码用共用的 `ink_ui_pagebar`：5 页以内画点，5 页以上写“2/7”。主题文件不在本任务的范围里，不改。
- E：能力参数整张表只有 416 字节（`INK_ARGS_TEXT`），编号清单放不下时“放到这里”提示分几次做；全选时用 `all_path`，不受这个限制。
- I64：预算不够时整项不做（见报告）。
