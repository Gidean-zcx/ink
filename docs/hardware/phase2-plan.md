# 第 2 步写入方案：自动上机测量

起草：2026-11-06。第一次已跑完（[分析](2026-11-06-phase2.md)），第二次的差别见文末。**每一次写设备前都必须得到用户明确同意。** 一条命令跑完，你只需要插上 USB；设备待机时短按一下电源键。

## 做什么

把测量固件 [tools/hw-bench](../../tools/hw-bench/README.md) 写进空着的 ota_1，它自己跑完，电脑记下结果，然后自动复原并和备份逐段比对，最后生成报告。大约 5 分钟。

要回答的问题：内部内存到底够不够（Wi-Fi 和屏幕都开时）、Flash 和 PSRAM 的真实速度、开一次密码要多久、屏幕整屏和局部刷新要多久、设计稿的灰阶在真屏上什么样、RTC 中断能不能到 P16、板上芯片齐不齐、存储卡读速、4G 模组型号和注册状态。

## 写什么

| 地方 | 内容 | 复原 |
| --- | --- | --- |
| ota_1（0x580000）开头 | 测量固件，约 3.9 MB（第一次约 2.7 MB，这次多了几张图） | 写回备份里的内容（空） |
| otadata（0xd000） | 让引导程序启动 ota_1 | 写回备份里的出厂内容 |
| ota_1 最后 256 KiB | 测 Flash 擦写速度 | 固件自己擦掉；再和备份比对 |

**不写**：引导程序、分区表、ota_0（出厂固件）、NVS、其他分区、eFuse。写入工具只接受上面两个地址范围，其他地址在接触设备前就拒绝。固件关掉了写到 Flash 的崩溃转储和射频校准。

## 固件运行时碰什么

- **屏幕**：用出厂固件自己的驱动和波形显示灰阶条和 4 张设计稿，每张停几秒。结束后屏幕上留灰阶条，可以看一眼；不看也不影响结果。
- **RTC**：临时开 2 秒定时器看中断，然后恢复原值。
- **Wi-Fi**：只扫描周围网络的数量和信号，不连接，不记录网络名。
- **4G 模组**：只问 `AT`、`ATI`、`AT+CGMR`、`AT+CPIN?`、`AT+CSQ`、`AT+CREG?`、`AT+CEREG?`、`AT+COPS?`、`AT+CIREG?`，不改任何设置，不打电话不发短信，不花钱。模组没上电就跳过。
- **存储卡**：只按扇区读 2 MiB 量速度，不挂载文件系统，不看文件名，不写。

## 复原

全自动，任何一步出错都会尝试复原：写回 otadata 和 ota_1，然后把引导程序、分区表、otadata、ota_0、ota_1 全部读回和备份比对。比对不一致会停下并报错。

如果电脑中途断开，事后手动复原：

```bash
ink-hw/venv/bin/python ink/tools/hw-probe/flash_probe.py restore --port '/dev/cu.usbmodem*' --dir ink-hw/bench-<时间> --backup ink-hw/bringup-20261103/private/flash_full_1.bin --approved
```

最坏的情况（测量固件卡死且连不上）：**先拔插一次 USB 线**，第二次上机就是这样恢复的。这台设备没有实体复位键，长按电源键关机是固件做的，测量固件里不起作用。第 1 步已经走通过同样的复原。

## 前提（工具运行时自动核对）

整片备份两份都存在，SHA-256 以 `ba58546360dba4fa` 开头，否则一个字节都不写。

## 怎么跑

```bash
ink/tools/hw-bench/build.sh
ink/tools/hw-bench/bench.py            # 只核对备份，打印方案，不碰设备
ink/tools/hw-bench/bench.py --approved # 真正执行
```

报告写到 `docs/hardware/<日期>-bench.md`，提交前会过滤 MAC、IMEI 这类长串。原始日志只留在 `ink-hw/`。

## 第二次和第一次的差别（已跑，[结果](2026-11-06-phase2.md)）

写的地方、复原步骤都和第一次一样，只是固件内容变了：

- **屏幕方向**改成 `EPD_ROT_INVERTED_PORTRAIT`。
- **屏上显示新界面**，不再是设计稿，共 7 张：先是四个数字点（停 40 秒），然后主屏、设置、读书页、确认卡、孩子的主屏和今日，每张停 20 秒。图片用模拟器画的干净画面，不带残影。
- **设置这一张用不闪的换页（GL16）**，从主屏换过去，让你看实际残影有多重。模拟器的残影是假设的数。
- **你要做一件事，约 15 秒**：第一张出现时，竖着拿好，依次点 1、2、3、4。测量固件记下触摸坐标，并每 5 秒读一次加速度计（只读，读完恢复原来的设置）。没点也不影响其他项，40 秒后自动继续。
- **其他修正**：Flash 擦除量真正写过的扇区；4G 模组拉 MRDY 再问；串口每行之后等一下。

## 第三次和第二次的差别（待用户同意）

写的地方、复原步骤都一样。这次要补回第二次丢掉的数据，并看新的灰度和 AI 图标。

- **结果不会再丢**：测量固件跑完会反复重发所有结果。
- **USB 可能又卡死**：如果卡死，工具会说，我会马上请你拔插一次 USB 线，其他什么都不用做。
- **你要做的和上次一样**：第一张图出现时竖着拿好，依次点 1、2、3、4，点一遍就够。
