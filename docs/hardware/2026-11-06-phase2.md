# 第 2 步：第一次自动上机的分析（2026-11-06）

原始数字见[自动生成的报告](2026-11-06-bench.md)。设备上写过的地方都已复原，和备份逐字节一致。本文所有结论都是【实测】，除非另外标明。没有测量电流功耗：测试时插着 USB 在充电。

## 回答了什么

| 问题 | 结果 | 意味着什么 |
| --- | --- | --- |
| 内部内存够不够 | 开机可用 274 KiB（最大连续块 164）。Wi-Fi 约占 43 KB。屏幕开后可用 179 KiB（最大连续块 76），历史最低 115 | 够，但测量固件没有 LVGL、TLS 和系统任务，Wi-Fi 和屏幕也没有同时开。两个同时开估计还剩约 145 KiB【推断】 |
| PSRAM | 16 MiB，屏幕开后可用约 14.7 MiB | 很宽裕 |
| Flash 读 | 7.1 MB/s（模拟器原来按 20） | 模型已改。翻页时读字形比原来估计慢约三倍 |
| Flash 写 | 4 KB 平均 7.7 ms，256 KB 擦除 148 ms | 这次的擦除量到的是空扇区，数字偏好，下一次改了测法 |
| 开一次密码 | PBKDF2 3000 次 242 ms（设计估计约 100） | 能接受，但比估计慢一倍多 |
| 屏幕 | 整屏清屏 923 ms，GC16 整屏约 750～780 ms，DU 小方块 325 ms | DU 不随面积变，是固定的波形时长 |
| RTC 中断线 P16 | 定时器 2001 ms 响，P16 同时变化，平时为低 | 线是好的，之前“P16 一直低”的疑问解决了 |
| TF 卡 | 读 9 MB/s（20 MHz） | 够放书和音频，不适合放要内存映射的字库 |
| Wi-Fi | 启动 237 ms，扫描 2.5 s，信号最好 -62 dBm | 正常 |
| 4G 模组 | 没有回应 | 没有回答问题：没拉 MRDY/SRDY，也可能没上电。下一次改了 |
| I²C 上的芯片 | 19、20、38、51、55、6b 都在，触摸、加速度计、RTC、电量计、充电芯片都读得到 | TPS65185 在电源关着时不应答，屏幕一样能工作 |

## 没有回答的

- **Wi-Fi 和屏幕同时开的内存**：两项没有同时开过。
- **USB 串口丢行**：屏幕工作时丢了几行（`panel_init`、`panel_temp`），已加等待，下一次看。
- **功耗**：要拔 USB、用电量计，单独做。

## 屏幕、触摸、加速度计的方向

用户看到画面上下颠倒。查了原厂驱动和我们自己的代码：

| 部件 | 结论 | 证据 |
| --- | --- | --- |
| 显示 | 测量固件写错了，系统的映射是对的 | 【实测】`EPD_ROT_PORTRAIT` 倒着；我们的 90° 等于 `EPD_ROT_INVERTED_PORTRAIT`，测量固件已改成这个，等下一次上机确认 |
| 触摸 | 原始坐标就是竖屏坐标，和界面逻辑坐标相同 | 【文档】原厂 `map_to_logical`。实机还没验证，下一次会让用户依次点四个点 |
| 盖板三个键 | 原始 y≈1600，x=100 主页、200 上一页、300 下一页 | 【文档】`boards/metalio_plus/metalio_touch.*` |
| 加速度计 | 原厂只存了 x、y，没找到使用它的业务；我们的系统也没用。方向不知道 | 【文档】下一次竖着拿时读一次重力方向 |
| 摄像头 | 还没查 | 没有测试 |

**移植时要注意**：`input_service.c` 的 `ink_native_to_logical` 假定输入是面板原生坐标。真机的触摸已经是逻辑坐标，`ports/esp32s31` 要先转成原生坐标，或者绕过这一步。
