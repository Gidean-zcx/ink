# 第二十七期：学习状态、操作边界与可复查的画面

2026-10-27。当前资料已经有操作手册、局部任务和图像依据，但**仍没有深入到每个产品的每个功能**。本期补讯飞学习机四条教程、PocketBook应用与设置、Supernote笔记操作。所有65组仍是部分覆盖；不能把资料数量当完成率。

## 这次超出功能宣传的具体内容

讯飞T30Pro帮助目录中的四条视频，从“有这个功能”补到了具体状态。数学同步学习有方案选择、知识图谱、典例与练习、多空手写、思路提示入口、批改反馈和下一节；阶段测区分考试与练习，并说明练习模式下未作答题不进入错题本。英语阅读分精读、泛读、句级跟读、词义卡和报告；听一听分当前播放器、历史和早晚听计划。出处与时间点见[讯飞逐帧摘记](../research/interaction-library/artifacts/iflytek-video-controls-deepening/source-notes.md)，任务见[案例F01/16–18](../research/interaction-library/cases/M-027-iflytek-learning.md)。

这些视频有剪辑和换题，本次也是跳到指定时间看静态画面，没有连续完整观看、听音或操作设备。因此只支持局部任务重建：没有补造同题错答→提示→重试，也没有声称测试了录音保存、定时播放、离线或重启恢复。

几个会改变设计判断的细节：

- **难度与掌握是两种状态。** 数学图谱分别用形状、颜色表示。迁到Plus灰阶屏时，两种信息都要能辨认；图谱全绿只能证明产品显示完成，不能证明孩子长期掌握。
- **找到内容还不是完成任务。** AI找题之后有候选、挑选、取消和去作答；不能把模型回复当成题库已导入。跟读有评测句数，阅读有完成按钮，报告有计数，它们也不等于音频作品已保存。
- **撤销有明确范围。** Supernote V3.28.42手册的当前页20步撤销排除增删图层和更换模板；日历自动同步还要求授权和开关。可参考[模板、图层、文本框、整页移动与事件任务](../research/interaction-library/cases/M-006-supernote.md)及[原件摘记](../research/interaction-library/artifacts/supernote-notes-controls-deepening/source-notes.md)，不将历史修复日志当实测。
- **多档案、重置和清空不是同一承诺。** PocketBook手册列出按档案保存的阅读状态等对象，但没有证明文件或云账户隔离；恢复设置与格式化内存的清除范围不同。Scribble的新建和保存使用同形图标，资料仍有歧义。详见[借阅、档案、读屏、绘图及维护任务](../research/interaction-library/cases/M-003-pocketbook.md)。

上述都是研究依据和候选设计问题，没有新增已确认功能，也没有开始全系统设计。

## 怎样确保以后能重复使用

继续使用[按设计问题查证据](../research/interaction-library/design-reference-guide.md)作为入口。查“孩子答错后怎么办”“AI保存了什么”“重装后恢复什么”，再进入具体型号/版本的任务F、来源E、原页或视频时间点。相同任务补回原编号；新截图不被当作独立互证；矛盾和未观察分支留在结论旁。

本批新增15条局部D2任务、9条证据，补7条旧任务；其中讯飞原学习任务由D1补为局部D2。保存27幅必要视频摘帧、1幅型号目录图和10幅手册页。两份手册目录保留父子层级与旧覆盖状态，讯飞70项台账只更新已抽样的四项；其余30条功能视频和24条问题视频仍未观看。准确总量见[覆盖索引](../research/interaction-library/case-index.md)。

下一步真正需要补的是固定版本下的错误、取消、中断、恢复，以及5–6岁儿童实际操作和理解表现。公开材料没显示这些结果，就继续标未知，而不是把正常路径写长来冒充完整研究。
