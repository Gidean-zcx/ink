# 第五十六期：墨水屏怎样做到操作顺畅

2026-10-28。回应用户对墨水屏 UI 是否应沿用传统屏幕方式的提问。状态：研究完成，待硬件验证；本期随 Git 备份快照纳入；原工作区因磁盘不足尚未同步。

**建议保留现代操作习惯，重新设计动态反馈。** 下拉状态栏、返回与手势仍有价值；优先比较直接展开、分页/整屏步进、局部状态反馈和稳定排版。连续滚动与动画按场景验证，不一律禁止。

本次读取 E Ink、EPDiy、BOOX 官方说明与 Kobo 历史发布说明，并抽查 Plus 固定提交的绘制适配、刷新任务、波形与区域更新实现。Plus 已有独立刷新任务和不同状态的刷新策略可供参考，不能认为只有移植商业算法才能起步；代码存在也不证明达到 60fps 或无残影。

最关键的指标是操作何时被接收、何时首次可见、何时稳定可读、任务何时真正完成。框架 flush 回调不是光学显示完成；局部面积更小也不保证按比例更快。

建议优先比较：下拉面板直接展开/短预览，新闻分页/步进/滚动，AI 按字/按句分段。成人内容可连续准备而保持版面稳定；儿童用剧情、选择与听觉回应承载趣味，保留静音下的可理解反馈。动态 app 的更新意图由系统统一协调，是后续关键架构讨论点，尚未确定协议。
