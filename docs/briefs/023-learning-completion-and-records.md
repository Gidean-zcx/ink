# 第二十三期：学完、保存与恢复，是三个不同的结果

日期：2026-10-27。继续深化百词斩App、墨案和Bigme已有案例；均未实际操作手机或电子纸设备。重点是把可复用的路径、状态差异和证据缺口补回原任务，不以资料数量代表研究完成。

## 百词斩：学习结果与激励结果分别记录

本轮从官网帮助页引用的公开脚本找到匿名帮助正文，整理5类、50个唯一问题；其中11题属于爱阅读，单独标注。热门问题是重复入口，不重复计数。这比商店功能介绍更具体，但帮助未标版本或更新时间，不能直接视为当前App界面。[公开帮助](https://www.baicizhan.com/qa)

| 问题 | 官方帮助给出的具体区别 | 后续设计可以据此追问什么 |
| --- | --- | --- |
| 误斩单词 | 已斩列表进入编辑，再点目标词的“斩”恢复 | 恢复后回到哪种复习状态，是否影响既有学习记录？当前资料未回答，已斩也不能直接当成已掌握 |
| 离线学完是否已安全保存 | 下载词书与上传学习记录是两个步骤；帮助警示同步前清缓存可能丢离线记录 | 设备应怎样区分“本地保存”“等待同步”“服务器已接收”？ |
| 完成计划是否等于当天打卡 | 帮助要求北京时间当日结束前完成并上传；另建议在打卡页停留10秒以上 | 不宜让AI把等待时长当成保存成功；需要能核对的执行结果 |
| 补卡是否补上全部奖励 | 日历补卡不作用于小班及特定活动 | 学习掌握、连续天数、活动资格和奖励，应分别说明变化 |

这些是公开帮助的规则重建，不是本项目测试结果。新政策与帮助在个人信息删除等路径上有差异，按来源并列；未把旧帮助的“不支持”当成当前版本永久限制。日常学词的错答→提示→重试→结算仍未完整观察，主任务继续保持D1。详见[百词斩案例](../research/interaction-library/cases/M-016-baicizhan.md)与[逐题目录](../research/interaction-library/batches/baicizhan-controls-deepening-inventory.csv)。

对G-001的启发是：成就应能解释实际学到了什么。补日历、领铜板、恢复复习与提升掌握度不是同一件事。儿童可以获得容易理解的反馈，成人可以保持连续学习节奏；具体玩法尚未决定。

## 阅读设备：到达设备不等于进入书架

墨案2020年的官方指南明确区分蓝牙收到文件与加入多看书架；未加入时，书架不会显示。它没有标明硬件型号，因此继续保留为历史路径，不能拼入Plus现版流程。另一个移动文件指南的粘贴位置文字有歧义，已纠正此前过于确定的概括。[墨案案例](../research/interaction-library/cases/M-054-moaan.md)

Plus短说明书逐项登记了10章；2022作者的两张设备照片补出下拉快捷栏、普通/快速刷新及取消入口。照片只说明当时可见什么，没有证明切换后效果、默认值、重启保持或听书恢复。这里研究的是墨案inkPalm Plus，**与本项目CloudZao E-Ink4 Plus是不同硬件**。

对“AI帮我找书并导入”的启发：文件已传输、格式能解析、书库已登记、可以打开，以及阅读进度已保存，都需要各自的依据。它们的具体系统实现仍待后续设计。

## Bigme：设置作用于哪里，不能从名字猜

HiBreak Pro黑白版手册已按13章及正文控件建立目录。本轮新增普通文本/PDF排版任务：阅读Format菜单与系统E Ink Center分开，文本字号/间距与PDF缩放/裁边/旋转分开；是否修改源文件、按书保存、撤销或跨设备同步仍未知。[Bigme案例](../research/interaction-library/cases/M-011-bigme.md)

逐帧核对官网宣传GIF后，带TTS文件名的三帧实际是音乐、词典、字体样例，并未演示读听切换。官网“80FPS”公告列的是Pro Color、Dual、B7 Pro系列，不能当作本黑白版的功能，更不能证明E-Ink4 Plus实现60fps无残影。[图帧与范围摘记](../research/interaction-library/artifacts/bigme-controls-deepening/source-notes.md)、[官方公告](https://store.bigme.vip/blogs/news/bigme-s-biggest-firmware-upgrade-yet-hibreak-pro-color-hibreak-dual-b7-pro-series-push-fast-refresh-e-paper-up-to-80-fps)

## 以后设计时怎样复用

例如设计“离线学完后刷机恢复”，先从[横向问题索引](../research/interaction-library/comparison.md)找到学习记录与恢复，再进入具体案例的稳定F编号，查证据E编号、原文定位、版本条件和未验证分支。不要只引用本简报的一句话，也不要把“有下载功能”当作“有备份方案”。

本批目录与案例都已保留具体获取方式。静态宣传帧、作者设备照片、厂商手册、未标版本帮助及当前政策分别标注。全部产品仍是部分覆盖；完整主流程、当前版本和实机表现继续补证。没有改变已确认需求，也没有进入全系统设计。
