# 第三十二期：学习游戏怎样判错、结束与保留结果

2026-10-27。本轮补了Duolingo Chess的实际入门课，以及Quizlet四种活动和Anki三项旧任务的操作依据。重点从“有游戏化”推进到“什么行为被允许、何时判错、怎样重试、结束后留下什么”。

**棋课把自由探索与目标约束分开了。** 本次匿名网页先允许车绕路到无星格，再要求三步取星。限步题走错第一步后，立刻提示步数将不够、心数减一；继续后回同一初盘，可以看提示、再试并完成。前面的可绕路并没有自动沿用到后面的限步任务。这里有一条实际的“错答→解释→重置→提示→重试成功”链，详见[操作审计与对应画面](../research/interaction-library/artifacts/duolingo-chess-interactions/browser-operation-audit.md)。

这对儿童游戏策划有一个具体启发：当前任务的限制需要说清楚，不能让孩子靠扣分才发现规则变化。对AI也一样，它需要知道棋子能怎样走、这一题要求什么、孩子是否用了提示。以上是原型建议，不是已经证明适合本家庭的教学方案。

**不同游戏的成绩，衡量的是不同事情。** Quizlet官方帮助给出了以下循环，仍是文档依据、没有实际游玩：

| 活动 | 学习与游戏怎样衔接 | 一轮何时结束 |
| --- | --- | --- |
| Match | 词义配对，错配增加计时 | 当局六对配完 |
| Blocks | 放完三块后答题，答对取得下三块 | 棋盘无可走步 |
| Blast | 在移动目标中匹配词义，可调速度/选项/时长 | 计时结束比较得分 |

因此，配得快、棋盘分高、抢答获胜与隔天能独立回忆，需要分别验证。Blocks的答题换块可以作为一种候选，但也要检查孩子是否只想拿块、随意换题；帮助页没有回答这种实际使用问题。版本、资格冲突、退出与恢复缺口见[四类活动摘记](../research/interaction-library/artifacts/quizlet-game-modes/source-notes.md)。

**“学完”和“保存好了”需要不同依据。** Anki当日结束对应当前范围内应显示的队列耗尽；额外练习Empty可归还卡片并保留筛选，Rebuild重新按条件选卡。它不承诺原样还原旧集合。统计的一次回答也不等于一张新掌握的卡。见[结束与统计依据](../research/interaction-library/artifacts/anki-session-completion/source-notes.md)。

棋课最终确实出现成绩、每日任务与奖励，选择Later后返回课程页，刷新仍保留本次可见进度。但选择7天连续目标后的保存请求返回403，页面却继续向下走。这一项只能记为“选择与跳转已发生，保存未证”，不能由后续奖励页面替它背书。跨进程、换设备和正式账户恢复也没有验证。

本轮新增一条有限实际操作任务，其他补证保持文档等级。所有65组竞品仍部分覆盖。已把结果合回稳定任务编号，并新增[学习游戏设计参考入口](../research/interaction-library/design-reference-guide.md)；没有将这些游戏或奖励规则升级为产品需求。
