# 第五十五期：全局入口与执行环境

2026-10-27。Apple快捷指令原目录剩余46个主题已补正文，包含欢迎与版权；95主题现均有记录。原目录的正文覆盖完成，仍不足以证明全部App动作、设备或异常分支已分析。本批新增9条文档任务，深化10条旧任务，没有设备操作或图像观察。

对AI原生设备，这轮有六个可复查的交互区别：

- **唤起与执行条件。** Siri按指令名调用；锁屏且需要打开App时要求解锁。同名指令还会覆盖标准Siri命令，命名因此可能影响调用结果。
- **入口与执行环境。** 组件有进度、取消和补输入；部分动作需要转入主App。手表显示某任务，也不能证明所有步骤都能在手表完成。
- **页面上下文与共享内容。** 共享菜单受内容类型影响；网页能含图片，因此图片任务可能在浏览器出现。入口出现并不证明已经取得当前页全部数据。
- **提醒与自动执行。** 指令可放进提醒列表，但文档要求点提醒中的图标运行；提醒出现和任务执行是两件事。
- **移除与删除对象。** 从自动集合移除仍保留在All；删除自建文件夹可以保留内容，也可以连内容删除。AI需要明确动作影响的对象。
- **接回结果与真正写入。** 打开编辑器、预览、复制到剪贴板、交付副本、创建联系人有不同终点。联系人样例还存在变量引用疑点，不能直接当作已验证的导入程序。

研究也修正了一项旧结论：同版“从App运行”和“完成”帮助对编辑器外预览的描述范围不一致，已补回原任务及参考条目；保留差异，等待实际核对。日期转换则另记秒/毫秒、时区、地区格式、相对日期和显示精度的缺口。
