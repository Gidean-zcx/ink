# 第二十五期：答完、答对与保存

日期：2026-10-27。本期深化小猿 AI 手机软件、Viwoods AiPaper 和小猿学练硬件。当前资料已经能支持若干具体交互的比较，但**尚未深入每个产品的每个功能**，所有65组案例仍是部分覆盖；手机和电子纸实机操作仍缺。目录数量、截图数量都不作为完成率。

## 练习的“下一步”不能用一条通用规则概括

小猿 AI 的历史作者记录包含13种练习小节，本轮逐项重读并查看35张新静态拼图、复看3张旧图。比“支持识字、背词、智能纠错”更有用的区别如下；来源是2025年作者体验，构建未知，不能当当前版本实测。[原始体验文章](https://www.woshipm.com/evaluating/6214837.html)

| 设计时会遇到的问题 | 这次看到了什么 | 还不能下的结论 |
| --- | --- | --- |
| 孩子答错后怎么办？ | 口算正文报告可重写/跳过；中文听写提交后看正确写法再到下一项；单词跟读报告首次失败重试、再次前进 | 不能将一种题型规则套给其他题型；识别误判与知识错误如何分流仍未知 |
| 谁决定下一题？ | 竖式有显式完成；背单词有选择后提交、反馈后继续；另有作者报告的自动推进 | 静态图不能证明推进时间，也不能保证当前版本行为相同 |
| 完成就是掌握吗？ | 结果页可同时显示完成多项与仅部分答对；识字另有字卡，背词另有重练 | 奖励、最终正确率与首次正确率应分开；没有长期保持或迁移证据 |
| 提示影响成绩吗？ | 背诗报告把提示次数、错字、用时、分数分别展示 | 示例1次提示、99分不能推导扣分公式 |

题量、金币/经验、草稿撤销、退出确认、听写的声音/间隔/重复/顺序也已按控件登记。间隔不是语速；纸笔听写不等于自动批改。语文选择练习和练字挑战虽然有入口截图，仍缺错误与完成结果，没有强行扩成完整流程。

可复用入口：[M028任务案例](../research/interaction-library/cases/M-028-xiaoyuan-ai.md) → F02/05/06及F07–12 → [逐图摘记](../research/interaction-library/artifacts/xiaoyuan-app-controls-deepening/source-notes.md)。后续讨论儿童玩法时，可直接引用这些具体差别；是否采用字卡、排行榜或自动推进仍是候选。

## 编辑、返回和删除涉及不同的数据对象

AiPaper 本轮逐页查看旧官方手册68个静态页（PDF文件2–69，含目录页），补了手写选区编辑、快捷模板及Memo删除去向。选区复制、笔迹撤销、退出页面、删除快捷入口、删除关联文件夹是不同动作。阅读工具栏有返回按钮，也不能证明从AI对话回来一定还原原选区。[官方手册入口](https://viwoods.com/pages/user-manuals)

版本与文图差异保留：旧手册中Paper/Meeting密码分别管理，V3.15改为共用笔记密码；Apps正文说清缓存，截图却写Clear Data，清理范围尚不能确认。Memo章所述最多30天回收期限只适用于该模块，不能扩大为所有笔记/书籍。V3.12明确逐App刷新可独立或跟随系统，但保存、重启保持和实际显示效果未测。[V3.15说明](https://viwoods.com/pages/system-update-3-15)、[V3.12说明](https://viwoods.com/pages/system-update-3-12)

可复用入口：[M007任务案例](../research/interaction-library/cases/M-007-viwoods.md) → F01/04/09/11/18–20 → [手册页与范围摘记](../research/interaction-library/artifacts/viwoods-controls-deepening/source-notes.md)。这些是后续AI操作笔记和恢复设计的参考，不证明竞品开放了可供本项目调用的接口。

## 备份不能只找有没有“备份”两个字

小猿软件政策的个人资料副本条目给出“头像框→截屏”；硬件家长App政策给出副本请求入口。两者均未证明完整学习记录导出或可回灌恢复。政策所述后台备份延后删除，也不是用户拥有恢复按钮的依据。[手机软件政策](https://xyks.yuanfudao.com/common/mobile-privacy-policy)、[硬件家长App政策](https://solar-online.fbcontent.cn/megrez-online/megrez-gallery/megrez-resource/1a017eac33f2fb4.html)

同一集团部分服务免重复注册，不代表进度互通；两份政策均要求关联产品分别处理注销/删除。研究因此分开资料副本、学习记录导出、同步和用户恢复，不把这些合成一个“云备份”勾选项。

硬件S6/E1本轮仍没取得可核的完整手册或同型号连续操作材料，保留5条D1及注销局部D2。S6也收窄为已取得官网前端的条目，代际/固件未核定；不能用手机软件填硬件学习链。[M056案例与缺口](../research/interaction-library/cases/M-056-xiaoyuan-hardware.md)

## 后续设计时如何引用

先从[横向比较](../research/interaction-library/comparison.md)选择设计问题，再定位产品F任务、E证据、截图/页码和未决分支。引用的最小单元应包含“哪个版本/资料、哪个动作、什么结果、哪些还未知”。例如讨论“AI说孩子已经完成今天学习”，先查F-M028-02/10的完成与重练口径；讨论“删除后恢复”，先查F-M007-20的Memo范围，而不是引用品牌总介绍。

本批新增9条局部D2任务、27条证据，修订22条旧任务；没有新增产品操作。三份目录共723行，含章节、父项、控件与版本范围的重复/包含关系，不是723个已完成功能。全部登记量见[覆盖索引](../research/interaction-library/case-index.md)。硬件仍只考虑E-Ink4 Plus，需求未改，未进入全系统设计。
