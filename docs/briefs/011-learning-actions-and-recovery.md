# 第十一期：学习动力、动作结果与恢复粒度

2026-10-27。继续回应“竞品分析是否只停留在宣传页”：**此前确实偏功能发现，当前仍没有把每个产品的每个功能研究完整。** 本批增加真实网页操作、官方操作帮助和公开API契约；三种证据分别标注。65组产品仍全部是部分覆盖，数量与逐项深度见[案例索引](../research/interaction-library/case-index.md)。

## 从交互细节中发现什么

| 设计问题 | 本批依据 | 对本项目的意义与边界 |
| --- | --- | --- |
| 答错后，是解释、惩罚，还是继续尝试？ | [Duolingo F-M031-17](../research/interaction-library/cases/M-031-duolingo-adventures.md)：匿名法语网页首题错误后5→4心、给正确答案；翻译题悬停显示词义。Energy博文另述课程消耗和连对补充，本次网页未采用。 | 错误、使用提示、首次正确及学习资源应分开记录。不能仅因文章介绍新机制，就认为所有端一致；更不能把普通课规则套给Adventures。 |
| 想继续学，但现在不能播放声音怎么办？ | 同一网页听力题点“现在不能听”，提示15分钟后恢复，随后进入文字题；未等待核实到时恢复。 | 可研究临时输入/输出限制，而不把它当“不会这道题”。儿童纯听、读听切换与成人公共场合学习都涉及这一差别。 |
| 点了继续，能否认定已经学完？ | 本次最后一道文字回答正确后回到基础选择，没有观察到课末纠错、奖励或完成结算；原因未知。取消退出能回原题；第二次进入后确认退出也实际记录。 | AI要核对任务结果，而不只复述点击成功。[57状态与14张截图的审计](../research/interaction-library/artifacts/duolingo-controls-deepening/browser-operation-audit.md)保留异常及定位失败，不能称完整学习闭环已验证。 |
| “学习上瘾”应该奖励什么？ | [Duolingo F-M031-08～11](../research/interaction-library/cases/M-031-duolingo-adventures.md)：连续天数、月任务、XP排行、个人纪录分别运作；官方还描述修正反复刷容易课程的激励。 | 这些是活动与坚持的指标，尚不足以证明掌握和视野增长。成人可比较连续任务、主动专项和自然停点；儿童可比较提示、尝试和作品成就，具体采用哪种仍未决定。 |
| AI把单词导入后，怎样知道真的完成？ | [墨墨 F-M017-07](../research/interaction-library/cases/M-017-maimemo.md)：查询词ID、建立词本、加入计划和提前复习是不同方法；成功数量可能少于提交数量。今日学习数据还有初始化与同步前提。 | AI应分别报告收集、整理、加入和实际可学状态；“有API”不代表全页面可读，也不代表执行成功。本批只分析契约，未调用。 |
| 导出PDF能否防止刷机丢学习数据？ | [墨墨 F-M017-09](../research/interaction-library/cases/M-017-maimemo.md)：PDF采用本地内容，需明确保存，没有云端生成历史；不导出超级释义。故障扣次的两种文案范围未解释清楚。 | 内容副本、学习记录、可回导备份分别讨论；不能拿导出按钮替代恢复验证。账户与备份方案仍保持待定。 |
| 孩子说“继续上次的”，应恢复到哪里？ | [Tonie F-M038-13](../research/interaction-library/cases/M-038-tonie.md)：不同游戏分别按轮次、最后位置或检查点处理，移除游戏盘不等于统一秒点暂停；不同地区帮助措辞仍有待核差异。 | 先识别内容类型、游戏状态和恢复点，再解释将继续什么。未取得某款游戏完整判分/奖励链，不能凭控制器宣传补出玩法。 |
| 家庭共享与闹钟有哪些容易漏掉的前提？ | [Tonie F-M038-14～18](../research/interaction-library/cases/M-038-tonie.md)：日出闹钟有3+及充电条件，顶部Tonie正在播放时不响；Creative编辑权可按对象授予，实体公仔移交不自动转云端权限。 | AI的“已设置”需要包含生效条件；家庭成员、设备、内容对象和权益分别建模是候选方向。尚未确定本项目账户制度，也未实际测试响铃或家庭迁移。 |

以上是研究发现和设计问题，不是新确认的产品需求。Duolingo的公开社交功能对未满13岁有限制，不能直接作为本家庭5–6岁儿童的互动方案；匿名成人式网页观察也不能证明儿童可独立使用。

## 后续设计怎样反复使用

资料按“问题 → 产品任务F → 证据E → 适用条件与缺口”检索：

- [横向问题索引](../research/interaction-library/comparison.md)：先找学习反馈、读听恢复、新闻、AI执行或备份问题。
- [逐条功能与帮助目录](../research/interaction-library/inventories/README.md)：查看哪些入口已发现、哪些正文已读、哪些仍未分析；目录行数不是功能完成数。
- [任务覆盖表](../research/interaction-library/coverage.csv)及[证据索引](../research/interaction-library/evidence.jsonl)：稳定编号、来源日期、版本范围、正文定位、必要截图与操作日志。
- [剩余缺口](../research/interaction-library/backlog.md)：没有拿到完整目录、当前构建、失败分支或实机体验的地方继续明确保留。

本批修正了M-031过去只围绕Adventures的范围，现把主学习应用纳入同一产品，旧编号保留。新增64条证据、23条任务，补证8条旧任务；目录新增237行。数量只描述资料登记，本批3条网页操作任务也包含没有成功结算的分支。
