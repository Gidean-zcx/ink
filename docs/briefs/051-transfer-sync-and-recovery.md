# 第五十一期：传出、同步与恢复的不同后果

2026-10-27。本轮继续读QUADERNO两代官方手册的35页正文，补到从连接、选择文件到传输、删除和恢复的操作条件。没有设备或PC App实操。

最值得后续设计复查的是这些差别：

| 看起来相似的能力 | 手册给出的具体规则 | 对本项目的研究问题 |
| --- | --- | --- |
| 在电脑上打开／保存设备文件 | Gen.3C双击打开的是临时只读副本，退出PC App删除；传出另走取出路径 | AI怎样确认用户获得了持久文件 |
| 同步／备份 | Gen.2明确要求分开目录，否则备份可能被同步删除 | 当前内容一致与历史可恢复必须分别核对 |
| 恢复旧备份 | 会删除备份后新增数据，改变文件时间并重置浏览时间 | 恢复前需要说明哪些新资料和进度会受影响 |
| 删除／回收站 | 设备删除、电脑删除和同步删除的可恢复性不同 | “删除成功”要同时说清作用对象及恢复出口 |
| 已连接／已选设备 | Wi-Fi、PC服务连接和设备ID分别检查，休眠连接另有设置 | AI不能只凭网络图标判断能操作哪台设备 |
| 导入学习模板 | Gen.3C多页PDF只取第一页，加密PDF不可作模板 | 内容接收成功与用户预期的完整资料是两件事 |

全部结论可从[两代原页与步骤摘记](../research/interaction-library/artifacts/quaderno-file-lifecycle/source-notes.md)和[更新的产品案例](../research/interaction-library/cases/M-060-quaderno.md)复查。传输中断后加编号副本不等于续传；同步时间也不足以证明文件完整。相应缺口继续保留。
