## 从卖点深入到会影响设计的差别

| 笼统说法 | 本轮查出的具体条件 | 对本项目的研究问题（建议） |
| --- | --- | --- |
| 支持静音 | Tab系列帮助只说静音铃声/通知；静态图中媒体、闹钟另有音量 | AI执行“安静一点”时，应明确要改变哪个声音通道；不能仅返回“已静音” |
| 支持后台运行 | 冻结会阻后台及通知；移动手册的自启动还要求app自身支持、安装后先手动启动一次 | AI如何知道任务实际在运行、被暂停，还是被系统阻止？ |
| 支持投屏 | BOOXDrop配图注明暂不支持反向控制；Miracast和AnyDesk另有条件 | 看见屏幕、理解数据、执行动作应分别取证 |
| 支持录屏/高帧率 | 录屏30fps是示例参数；锁屏结束并保存只是设置文案 | 实际屏幕刷新、残影与文件保存需要各自验证 |
| 支持订阅与离线 | OPML导入的是来源；移动手册称网页首次联网加载后可离线 | 订阅成功、正文就绪、附件可用、读到哪里分别是什么状态？ |
| 支持阅读记录 | Calendar Memo按最后阅读/编辑日期列条目 | 打开、读过、读完、理解及掌握不能互相替代 |
| 支持云端文件 | 第三方云有显式复制上传步骤 | 云副本、双向同步、删除传播与可恢复备份须分别分析 |

这些判断对应RP-M004-01～10、RP-M010-01～02，已进入[可筛选的交互依据表](../research/interaction-library/reference-points.csv)。每条保留前提、动作、资料所述反馈、保存证据、未知分支、版本以及原件定位；文档描述不会写成亲自操作结果。

## 哪些没有被这轮材料解决

Note Air5 C仍固定V4.1.2基线，现行通用帮助不等于该构建的整册说明。部分文章明确属于Tab系列或其他具体型号；Work Profile和AI Assistant只注明部分机型。Palma资料封面是Mobile ePaper Series通用V4.0，文件名含Palma 2 Pro不能充当Palma 2专用证明。触摸手感、错误提示、中断、卸载后的数据和恢复过程仍缺实际记录。

相机扫描、InkSpire、专用键盘与后续Talk Insights分别保留适用性条件或排除，不增加本机能力承诺。NeoReader的选区问答也不能证明满足本项目G-002的全页面、全数据与跨应用操作要求。

## 后续怎样反复使用

从[按设计问题查依据](../research/interaction-library/design-reference-guide.md)进入，选符合场景的产品/版本，再读F任务、E来源、具体画面或日志及未证分支。按产品查漏则用原功能目录；不能只挑容易查到的卖点。简报负责传达发现，稳定任务和证据负责承接正式设计引用。

本次新增7条局部D2任务、25条来源记录，补10条原任务；原目录就地更新，不以正文阅读完成宣称全功能完成。新增12条直接检索依据，当前共68条增量查阅条目，仍非全库所有任务的状态表。数量及结构校验只检查资料一致性，不证明产品行为正确。没有更改既定需求，也没有据此确定接口、运行时、账户或新闻app方案。
