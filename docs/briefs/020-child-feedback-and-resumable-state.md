# 第二十期：儿童纠错、任务完成与可恢复状态

2026-10-27。本轮深化Britannica、微信读书和Meebook M7。此前的功能盘点不足以回答“孩子答错以后怎么办”“AI能否带我回到原文”“清后台会不会丢进度”。现在按具体任务记录入口、反馈、分支和恢复，但**仍未研究完所有产品的每个功能**。公开网页实操、文档步骤、版本声明继续分别标注。

## 儿童互动：完成四题以后，还有什么

在Britannica官方公开目录的Community Helpers预览中，本轮实际走完四条职业线索，并故意答错一次。过程是：读线索→从场景选人→答错后重试或回看线索→答对后看职业解释→下一题。四题结束先展示勾选回顾，再进入庆祝场景和联系自己社区的开放问题；没有观察到对这个开放回答自动评分。[官方预览入口](https://britannicaeducation.com/resources/britannica-school-early-elementary-content-catalog/)

这比“有游戏、寓教于乐”更能支持设计讨论：线索帮助作答，解释补充知识，回顾显示完成，开放问题尝试连接生活。它们承担不同作用，完成按钮也不能证明已经理解。我们没有儿童使用或学习效果数据；5–6岁能独立阅读中文，也不能据此推定能独立理解英文线索。

| 实际操作 | 观察到的结果 | 可以引用到哪里 |
| --- | --- | --- |
| 首题故意选错，再试与回看线索 | 可返回选人场景，也能重新查看本题线索，之后选对进入讲解 | 只支持这个公开活动的纠错链，不代表全部游戏规则。 |

以上为代理驱动桌面浏览器操作；动作、失败、截图和范围见[审计](../research/interaction-library/artifacts/britannica-controls-deepening/browser-operation-audit.md)，任务沿用F-M049-05。目录本身同时显示429错误，未取得文章列表，已停止该请求路径；这个失败单独记为F-M049-08，不用能打开预览来冒充目录正常。

## AI问答：回答、引用与返回需要分别核对

微信读书2024年官方技术文章描述了“搜索中提问→AI问书→回答及引用列表→点击定位资料片段”的路径；另有选文问书入口，可在界面内获得解释，未独立说明这条分支的来源跳转。三张历史静态图支持入口和来源列表的形态，但本轮没有执行点击，更没有验证返回问答或恢复原阅读位置。该文章未给App构建，不能直接当作当前版本行为。[官方技术文章](https://developer.cloud.tencent.com/article/2433150)

其固定提交的Skill说明还揭示了数据口径差别：笔记总数包含书签，单书内容导出不包含书签；不同列表需要不同分页条件。对于G-002，“能读统计”和“能读完全部内容”要分别判断；有接口说明也不代表实际调用、写回和恢复已经成功。[固定版本笔记说明](https://github.com/Tencent/WeChatReading/blob/d98e66ee60a8c7bcd35da549d0643c4470439643/skills/notes.md)

本项目后续可以比较“提问对象→引用位置→跳转结果→返回位置”这条链，相关依据见F-M013-01/04/05。这是设计问题，尚未确定AI协议或数据结构。

## 设备系统：配置入口与真实保留状态不同

Meebook M7的历史日志提供了长按按键设置、第三方App图标长按进入滚动优化，以及后续180°旋转等线索。但它们分属V1.5.2与V1.5.3；没有实机证据说明配置如何组合、App如何接收按键或当前版本是否一致。[销售商的分型号日志](https://ereader.co.th/firmware/)

快速指南中的任务清理和后台管理是两个入口，目前不能证明它们对未保存编辑、播放位置或重启恢复有什么效果。原PDF未取得，转录和型号元数据仍有疑点，所以保留D1/D2，没有因为新增目录就提升为实测。
