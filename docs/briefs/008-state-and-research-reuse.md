# 第八期：把功能名称拆成可复用的操作依据

日期：2026-10-26。研究阶段；没有开始全系统设计。

本期继续处理“有功能介绍，缺操作细节”的问题。重点是 Anki 的资料与学习状态、Kobo 的内容和手写、Ground 的信息选择控制、Espresso 的读听入口；同批音频补证见持续更新的[案例索引](../research/interaction-library/case-index.md)。这些材料能支持有边界的设计讨论，仍不能宣称已研究完每个产品的每个功能。

## 本轮最有用的差别

| 场景 | 取得的具体依据 | 对本项目的启发，尚未成为设计决定 |
| --- | --- | --- |
| AI 帮我更新题库 | Anki 的文本导入、共享包导入和集合导入有不同的匹配、合并或替换规则；内容更新与学习进度可以分开。见 [F-M020-04/05/19](../research/interaction-library/cases/M-020-anki.md)。 | “导入了什么、覆盖了什么、保留了什么”应有可检查的结果。内容版本和个人学习历史需要分别讨论。 |
| 今天再多练一些 | Anki 的过滤练习默认影响调度，关闭对应选项才按预览处理；达到今日上限不代表所有到期卡都已练完。见 F-M020-12/13。 | 区分临时加练、长期复习、今日负荷；不能从一句“再练一遍”直接推断要重排计划。 |
| 孩子输入答案后得到反馈 | Anki 能比较输入文本，但仍需使用者自评；答题次数也不等于练过的独立题数。见 F-M020-09/17。 | 比较差异、自动判题、提示帮助和掌握判断应各有依据。不能把输入框或统计数字当成完整学习机制。 |
| 少看一种新闻 | Ground 的取消关注、减少主题、移除媒体、自定义专题排除、全局筛选有不同入口和范围。见 [F-M046-07～10](../research/interaction-library/cases/M-046-ground-news.md)。 | AI 需要知道用户要改变哪个对象、持续多久，以及怎样改回；来源缩减可能同时减少观点范围。 |
| 保存下来以后读 | Ground 官方教程明确 Web/App 均不支持离线浏览；保存是回访入口。见 F-M046-02/E-GND-14。 | 收藏、全文保存、离线准备、阅读进度不能用一个“已保存”状态代替。 |
| 从短报切到听读 | Espresso 官方静态图显示阅读预计时间和音频总时长，两者不同；有听读入口，但未取得播放、暂停、结束及恢复的连续链。见 [F-M045-03](../research/interaction-library/cases/M-045-espresso.md)。 | 可以参考阅读预算和可选听读；目前不能据此采用其续播、队列或睡眠计时规则。 |
| 把书上的笔记都备份 | Kobo 的 EPUB 书内笔迹不能像非保护 PDF 笔迹那样导出；独立笔记本又有另一套同步和导出。见 [F-M002-14/17](../research/interaction-library/cases/M-002-kobo.md)。 | “笔记”不是单一数据类型；恢复书文件、笔迹和可编辑笔记本应分别检查。 |
| 软件支持朗读，我的设备就能用吗 | Kobo 的已购有声书与欧盟可选无障碍分支的 Read Aloud 是两条能力路径；分支有重置代价和特定版本限制。见 F-M002-18/22。 | AI 需要读取本机实际条件，不能把品牌宣传中的全部能力视作随时可执行。 |

成人版可以从这些依据研究更可控的练习负荷与新闻阅读范围。儿童版需要把复杂管理动作留在适合的入口，让孩子理解当前任务、求助和反馈；这属于本项目的体验建议，还没有观察孩子实际使用，也没有证据证明某种界面提高了学习效果。

## 一条功能记录现在包含什么

以 Anki 的“额外练一组”为例，资料已经拆到这些层次：

- **前置和入口：**牌组的 Custom Study，或 Tools / Create Filtered Deck。
- **操作：**设查询、数量和顺序，再 Build；符合条件的卡临时进入过滤组。
- **状态：**默认练习影响调度；关闭 Reschedule 时按预览处理。
- **例外：**停用、暂埋或已在其他过滤组中的卡不会纳入。
- **退出：**清空或删除过滤组让卡返回原牌组，不等于删除卡片。
- **未知：**取消后的全部提示、重进状态、预览练习历史口径和固定构建的实际行为。

定位为 **F-M020-12 → E-AND-11 → 官方 Filtered Decks 手册相应章节**，属于 D2 文档重建。后续设计可以引用这条依据，再明确我们采用或修改哪部分；没有证据的行为不能补成竞品事实。

## 防止资料越多越难用

维护三个入口：[按产品和任务查](../research/interaction-library/case-index.md)、[按设计问题比较](../research/interaction-library/comparison.md)、[按证据回到来源](../research/interaction-library/evidence.jsonl)。每个案例同时列主要功能域和缺口，避免只分析容易找到的几个卖点。

本轮审校发现三项补证与既有任务重叠，已合并回原编号：Espresso 的周度主题设置、文章听读入口，以及 Ground 收藏后的离线范围。因此，新来源和新图片不会自动增加任务数；后续仍查同一条持续修订的记录。具体修订见[核查记录](../research/interaction-library/verification-log.md)。

数量只表示登记规模。D1 是功能或静态入口依据，D2 是有文档支持的任务与分支；两者都不等于连续观察或亲自操作。当前 D3/D4 仍为零，完整功能总数也未核定，整体研究继续进行。

## 后续补充：儿童学习设备的数据与权限

讯飞旧型号帮助进一步说明：**更换故障设备、恢复出厂、退出家庭和删除孩子档案，会影响不同对象。** 其中，换机有按设备序列号移除、重新添加的步骤；删除孩子被说明为清除学情且不可恢复。另一个迁移帮助却建议跨家庭删除孩子再迁移，两处解释不足以保证数据保留，已保留冲突。[案例 F-M027-03/09～13](../research/interaction-library/cases/M-027-iflytek-learning.md)逐项列出条件；不能把这些旧型号规则当作 T30 Pro 的现行行为。

同一批材料还补出了“桌面看得到但当前孩子不能使用”“电脑传文件前要允许 USB”“家长端守护设置依赖设备端组件”等前置条件。这对系统 AI 的启发是：只知道应用名称和按钮不够，还要知道当前使用者、许可与设备实际状态。具体权限和账户方案仍待讨论。

为避免只挑容易读到的手册，另建了 [70 条帮助入口台账](../research/interaction-library/inventories/M027-help-inventory.csv)：T30 Pro 的 58 条视频教程只记为目录，12 条文字手册逐项限定型号。本轮读到旧型号流程，不代表已经观察 T30 的单题学习循环；这个缺口仍明确保留。

中文背词材料同样需要区分历史与当前：百词斩 2023 年官方公告曾将当时的深度模式用户迁回轻快模式，现官网仍有同名宣传；目前不能判定两者规则相同。[百词斩案例](../research/interaction-library/cases/M-016-baicizhan.md)保留这处冲突，并把历史查词收藏拆成原文、语境义、标记词表和收藏对象。原句是否一起进入复习仍未知，不能直接作为本项目的已验证方案。

儿童游戏方面，新增的 Duolingo Practice 路径支持回访课程内容，但没有证明恢复上一次未完成的对话；洪恩绘本的阅读入口和目标字也没有证明读听切换或页码续接。墨水屏手机补出了分屏、浮球、按键速记等局部动作，但通信打断和后台恢复仍缺完整链。对应缺口统一放在[后续取证表](../research/interaction-library/backlog.md)，便于正式设计时区分可引用依据与必须先验证的假设。
