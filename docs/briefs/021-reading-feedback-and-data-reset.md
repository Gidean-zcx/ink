# 第二十一期：读完、少推和清除——动作的实际范围

2026-10-27。本轮继续Espresso、今日头条和汉王N10 Pro二代，重点补此前薄弱的交互证据。新增材料来自历史亲历记录、机构指南、官方政策及型号使用文章；没有新增App或设备实操。

## “今天读完了”怎样表达

Espresso的2017年使用记录给出了较具体的路径：进入文章、滑动继续、出现完成勾，作者称七项之后显示结束页。三张实际查看的静态图分别支持列表勾、文章和末尾名言/分享入口，尚不能证明已读的触发条件，也不能套用为当前版本的行为。[作者原始记录](https://alearningaday.blog/2017/07/26/delight-to-use-and-the-economist-espresso-thinking-product/)

2025年更新的HKU指南样例图中，Today有短文、时长、部分红勾和Daily quiz入口，For you显示周长文卡。它补足了栏目和控件形态，却没有解释最后一篇后的状态、测验纠错或次日恢复。[机构指南](https://libguides.lib.hku.hk/espresso)

对我们的个人新闻产品，这形成了三个待讨论的问题：一期包含哪些内容，什么动作算读完，何时给出可以离开的明确反馈。历史结束页是一个可借鉴的例子；读完、理解和知识增长仍需分别评价。

## “不想再看到”对应不同操作

今日头条官方政策描述的控制并不等价：

| 操作 | 文档描述的作用 | 不能据此认定 |
| --- | --- | --- |
| 关闭个性化推荐 | 不再展示推荐频道，仍可浏览关注、热门、要闻等内容 | 关闭广告、清空浏览记录或获得完全无排序的信息流。 |
| 分别关闭位置、搜索、关注特征 | 对应信息不再用于个性化推荐 | 该信息从所有用途和存储中删除。 |
| 增加屏蔽标签 | 不再或减少推荐相应内容 | 永久、绝对过滤所有同类内容。 |
| 提高内容丰富度 | 尝试推荐常看范围之外的内容 | 信息必然高质量、观点必然全面。 |
| 清除历史阅读兴趣 | 清除已有兴趣及推测偏好，之后重新积累 | 永久停止形成兴趣，或删除全部操作历史。 |

这些是政策中的路径和效果声明，尚未用当前App验证。[官方政策](https://lf26-cdn-tos.draftstatic.com/obj/ies-hotsoon-draft/toutiaoGIP/5fb89857-7777-40b8-8105-989b87cdfb8f.html)

来源之间还有差异：较早规则的按钮路径含“永久清除”，随后又说重新积累兴趣；另一份未标日期的管理指引把删除范围写得更宽。本次把差异保留下来，没有选一句最强的措辞当作结论。对G-001，增加内容多样性、减少某类信息、关闭个性化和重置历史应分别比较；我们还没有确定采用这些具体开关。

## 页面和数据分别保留到哪里

头条的个人信息下载路径要求提供邮箱接收下载链接。文档没有证明副本包含完整正文、可回导的收藏或推荐状态，因此不能把“导出个人信息”当成刷机后恢复新闻App的方案。[同一政策7.2.2节](https://lf26-cdn-tos.draftstatic.com/obj/ies-hotsoon-draft/toutiaoGIP/5fb89857-7777-40b8-8105-989b87cdfb8f.html)

汉王同型号使用文章补到了中央键短按返回、长按刷新，以及灵动条的多个入口，但没有给出切走后的播放、编辑保存和重启恢复链。这些局部描述继续留在D1，不能因入口丰富就认为数据能安全接续。[型号使用记录](https://itsjzx.com/ai/44320)、[另一作者记录](https://zhongce.sina.com.cn/article/view/189952)

此外，Economist Pro的公开内容API说明：“当日”按接入时配置的时区判断，尚未发布时可返回前一日。这提示后续AI需要核对返回内容的日期；该API属于另一种合同授权服务，不能当成Espresso个人阅读状态的接口。[官方开发文档](https://developer.economist.com/docs)
