# 第三十五期：AI工作流、阅读状态与历史学习交互

2026-10-27。仍处于竞品研究。当前资料已经包含操作文档、源码、静态画面和少量公开网页操作，但**没有深入验证每个产品的每个功能**。本期补到具体输入、对话选择、写入对象和失败出口；工作流定义与真实执行结果仍分开。

## AI先筛资料，再带着学习：哪些步骤已经有参考

本期读完Readwise官方仓库固定提交的11份工作流/工具说明。它们供外部AI使用，与Reader原生Ghostreader的界面、权限和技能编辑分开。没有安装或执行这些工作流。[固定版本来源与冲突](../research/interaction-library/artifacts/readwise-ai-workflows/source-notes.md)

| 用户目标 | 具体交互依据 | 对我们有用的判断与未决问题 |
| --- | --- | --- |
| 帮我处理待阅文章 | 每批10篇，逐篇推荐，选择阅读/稍后/归档，需要时再取全文；一些简短肯定回应也会触发归档。 | 对话的回应与数据写入需要明确对应。“很好”是否代表读完，不能由AI随意解释。见Readwise F27。 |
| 给我一批值得看的新闻 | 分页取20篇未打开内容，从中选5篇；下一批会把当前整批标为已见，停止时汇总。 | 这能形成有限批次，但不保证来源多样；“没有被推荐”与“我已经看过”应分别研究。文件中下一批10/20及seen筛选的矛盾保留。见F28。 |
| 帮我巩固刚读的知识 | 选文后取正文/高亮，按篇幅设3/4/5题；问一题、等回答、给等级和解释，再继续，最后总评。 | 已有节奏参考；没有可重现评分量规、退出续答或题库写入证据。此流程不同于把高亮制成间隔复习卡。见F29。 |
| 按我的兴趣整理阅读 | 从历史抽样建立本地画像，展示摘要并允许反馈修改；另一工作流寻找跨材料的行为模式。 | 历史没出现的主题可能是尚未接触，不能直接成为排除项，否则会限制知识边界。画像并非系统账户。见F30/35。 |
| 帮我把资料变成成果 | 书评先选书、处理高亮、关联其他材料，再生成待编辑草稿并写回Reader；写入失败输出Markdown及已完成部分。 | 可以借鉴“已生成”和“已保存”的区别；重复重试、确认与撤回仍缺。关系图和阅读网页是另两种本地产物，没有自动发布证明。见F32–34。 |

具体任务、输入/结果和未验证分支在[Readwise案例](../research/interaction-library/cases/M-015-readwise.md)。原有泛化外部AI条目补为接入/工具文档链；不同目标的工作流分别索引，避免把所有行为塞进“支持AI”一项。

同一句“done”在逐篇筛选中表示归档当前文章，在订阅追读中表示结束整轮。这个差别说明，研究系统AI时还要记录当前任务阶段与动作范围，单有自然语言按钮名称不够。订阅工作流用first_opened_at筛选、写入却改seen，两字段是否联动及重启后是否重复处理仍需验证。

## 不能把统计字段直接当成学习事实

同一套公开工作流里就存在不同口径：回顾按更新日期选归档/稍后内容，且把没有高亮或笔记的文章归为未参与阅读；阅读网页则按进度阈值分类，并用最后打开时间绘热图。它们是工作流作者的处理规则，不能证明读者实际读完、理解或在每个日期都读过。

后续设计应讨论如何区分**出现过、打开过、主动略过、读完、做过练习、独立掌握**，以及哪些来自真实操作、哪些由AI推断。这里提出研究问题，尚未确定数据结构或评价算法。具体反例见[来源摘记](../research/interaction-library/artifacts/readwise-ai-workflows/source-notes.md)。

## 儿童学习：补到了历史文字链，当前设备仍缺连续证据

找到同一作者2024年两篇小猿样机报告：课内练习提交后批改，错题订正再交；首次全对与订正全对评价不同，点数可换课外书。作者也报告减号误判。后续文章给出互动阅读内的听书入口、调速、进度和定时控制。[原报告](https://post.smzdm.com/p/a3x3nk5d/)、[后续报告](https://post.smzdm.com/p/a4x56p6x/)

这些能支持历史任务的文字分析，**不能套入当前S6/E1**：样机型号和固件未核，两篇也不是独立验证。三条内嵌短片共查看九个时间点，只看到讲解、题面和诗文，没有同题错答→提示→重试→结算。正式保留代表帧及具体时间点，见[小猿历史证据](../research/interaction-library/artifacts/xiaoyuan-historical-learning/source-notes.md)。

对儿童版最值得继续核验的是：系统认错孩子的答案时，孩子能否纠正；借提示通过与独立答对是否分开；听到一半退出或换孩子后能否找回。奖励数量和复练次数本身不能证明学习收益。
