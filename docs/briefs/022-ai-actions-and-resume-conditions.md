# 第二十二期：AI能做什么，退出后留下什么

2026-10-27。本轮继续Gemini、Palma 2和掌阅App。重点是操作的作用对象、权限、结束和恢复；帮助正文与通用手册不能证明当前设备的运行效果。全部案例仍部分覆盖。

## AI接入需要拆到具体动作

Gemini的Messages连接器可以起草、修改和发送消息，却不能直接读取完整消息库；通知中的读写交给Device assistance。断开Messages，也不必然撤销Google的通讯录权限或另一项通知能力。研究“AI能操作短信”至少要区分这些对象与路径。[消息官方帮助](https://support.google.com/gemini/answer/15574940)

Phone连接器又涉及两个层次：先按同联系人上次使用的通信应用选择，进入Phone后使用系统默认拨号应用。帮助没有给出接通确认、失败重试和重复拨号处理，不能把自然语言请求直接等同于电话已接通。[电话官方帮助](https://support.google.com/gemini/answer/15575143)

自定义应用支持通过MCP地址接入，Web负责添加，手机可以使用已连接服务。文档分别列停用、解除账号授权和移除入口；解除后仍留目录，移除同时解除授权。具体写入确认、取消和部分执行仍待观察，当前地域、年龄、语言和账号条件也限制了直接使用范围。[自定义应用帮助](https://support.google.com/gemini/answer/17209137)

这些差别支持一个研究判断：G-002需要同时核查数据可读范围、动作支持范围和真实结果；一个“支持AI”的标记不足以判断完整覆盖。协议和具体实现仍未定案。

## “继续”可能恢复不同的状态

Gemini Live文档给出以下区别，均未实际操作验证：

| 操作 | 文档中的状态变化 | 后续仍需核查 |
| --- | --- | --- |
| Hold | 暂停会话，关闭麦克风；可点Live接续 | 断网和进程终止后的恢复。 |
| Mute | 麦克风静音，会话与输出可继续；屏幕/视频可能继续共享 | 用户是否能清楚辨认仍在共享。 |
| End | 结束Live，回看文本记录，旧会话可再进Live | 返回会话不证明全部外部任务仍存在。 |
| 暂停或锁屏时的屏幕共享 | 停止，恢复对话后仍需重新开启 | 重新共享后的上下文是否更新。 |
| 撤销应用动作 | 前台可Undo；后台及三星应用有例外，需到目标App编辑 | 时限、复合任务和部分成功。 |

[Live官方帮助](https://support.google.com/gemini/answer/15274899)还区分摄像头因暂停、离开App、锁屏而关闭后的恢复规则。由此得到的候选问题是：恢复入口应说明恢复的是会话、媒体还是外部动作，不能只给一个含义不明的“继续”。该判断不等于已确定本产品界面。

Palma 2相关资料也提醒我们区分系统睡眠与播放器状态。本次取得的PDF虽然下载文件名包含Palma 2 Pro，封面实际是Mobile ePaper Series通用V4.0手册。其Power页分别设置Wi-Fi、蓝牙和睡眠后音频，静态示例音频为Pause；正文给出继续蓝牙在线播放的条件，仍不保证Palma 2当前固件或TTS逐句断点。[原PDF](https://ebookreader.dk/images/upload/Onyx%20BOOX%20Palma%202%20Pro%20User%20Manual.pdf)

## 明确保留资料不足

掌阅手机App的选区、听书、AI书童与导入后恢复，仍缺足够的入口、反馈和结束链。Huawei提供的掌阅墨水屏版FAQ能支持部分刷新、模式和显示问题排查，适用对象是MatePad Paper，不能移植成iPhone操作说明。[Huawei官方FAQ](https://consumer.huawei.com/cn/support/content/zh-cn15939571/)

遇到这些缺口，保留“未核实”比用常见App交互补齐更有参考价值。没有找到操作资料，也不等于该产品没有相应能力。
