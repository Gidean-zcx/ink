# 第三十三期：家庭听书、语音控制与内容准备

2026-10-27。本轮把Audible既有Listening首屏中22项“只有目录”的帮助推进到正文，另补书单的直接打开正文；Yoto补RSS/音频流导入，Toniebox 2补播放对象、下载和排错。所有新材料仍为文档依据，没有设备或App实测。

**家庭共享不能替代每个人的进度管理。** Audible允许一个Kids Profile供多个孩子在不同设备同时听，但要求换设备时重新定位，同一设备上的语速还与成人档案共用。内容访问、个人位置和设备设置有不同归属。删除儿童档案会失去其历史，成人书库原书仍在；重新建立档案需要重新共享。这个案例可以帮助我们讨论成员档案与备份范围，不能直接决定本项目采用哪种账户制度。见[儿童档案与恢复任务F15–17](../research/interaction-library/cases/M-039-audible.md)。

**“语音操作”和“系统原生AI”有明确差距。** Audible内置Alexa可选书、续播、跳章和设停播计时，但要求App在前台；锁屏或进入其他App后不能响应。Maven则主要提供找书、比较和概述，帮助说明可在24小时内恢复对话，没有证明能执行全库修改、导入或跨App任务。我们需要逐项研究语音入口、当前上下文和可执行动作，不能从“有AI”推断G-002已经满足。见[F20、F29及平台边界](../research/interaction-library/cases/M-039-audible.md)。

**同一个“分享”按钮，可能改变完全不同的东西。**

| 动作 | 文档支持的结果 | 不能据此认定 |
| --- | --- | --- |
| Audible分享书籍推荐 | 发出书籍详情，收件人自行决定取得内容 | 对方已获得完整收听权 |
| 共享到Kids Profile | 授予该儿童空间可访问的合资格书目 | 已下载、另端立即更新或位置独立同步 |
| Goodreads书架接入 | 匹配可用音频版本，增删仍在Goodreads完成 | 每本都匹配正确，或隐藏等于解除所有关联 |
| Yoto导入RSS并绑卡 | 获取节目名/集列表、保存，再把入口关联到MYO卡 | 内容已完整下载、可离线或已保存故事断点 |

细节与异常分别见[Audible任务](../research/interaction-library/cases/M-039-audible.md)及[Yoto F20](../research/interaction-library/cases/M-037-yoto.md)。这些对象差别会影响AI应向用户报告“已经完成”的哪一步。

**退出入口不一定停止后台工作。** Toniebox 2官方帮助明确：取走游戏盘后，下载仍继续；普通故事只需首章下载后就可开始，游戏则需完整下载。另有快速换公仔导致播错内容、过早放公仔阻止同步等排错描述，但未证明重启后的故事断点。这些分支已回写[F09、F11、F12](../research/interaction-library/cases/M-038-tonie.md)，没有将建议步骤当成恢复成功。

**持续听与真正学到东西仍需分别衡量。** Audible挑战以分钟或完成本数计进度，开始后不能修改目标；收听提醒则是指定书籍的通知，不是到点自动播放。对成人“持续学习”和儿童故事体验，我们可以比较目标能否调整、有没有明确终点、哪些记录可用于回顾；分钟、徽章和理解收益不能合成一个指标。
