# 第五十七期：墨水屏刷新算法与直驱方案

2026-11-02 归档。研究于 2026-10-28 在公共会话完成，用户随后将会话移入本项目，并要求保存全部过程与成果。

状态：仿真与指令级估算已完成，待硬件标定与实测。

**结论：在 Plus 上，绕开 EPDiy 的全局锁、自己逐相驱动，是兼顾跟手与清晰的可行方向。** 在同一面板模型下，异步驱动把点按后达到 50% 可见的平均时间，从现架构 DU20 的 136 ms 降到 48 ms，回到初始画面后没有残余直流。

## 算法怎样演进

1. **起点：PaperBoy 的计数器驱动。** 它在颜色翻转时清零计数，直流随内容无界累积。
2. **积分器驱动与物理量化器 PQ。** 研究把刷新抽象为“像素只能到达有限状态”的量化问题，由此得到这两种方法。
3. **PQ-BN。** PQ 依靠误差扩散，无法并行，因此改为每个像素独立地用蓝噪声在可达状态之间选择。
4. **v4。** 为压低算力与存储，最终版采用规划/执行分离。

## v4 的开销

单核 RV32 估算，每 12 ms 相的耗时如下：

| 场景 | 每相耗时 |
| --- | --- |
| 静止页 | 0.32 ms |
| AI 出字 | 1.15 ms |
| 翻页 | 6.38 ms |
| 全屏快速滚动 | 平均约 9–12 ms，最坏约 22 ms，需双核 |

- 全屏快速滚动时，驱动按区域自动切入二值运动渲染。
- 存储为每像素 2.5 B，SRAM 约 51 KB。
- 应用和 LVGL 不需要选择刷新模式。
