### 复核方法

- **对象**：main 3226d53。审计冻结在 42cd986，之后又合入了 81194d8（第 0 步实机记录）、d17e934（按实测改档案）、3226d53（I-040、D-41），所以每条都按最新代码重跑。

- **环境**：用户的 Mac（Apple clang 17，arm64）上的模拟器和主机小程序，不接触设备。macOS 上主机栈估算会让 16 项场景报警告（已知，[平台与模拟器 §5.7](../system/platform-and-simulator.md)）。判断预算时只排除这一条警告；改动另在 clang 的 `-Werror` + ASan/UBSan 下跑过。最终以 GitHub Actions 的 Linux CI 为准。
- **证据类型**：
  - 【模拟复现】在模拟器或主机小程序上跑出来的，不是实机；
  - 【代码核查】读代码确认；
  - 【文档核查】对照文档；
  - 【推断】没有验证的推理。
- **范围**：审计报告称按用户后来的指示排除了 I 部分（安全、隐私、合规），本复核没有补做。
