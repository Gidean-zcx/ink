# 成人与儿童：学习动力、游戏互动与连续体验

## 用户意图与初步判断

用户要求研究“学习上瘾”，分别考虑成人和儿童：儿童参考学习机的成就、游戏互动与游戏策划；成人参考头条、抖音等。随后明确核心目标是将原来刷消遣 app 的时间转成高价值信息获取、知识与能力增长。保留“学习上瘾”这一原始表达；本轮暂以“容易开始、愿意主动回来、学有所获”作为可验证的体验解释。

- **有依据可行**：角色任务、成就反馈、自主探索、短单元与持续推荐都有现成产品模式。
- **有条件可行**：将这些机制转化成长期学习收益；需要合适的内容、难度、反馈和复习，不能仅以打开次数判断。
- **信息不足**：对本家庭各年龄的有效组合，以及是否真的替代原手机消遣时间。目前不承诺必然养成习惯或提升成绩。
- **当前约束下不建议**：直接用停留时长最大化作为目标，或让核心学习过程必须依赖未经验证的 Plus 全屏 60fps。

成人、儿童需要两种体验研究；不据此认定成人都讨厌游戏，或儿童都需要高密度奖励。年龄、阅读基础与个人偏好决定具体引导。

### 家庭信息补充：5–6 岁，可独立阅读

2026-10-26 用户补充：孩子识字能力可以，能够独立阅读，有听书功能会更好。来源为用户答复，见 [I-020](/home/workspace/reader/docs/ideas.md)。以下是据此调整的候选体验，未新增学习效果证据：

| 方式 | 候选体验 | 需要保持的连续性 |
| --- | --- | --- |
| 自主读 | 可以自己读故事、任务线索和简短说明；需要时听一个词句或让 AI 解释。 | 求助后回到原来的段落或任务。 |
| 纯听 | 自己选故事、暂停、继续；允许完整享受故事，互动问题按意愿开启。 | 保存具体内容、版本和播放位置。 |
| 读听切换 | 从当前段落开始朗读，或暂停后继续看文字。 | 精确切换需要文字与音频的定位对应；真人音频与不同文本版本不能默认逐句对齐。 |

游戏原型可使用文字线索、路线选择、物品分配和简短推理。阅读难度、数学水平与英语基础分别了解，不由年龄和能独立阅读自动推定。成就仍可围绕独立读完、解释清楚、解决新问题展开。

听书与续播已是 R-018；点字朗读、逐句跟读、同步高亮和发音评分不是本次自动新增的要求。系统 AI 可研究“刚才那句话是什么意思”，先定位当前读/听内容，再解释并返回原处；这些行为仍需验证。相关定位问题见 [读听与故事断点](/home/workspace/reader/docs/research/ai-native-platform.md)。

## 研究依据能支持什么

| 依据 | 原始材料的发现 | 对本项目的启发与限制 |
| --- | --- | --- |
| Ryan、Rigby、Przybylski，2006，四项电子游戏研究 | 自主感、胜任感等与游戏享受、偏好及继续玩意愿相关；多人社区研究还涉及关系感。 | 让学习者能选、能理解进步、能与他人合作。研究的是游戏体验，不能直接证明儿童学习成绩会提高。[论文原文](https://selfdeterminationtheory.org/SDT/documents/2006_RyanRigbyPrzybylski_MandE.pdf) |
| Sailer、Homner，2019 在线发表／2020 卷期，游戏化学习元分析 | 汇总结果在认知、动机、行为指标上有正向效果；高方法质量子样本中，动机与行为效果较不稳定。 | 有理由探索，但需分别测掌握与参与；不能把一种徽章或剧情的效果推广到所有年龄和学科。[论文](https://link.springer.com/article/10.1007/s10648-019-09498-w) |
| Karpicke、Roediger，2008，外语词汇实验 | 在该实验中，初次答对后的重复提取改善延迟回忆；继续重复学习没有同样效果。 | 学习内容需要回忆、作答与后续检验；“看过、觉得懂”不足以判掌握。实验不是所有学科、所有练习比例的通用证明。[论文摘要](https://doi.org/10.1126/science.1152408) |

以下原型由上述依据和竞品启发推导，不属于论文已验证的方案。心流、习惯和长期掌握分开观察，也不用“多巴胺设计”代替可检验的机制解释。

## 成人与儿童两版候选体验

本节为助手建议，尚未选定产品形式。

| 维度 | 儿童版候选 | 成人版候选 |
| --- | --- | --- |
| 开始 | 从一个故事任务、好奇问题或可选角色进入。 | 从想学的主题、考试目标、昨日进度或当前新闻进入。 |
| 核心操作 | 找字、听音、分配、排序、选路径、解释给角色听；按阅读能力提供语音。 | 阅读短解释、主动回忆、作答、举例、推演；随时展开原文和长解释。 |
| 难度 | 遇到困难先换例子或拆成小步骤，完成后减少辅助。 | 结合目标、前置知识、错因与自报难度调节；可切换连续练习或完整模拟考试。 |
| 即时反馈 | 操作带来可理解的结果，例如分配后大家是否同样多；提示允许重试。 | 给出结果、错因与下一步；用户可选择立即解释或一组结束再看。 |
| 成就 | 能读懂一个小故事、独立解开一个谜题、向家人讲清楚；可收集作品或章节。 | 能独立解决一道新题、看懂一篇新材料、完成一个小项目；展示能力变化。 |
| 自主选择 | 引导路线与自由探索并存；孩子可以换题材、求助、暂停。 | 自选目标、来源、节奏和深度；一键标记太易、太难、已会、暂不想学。 |
| 连续性 | 一个小章节有收尾，之后可明确选择继续；下次恢复故事和学习进度。 | 少切换页面，下一步准备好；阶段总结后可继续一组，暂停不丢状态。 |
| 社交 | 可选亲子共同解谜、讲给家人听。 | 可选共同目标、交流或自我比较；不预设必须排行竞争。 |

“太难”“今天没空”“不喜欢这个题材”“这部分已会”应成为不同反馈。直接把跳过都解释成不喜欢，会把有价值但较难的知识逐渐排除。答得快、看得久也都不足以单独推断掌握。

## 按游戏策划拆，而不只列奖励按钮

| 设计层次 | 要回答的问题 | 候选例子 |
| --- | --- | --- |
| 单次动作 | 学习者实际做了什么认知活动？ | 用已学字辨认路牌；将数量分成两组；从记忆中说出词义。 |
| 一段任务 | 为什么愿意完成这些动作？ | 给角色送对包裹；准备一次旅行对话；解释新闻中的一个原理。 |
| 难度进阶 | 新一关到底增加了什么能力？ | 从图物对应，到少提示，再到新场景；检查前置知识后再增加复杂度。 |
| 长期进度 | 怎样感觉自己正在变强？ | 可独立阅读的文本变长、可处理的问题变复杂、可完成的作品增加。 |
| 再次回来 | 为什么明天还想继续？ | 对后续任务有兴趣，知道下一步，能轻松恢复；复习内容确实值得再练。 |

建议把知识应用放进关卡的关键操作，并设置一次脱离游戏表面的迁移检验。单纯答题换装饰可以作为可选反馈，但不能替代学习过程。故事里的虚构与百科中的事实需明确区分。

连续天数、积分、徽章和排行榜可以研究；本轮不直接采用限时抢奖励、掉队惩罚或随机大奖。依据是 G-001 所要求的时间收益和主动学习：每个机制都要说明它改善了哪一种学习行为，是否让停止与恢复变得更困难。

## 成人怎样参考头条、抖音

推荐研究可拆为三件事：怎样少做操作就能开始、怎样决定下一个内容、怎样让反馈影响之后的选择。我们建议逐项评估：

| 可参考的机制 | 在学习中的候选改法 | 判断是否有效 |
| --- | --- | --- |
| 快速进入一个内容 | 打开就能继续上次任务，或开始一个清楚的小目标。 | 减少寻找和准备时间，同时保留选题权。 |
| 单元衔接与预取 | 在一段解释、回忆题、应用题之间连续切换。 | 少等待、少跳转；不把长知识链切碎成无关联卡片。 |
| 行为反馈 | 同时看作答、提示、错因和主动反馈；时长只作辅助。 | 下一题更合适，后续掌握有改善。 |
| 兴趣推荐 | 以目标、已掌握知识和前置关系约束内容选择。 | 兴趣提高启动意愿，课程仍有结构。 |
| 探索陌生主题 | 用户可调的跨主题发现，说明与已有知识的联系。 | 认识新领域并能深入，不只换一种刺激。 |
| 连续浏览 | 支持自愿继续，提供任务终点和可恢复进度。 | 使用者能按计划结束，也愿意下次回来。 |

不设一条把所有目标加成“停留分数”的公式。学习主题推进、考试练习和新闻获取可有不同的选择规则；长篇理解、推理题和完整考试也需保留各自节奏。

## 原型例子与候选池

两个例子只是供讨论的任务脚本，不是完整游戏或课程设计：

- **儿童“森林邮局”**：听任务 → 读路牌中的目标字 → 将包裹按数量送达 → 听到角色针对错误的提示 → 用不同路牌再认一次 → 存下本章。可通过静态图、语音、点选/实体键成立，动画是额外表达能力。

## 将来如何验证，当前不开展实验

建议先用可比较的小原型观察，不能凭家庭少量样本声称普遍有效：

1. **时间转化**：是否减少原手机消遣、是否只增加了另一段屏幕时间；可从自报与已有时间统计开始，尚未要求收集其他手机的数据。
2. **主动性**：愿不愿意自己开始、是否需要反复催促、是否能安心暂停。
3. **学习收益**：隔一段时间能否回忆、换一道题或情境能否使用；记录使用了多少提示。
4. **探索收益**：是否主动问出新问题、读过并理解陌生主题，而非只多打开几个分类。
5. **成本**：等待、误识别、刷新、准备内容耗时，以及为了奖励而重复最简单任务的现象。

当前家庭年龄已明确为 5–6 岁；具体测量周期、指标阈值和内容难度仍未定。Plus 上需分别验证静态/局部刷新、音频、输入和内容缓存；先建立候选体验，不把高刷、完整动画或任何商业课程包当成现成条件。
