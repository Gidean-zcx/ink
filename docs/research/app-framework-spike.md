# 应用框架单页实测

2026-11-05；产品基线 `39a349d`。选择 C＋LVGL、受限 JSON、Lua 5.4.8，三者共用现有 LVGL 9.5.0、系统 UI 任务、能力表和文字输入服务。原型在 [tools/appfw-spike](../../tools/appfw-spike/README.md)，没有进入产品或默认构建。

**【实测H】统一环境**：macOS 15.7.9 / arm64、Apple clang 17.0.0、`RelWithDebInfo`（`-O2 -g -DNDEBUG`）、`INK_WERROR=ON`；同一 Plus 档案、684×1216 逻辑屏幕、32px 现有字库。CPU 型号读取被沙箱限制，记录到 arm 架构。表中每个“【实测H】”都使用此环境；内存取确定性轮，时间取五次 `--cpu measured:1` 的中位数（括号为最小～最大），ASan 数据单独存档。

【实测H】三个页面逐像素相同；每个候选两轮确定性指标完全相同，每轮 20 条主检查通过，JSON 另有非法描述反例，Lua 另有模块隐藏、循环中断、配额和非法行反例。触摸和 AI 的 JSON 调用都进入 `spike.set`；文本框走 `text.insert/submit`，底部按钮走 `spike.submit`，关闭页面后模型与 VM 的分配均释放。这里的能力只操作合成页面数据，不持久化产品设置。

**读数边界**：计时通过模拟器结算宿主线程 CPU，倍率为 1，并保留调度／固定时间成本；没有 S31 换算依据，不能推导真机速度。初始化包含共同模型分配；C／JSON 没有 VM，其入口读数接近计时开销。建页不含首屏绘制或波形；开关不含触摸传输、排队或光学反馈。整轮堆包含共享系统、字库、键盘及测试任务，标签峰值不相加；对象尺寸仍是宿主 64 位，不是 RV32 的实际占用。

代码行数保留空行，共同 C／头文件为【实测H】346 行；Lua 的第三方 C 来自【实测H】32 个编译单元，不代表最终链接大小。AI 读按紧凑 JSON 快照，写按完整 `candidate_c.c`／`page.json`／`page.lua`；接口说明、提示词、manifest 和 token 不计，没有调用真实 AI。源文件、哈希、全部计时样本和口径见[普通记录](../tasks/appfw-spike/measurements.json)、[内存检查记录](../tasks/appfw-spike/measurements-asan.json)及[工具说明](../../tools/appfw-spike/README.md)。

**E1【实测环境检查】**：ESP-IDF 检出为 v6.1；加载 `export.sh` 时提示缺少它要求的 Python 虚拟环境，随后找不到 `idf.py`。本轮未安装全局环境，未生成目标 ELF，也没有用本机二进制大小替代。复现：`bash -c 'source "$HOME/esp/esp-idf/export.sh" && command -v idf.py && idf.py --version'`。

**结论：有条件可行。** 同一能力和快照桥能承接三种写法，JSON／Lua 在这个样例里减少了页面输入字符；新桥、运行时和权限维护仍有成本。这组宿主微秒差距不足以选定脚本赢家，也不能确认 SP-08 的 S31 资源目标。此次按任务书的候选上限没有量 MicroQuickJS；后续仍按设计第 8 节验证。

**只有真机能回答**：现有系统与驱动并发时的真实内部 RAM 余量、PSRAM／Flash 缓存停顿、GC 对音频／显示的干扰，以及触控、残影、稳定可读时间和耗电。S31 静态大小只需补齐编译环境，不需要碰设备。

复现本表：`bash tools/appfw-spike/run.sh all`。普通／ASan 运行、全部检查与配额反向对照见[验收报告](../tasks/appfw-spike/REPORT.md)；所有构建最多 `-j4`，全量测试最多 `-j3`，没有启动带窗口的模拟器。
