# PQ-BN v4 在本仓库 ISS（ESP32-S31 模型）上的重测

条件：研究的全分辨率场景（1216×684，每 3 相一帧 UI），前 60 相；plan_budget 8000、auto_motion、每像素状态与帧缓冲在 PSRAM（经 D-cache），表与 tile 状态在内部 SRAM，代码在 flash；ESP-IDF S31 编译选项 -O2。拟合 = 本仓库校准的时序（CoreMark 3.08/MHz、PSRAM 按 P4 实测拟合），慢角 = 偏慢核参数 + 按 S3 实测拟合的 PSRAM。
