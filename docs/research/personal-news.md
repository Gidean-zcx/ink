## 已明确的意图

用户将个人定制新闻 app 列为重要功能：减少当前智能手机 app 对碎片时间的争夺，避免认知边界被推荐系统限制，回到传统新闻获取方式，或获得个人偏好的高价值推荐，避免娱乐化、低价值、廉价信息填充。儿童可能有对应的儿童新闻或百科。

个人新闻已是明确需求；儿童版本是探索候选。用户并未否定推荐本身，传统报纸式阅读、自选订阅和个人推荐可继续比较。是否每日一期、是否听新闻、是否有自动通知都尚未决定。

**有依据可行**：订阅、编辑简报、去重、多来源对照、分级儿童内容均有产品参考。**有条件可行**：在 Plus 上做个人新闻与 AI 延伸学习，需要可用来源、内容准备、缓存和统一 AI 接入。**信息不足**：个人“高价值”的具体标准、中文来源覆盖、付费内容接入方式，以及长期扩大视野的实际效果。不能承诺一个算法彻底消除信息茧房。

## “高价值”需要一套可解释的选择标准

以下是可讨论的维度，不是已训练的评分模型，也不假设 AI 能自动判断一切价值：

| 维度 | 候选判断方法 | 需要防止的误读 |
| --- | --- | --- |
| 证据与来源 | 是否有原始材料、可追溯出处、清楚的事实与推测区分；更正是否可见。 | 多家转载同一稿不能算多份独立验证。 |
| 个人相关性 | 与明确关注的主题、学习目标、生活决策有哪些关系。 | 偶然长时间停留、看过冲突内容不自动变成长期偏好。 |
| 公共重要性 | 影响范围、持续性、对理解社会与世界的作用。 | 热度、转发量和重要性不是同一指标；重要性的编辑规则也要可见。 |
| 新增信息 | 相比已读内容增加了什么事实、证据或解释。 | 同一件事换个夸张标题不应占一个新的主题位置。 |
| 理解价值 | 有无必要背景、概念、数据与可继续阅读的线索。 | 只有结论的短摘要可能省时却损失理解；允许展开长文。 |
| 范围与视角 | 主题、地区、时间尺度、来源与解释角度是否过于集中。 | 多样性不只是政治立场对半分，也不应为“平衡”加入证据薄弱的说法。 |

建议由用户设置关注方向和来源，系统提出可修改的初始规则。每条推荐可说明“你关注的主题有新进展”“与你正在学习的概念相关”“补充本期未覆盖的领域”等理由。趣味表达可以帮助理解，是否有价值需要看具体内容；不把题材名称当成唯一质量标准。

## 候选原型：个人报纸

这是一种建议形式，尚未取代用户保留的其他可能。

| 栏目 | 作用 | 候选控制方式 |
| --- | --- | --- |
| 世界概览 | 给用户主动关注之外的重要事件保留位置。 | 可查看选题理由、地域与主题分布；采用公开可改的编辑规则。 |
| 我的关注 | 追踪明确订阅的主题、来源和长期问题。 | 订阅／取消、按时间查看、只看新进展；可选择关闭个性排序。 |
| 知识拓展 | 引入未熟悉但能理解、值得深入的主题。 | 说明关联，调节探索强度；不因一次跳过就永久消失。 |
| 一个深读 | 从事件走向背景、原始材料和不同解释。 | 加入稍后读、听读、学习包或个人笔记。 |

候选的一次会话：打开本期 → 浏览目录与时间估计 → 读少量事件摘要 → 对一项展开来源／背景 → 收藏或建立专题 → 到达本期结束，可自主继续。篇数、时间估计、栏目比例、出版时点均未定。

同一期可保留稳定目录；新进展显示更新标记，按需刷新。已读摘要若被更正，应能发现更正并回看出处。默认通知频率、重大事件提醒和“本期结束”的呈现方式都留待体验讨论。

把时间排序或关闭个性化作为可选控制很有用，但有限来源依然会形成盲区；只换排序方式不足以保证视野增长。因此来源选择与内容覆盖需要同时检查。

## 内容从哪里来，AI 做什么

下面仅划分职责，不选择技术栈或服务商：

1. **信息取得**：读取允许访问的 RSS、出版者接口、订阅内容或用户主动保存的资料。搜索发现不等于获得全文；付费全文、图片和音频能否入库需对应来源条件。
2. **组织**：识别文章与事件、合并重复转载、保留原始出处。不同采访或新事实应留在事件下，不能被近似标题直接抹掉。
3. **选择**：根据显式关注、编辑标准和覆盖目标选取；来源不足或暂时缺少高质量内容时如实显示，避免为了填满版面而凑数。
4. **解释**：AI 协助摘要、翻译、补背景与解释术语，事实指向可核对的来源。标明哪些是报道、作者分析、AI 整理或仍有分歧的内容。
5. **延伸**：用户想深入时，查资料、建专题、做笔记、准备可核查的练习，再导入相应 app。阅读本身可以结束，不强制每篇都变成测验。

需要显示事件发生时间、报道／更新时间、获取时间；离线阅读也能知道内容有多旧。模型预训练知识不能充当当天新闻。重要数字、引文、翻译和摘要存在错误可能，原文定位和更正记录应保持可用。

新闻的质量不能靠一个提示词独立保证。来源维护、摘要复核、缺失信息处理、收费与更新成本都属于产品持续运行成本，目前没有确定由谁维护，也没有验证任何服务商的内容许可或 API 套餐。

## 儿童新闻与百科候选

2026-10-26 用户补充：目标儿童 5–6 岁，能够独立阅读，希望提供听书。以下模式据此优先研究自主读与可选听读；年龄和阅读能力来自用户说明，并非本项目测评结果。

| 方向 | 要帮助孩子做什么 | 候选互动 |
| --- | --- | --- |
| 儿童新闻 | 理解真实发生的事件、相关人物地点、为何值得了解，以及信息来自哪里。 | 听一段／读一段、找地图、区分事实与观点、说出想追问的问题。 |
| 儿童百科 | 对一个相对稳定的概念逐步理解。 | 从生活问题出发，观察、分类、预测，再看解释；回到真实生活做小观察。 |
| 新闻连百科 | 借真实事件激发兴趣，再建立背景知识。 | “一次航天任务的报道 → 什么是轨道 → 相关图解／小练习”。此为假设场景，不是本轮真实新闻。 |

建议按实际阅读和理解能力提供短句、语音、图示及更深入版本，年龄只是输入之一。事实简化应保留关键因果和不确定性；不能把真实报道编成虚构结局。复杂或令人不安的主题需要适龄语境和可求助的成人入口，具体内容范围与家庭偏好尚未定。

对本家庭，候选入口可以是“发生了什么 → 一个看得懂的解释 → 想知道更多就继续问”，支持自己读或听。例如从真实的自然、航天或生活技术报道引出背景问题；这些只是选题例子，未确定栏目范围。直接借用上表 8–14 岁周刊的文本难度并不适合据此定案，可参考栏目组织，再按孩子的实际理解取样。单篇时长、题量、更新频率和跟读形式都未确定。

进度可以记录“我问过的问题、能解释的概念、做过的观察”，也可有可选的发现册或章节成就。儿童新闻不自动等同于考试练习；好奇、提问、讨论也有独立价值。

## 与系统级 AI first 相连

在新闻详情、目录、听读或百科页，唤醒 AI 后都应能指代“这段”“刚才那条”“这个图”，并取得当前对象、原文位置、出处、时间和相关操作。该覆盖目标来自 G-002，具体表示方式见 [AI 平台研究](/home/workspace/reader/docs/research/ai-native-platform.md)。

候选任务示例：

- “这两篇的分歧是什么？各自用了哪些证据？”——读取具体文章，保留一致事实、不同解释及缺失材料。
- “我想补上这方面的基础知识。”——基于当前主题查背景、选择深度、导入学习 app，返回实际可用入口。
- “以后关注这件事，只告诉我新进展。”——持久保存关注对象和已读状态；提醒策略由后续设置决定。
- “找回上周看过的那篇，再从上次没听完的地方开始。”——结合历史、具体版本与音频断点恢复。

这些例子同时检验 G-001 的价值与 G-002 的能力覆盖，尚未意味着现在已经支持这些任务。
