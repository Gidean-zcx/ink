## 书库与模板

Gen.3C p38–40：从总列表按全部/笔记/收藏与浏览/更新/名称排序选择；文件夹入口按目录进入。阅读工具栏的快速列表可切同目录、最近打开或收藏。未读图标不是掌握程度，也没有据此确认断点保存。p41–42另支持目录新建、命名和选目的地复制/移动。

Gen.3C p103：PC App设置→笔记模板→添加→选PDF→输入模板名→OK；删除有确认，改名另有OK。多页PDF只取第一页，加密PDF不可作模板；对已存在笔记的影响和同名覆盖未知。模板、原始PDF、已创建笔记不能当同一对象。
