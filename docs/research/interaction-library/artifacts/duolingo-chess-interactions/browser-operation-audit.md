# Duolingo Chess：匿名入门课的实际操作

2026-10-27，E-DUCX-02；新任务F-M031-19，另补F-M031-16和F-M031-18的棋课子范围。这里是实际公开网页操作，不是Adventures、语言课、原生App或儿童实测。结果仅覆盖本次课程样本。

## 环境及边界

Linux、Chromium156.0.8078.4、1280×950、en-US、全新临时上下文；从[官方Chess页](https://www.duolingo.com/chess)正常进入。使用可见按钮和鼠标拖动，没有修改业务变量、强制启用控件或直接调用答题接口。未提交姓名/邮箱/年龄、登录、付费、联机对战、听音或录音；选择Other、零基础、5分钟、7天目标都是研究选择。正常匿名流程建立了临时服务端状态并提交学习结果，不能称外部状态未变。

[观察状态](browser/observed-states.json)保存82次快照的文本/控件/URL，[动作日志](browser/trace-actions.json)保存带时间的命令和失败；不是连续录屏。读DOM不等于所有文字在截图时已可见：过场存在重复/残留文本，数字滚动把0–9全部留在DOM，成绩以实际图像为准。正式只选已由root实际查看的必要画面。

## 失败、网络与可复用判断

四次工具定位失败分别是Start Playing大小写、第二题禁用的Hint、误以第三题已完成而查找Continue，以及未选连续天数目标就点击禁用确认。均记录在动作日志中；没有强制执行。第三题两个无效拖动保留，不把文件名中的“complete”当完成证据。若后续复核先看实际状态和动作结果。

文档请求200；正常运行中部分辅助请求404。收尾核完整日志发现：选择7天目标并确认后，streak-goal-current的PUT返回403，但页面继续到每日任务和奖励。该请求没有重试，没有换身份/端点或绕过；后续仅完成正常返回及刷新观察。因此**不能声称7天目标保存成功**，也不能由403推断整节课或所有进度保存失败。页面未出现访问挑战；网页加载的后台组件不当人为验证已发生。网络记录只保存方法/状态/脱敏路径，不含请求体、令牌或响应正文；200也不能单独证明业务成功。本次结算、奖励及刷新后的字段有独立UI证据。[会话](browser/session.json)、[网络状态](browser/network-statuses.json)、[浏览器错误](browser/browser-errors.json)另存。浏览器正常关闭，exit0。

后续设计可区分：走法允许、题目约束、提示使用、同题重试、课程得分、连续天数与奖励。特别是“前面可绕路，后面限步判错”的规则变化，需要让学习者与AI都知道当前目标。具体采用方式仍是建议；没有要求本产品增加国际象棋，也没有证明这种激励适合5–6岁或优于其他学习方法。
