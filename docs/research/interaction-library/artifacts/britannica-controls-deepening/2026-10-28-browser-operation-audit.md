### Britannica School Elementary — Community Helpers 预览（公开网页 D4 审计，2026‑10‑28）

- 环境与前提
  - 桌面浏览器，匿名访问；不登录、不写入账号数据；零副作用。
  - 链接范围：Community Helpers 公开预览入口与题页 iframe；仅限本期可预览材料。
  - 不主张声音/正确性评估；仅记录可复查的页面状态与控件反应。

- 操作与状态序列
  1) 进入预览目录页 → 点击 Community Helpers（公开预览）
     - 预期：出现首题与选项；可见 Next/Back/Start Again 等控件的初始禁用/可用状态
  2) 故意点错一个选项 → 观察错误反馈
     - 预期：出现否定反馈与线索/讲解；Try again 显示
  3) 点击 Try again → 重新选择正确答案 → Next
     - 预期：进入下一题；上一题的讲解已展示过
  4) 点击 Back 返回上一题 → 观察讲解页稳定后再 Next 前进
     - 预期：回到上一题的讲解稳定帧；Next 后回当前题
  5) 完成四题 → 进入回顾/庆祝页
     - 预期：显示回顾列表与开放问题；无账号保存
  6) 点击 Start Again → 框架重载 → 重入首题
     - 预期：回到起点；先前作答不保留（匿名环境）
  7) 刷新页面（浏览器刷新）/重新打开同一预览 URL
     - 预期：同样回到首题；未见“续答”入口

- 失败分支与限制
  - 离线/断网未在此次序列中模拟；不主张弱网下的控件行为
  - 订阅版/已登录环境的保存或差异不在本轮范围

- 可复查证据
  - 目录与题页公开 URL（站点合规不在此复制）；回放步骤见 coverage 与 reference‑points 中的 RP‑M049‑04/05
  - 对应 evidence.jsonl 记录 observed_browser_sequence（本批新增）

- 研究提示（不升级为需求/能力断言）
  - 区分“错误→讲解→重试→正确→Next”和“Back→讲解稳定→Next”的两条可复查路径
  - Start Again 与刷新都“回到首题”，匿名预览下不存在“续答”保证
