# M-052 今日头条：推荐、主动检索与兴趣重置

## 范围与证据强度

查阅日2026-10-27。研究对象仍为中国大陆今日头条主App；商店快照可固定iPhone/iPad 18.8.0（HTML发布日期2026-10-22），未安装。政策本身覆盖头条多个系列及Web等形态，不据此将每条路径标为该iOS构建；Android构建未知，极速版/抖音/Web不互套。官方当前隐私政策 2026-10-14 更新、10-21 生效，路径仍可能随端与版本调整。中国区官方 App Store 可确认 iPhone/iPad、16+ 分级及内购；商店年龄评级不是儿童课程适龄认证（E-TT-04）。

**主阅读链 D1；部分设置/历史操作 D2。**全部为文本资料，`hands_on=false`、`visual_observed=false`。没有进入个性化首页，也没有点击真实反馈、关注、收藏或清除历史。公开算法备案只能说明平台宣称怎样工作。

本次覆盖发现、负反馈、偏好重置、历史、搜索及个人信息副本边界；不穷尽微头条创作、社交、直播、小说漫画、广告与商业会员功能。

## 一次阅读、控制与回访

**F-M052-01 的任务边界：**成人带着问题进入→选择一条消息→阅读原文与出处→判断是否还有未知→保存或结束。该完整链尚不能用本次公开材料重建：未见当前版启动页、全文内交互、朗读控制、读完标记、回到卡片位置及重新启动状态。因此维持 D1，不用网页文章或他人教程冒充应用观察。

以下“P”仅为缩短路径，指**我的→设置→隐私设置**。操作说明主要来自 E-TT-01 §6.1.2、6.2.2、7.2.1；不是本次点击结果。

## 失败、奖励、家长及内容边界

- **控制失败：**屏蔽后仍见相似内容究竟是新标签、设置未提交还是算法边界，资料不能判定。清除兴趣不能当作消除旧推荐影响的即时效果承诺。
- **阅读中断：**文章读到一半退出、视频暂停后切后台、断网与账号切换，均缺少同版本恢复材料；不假定自动续播或跨端同步。
- **付费与来源：**商店存在自动续期会员（E-TT-04），但不能因此认定每篇资讯收费或会员解锁外部来源。需另查具体内容的权益标签、来源跳转和权限失效。
- **未成年人：**独立规则说明会参考年龄、收集有限观看日志；模式内发布受限、私聊及评论默认关闭（E-TT-03）。这不能证明 5–6 岁可独立操作，更不能保证完全无推荐数据。
- **奖励/难度：**没有找到与这条阅读任务相联的掌握测验、知识等级、完成奖励和结束结算证据。其他版本的金币/签到不能移植到这里；阅读时长、点击率和兴趣广度不是学习成绩。


## 本轮目录、版本差异与未取得材料

[22项功能来源台账](../batches/toutiao-controls-deepening-inventory.csv)区分功能声明、局部路径和完整任务，不是App全功能目录。另存[创作者帮助目录](../artifacts/toutiao-controls-deepening/creator-help-index.csv)：73行含父子项，只有“内容相关常见问题”读到正文，其余只读取目录名称；它不是读者设置目录，不扩大阅读覆盖。

- **来源与频道：**商店声明关注作者/收藏能力；E-TT-01 §7.2.1和E-TTCD-01给出我的→关注/粉丝查询编辑路径，但未提供关注/取关确认或排序机制。政策声明可增减排序兴趣频道，没有具体编辑按钮；其后相邻的清除兴趣路径不能拿来补频道入口。文章来源跳转仍未知。
- **版本差异：**E-TTCD-01没有日期，清兴趣项笼统说删除操作使用行为；E-TT-01的2026版本明确说历史兴趣与推测偏好。E-TTCD-02更新2024-05-06、生效05-13，部分路径省略设置层且有“永久清除”字样，同时说明会再积累兴趣。不将三份文档合成“永久清空所有历史”的承诺。
- **控制对象：**内容推荐总开关、用于推荐的位置/搜索/关注特征、个性化广告、显式关注列表、屏蔽标签、浏览记录与收藏分别记录。关个性化广告的政策结果是仍有广告且数量不变，不能当成关内容推荐；关闭基于关注的特征不等于取消关注。没有证据确认长按负反馈的对象枚举或绝对屏蔽效果。
- **数据出口：**F07是个人信息副本申请，不证明包含原文/全部收藏、能够导回或恢复阅读位置。账号锁定导致已登录设备退出、解除锁定恢复可用，仅见局部政策路径，未新增完整恢复任务。无痕状态、清历史、清兴趣也不等同删除一切服务器信息。
- **实际取证限制：**官网普通GET为要求JavaScript的身份初始化壳，未执行脚本；反馈URL网页工具不可访问并停止。官方创作者帮助可公开读，但其客服入口和创作信用分不移植成读者行为或学习奖励。长按/频道/历史的第三方教程未采用。18.8.0及近期商店日志仅一般问题修复，不能补阅读结束和恢复。

## 本项目启发与限制

对成人 R-020/G-001，**有条件借鉴**的是“系统供给内容 + 主动检索 + 用户可改变供给规则”。本项目可把一次任务限制在一个问题、有限条材料、出处和尚未解决的分歧，结束时允许暂存；不能仅复制连续供给来延长消耗时间。这些是建议，不是头条已实现的知识任务流程。

对 5–6 岁且偏好听书的孩子，现有证据不足以把主应用作为自主内容入口：未确认持续朗读、语速、词汇难度和合适的结束机制。已有独立未成年人规则也没有给出本次可复核的完整儿童阅读链。可以研究成人代选材料的可能性，但需另核内容版权、年龄理解与旁白体验。

对 G-002/R-007/R-021 的**推断**：若本设备采用类似机制，AI 需区分显式关注、当前问题、模型偏好、屏蔽项、阅读历史、内容权益与实际播放/阅读位置；需要知道一次负反馈是否提交以及是否可撤销。不能把“清除偏好”映射为删除原文笔记，也不能把历史浏览误认作已经理解。没有发现本项目可直接调用全部这些动作的官方公开接口。

## 结构化竞分（2026-10-28）

- 对象/信息架构
  - 推荐/检索/热榜、关注/收藏、负反馈/屏蔽、个性化推荐开关与特征开关（位置/搜索/关注）、清除历史兴趣、无痕搜索/阅读、个人信息副本为不同对象（F‑M052‑02/03/04/05/07）。
  - “清除历史兴趣”与“删除浏览/收藏记录”以及“关闭推荐”与“退出登录/停用数据处理”非同一效果（F‑M052‑03/04）。
- 关键任务流（已证与限制，D2）
  - 负反馈/屏蔽管理；个性化推荐开关与特征开关；清除历史兴趣；搜索与无痕范围；个人信息副本申请（F‑M052‑02/03/04/05/07）。
- 失败与恢复边界
  - 未证即时移卡/撤销/跨端同步与回执；关闭特征不等于取消关注；广告与内容推荐开关分离。
  - 未成年人模式存在但入口/完整链未证；不以算法备案声明代替实际交互。
- 对 E‑Ink4 Plus 与家庭的启发与风险
  - 启发：将“推荐供给/主动检索/用户控制”拆分；任务以“读原文并记录依据”为终点。
  - 风险：把“清兴趣”当删除全部历史；把收藏当掌握；把热榜当编辑精选。
