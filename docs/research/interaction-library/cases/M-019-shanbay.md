## 分支、统计与版本差异

- 单词帮助把“太简单”与按学习次数形成的已掌握合计为一种进度指标；另一篇写有效学习至少5次且测试均通过（E-SBCD-11），E-SBY-03又写连续5次选认识。它们不是同一份现版算法规格，也不是外部能力测试；“认识”、测试正确、被系统列入已掌握、计数展示须分别保留。
- 听力帮助允许选择挖空比例；零挖空仍可完成打卡但无听力积分；使用提示不计该空积分/星级贡献。积分与星级规则是不同口径，不能将星数直接当答题正确率。E-SBY-10、11。
- 阅读统计的词数会累计重复词，章节数按产品切分文章计算，不能理解为掌握的独立词汇量或原书章节数。E-SBY-14。
- 分享后奖励未记，旧帮助要求从分享弹窗返回扇贝，再检查贝壳明细；同渠道重复分享不重复发奖。E-SBY-13。不要将社交传播收益误作能力进步。
- 旧词书帮助限制同账号书数并写删书后相关书进度不可恢复（E-SBCD-03）；现商店对会员又称词书无上限（E-SBCD-07）。不能把旧上限当当前所有账户限制，也不能把换书等同删书。未取得收藏删除和跨书词状态传播规则。
- 阅读4.56.0“自动打卡”、4.47“重读打卡”与旧帮助“手动完成纳入进度”存在版本/计量边界。日志未说明自动打卡是否等于同一阅读进度对象、何时触发，故不直接宣布旧完成按钮已被取消。E-SBCD-08。
- 单词提示路径不同、听力口语与独立口语并存，均须附具体E及版本引用；商店版本声明不证明服务在本项目上可用。
- **统一缺口**：误评撤销、太简单恢复、题目跳过、离线缓存、进程结束、双端并行学习、账号切换和备份恢复均未取得当前完整规则。计划系统“继续安排”不等于崩溃后能恢复原句、录音或未提交答案。没有把入口壳页当正文，没有使用未观看视频的时间点。扩展端只有同账号检查说明，不能填补四个手机App的同步/恢复缺口。

## 2026-10-27补回原任务的控制与边界

**F01与F03：失败进入详情、明确数量入口。** E-SBY-04说回想不起或测试没通过会到详情，而每天最终通过也会到同页；页面相同不代表答题状态相同。E-SBC2-04的历史单词英语版说明把数量按钮定位到我的→单词书，在每日新学数量右侧；E-SBY-05再给生效条件：一般修改即生效，设定低于当天已学数则次日生效。这两篇都没有保存确认、复习重排或当前构建。公司介绍另外声称多次不认识时可AI助记，但“超过3次”是产品示例，平台/版本不明，只留D1，不拼入旧自评算法。E-SBC2-07。

**F04与F05：标注、查词、排版各有不同含义。** 旧E-SBY-06可按英语水平标出文中大纲词，未说按个人已掌握词着色。非正文单词由空白处→右上搜索查询；排版则空白处→底部对应按钮调整。没有取得这些设置如何撤回或跨端保存；出版译文、AI讲解、长按单句播放继续按旧帮助/商店版本分开。

## 数据与激励分析（推断）

关联 G-001、G-002、R-015/018/019/021：这组产品适合研究“文章中的词、词条、音频句段、提示使用、独立回答、学习安排”怎样连接。阅读完成按钮、累计阅读词数、听力积分与自评熟悉度分别表示不同事实；AI 必须能够获取其口径，否则会把接触量报告成能力增长。

对本项目更有价值的是低摩擦的跨场景衔接：先保留原句与声段，再进入词汇或听说任务；任务可以结束，奖励不必无限累积。Plus 上选择题、拼写和录音各有输入成本，需分别验证；不能因为同一品牌多个 App 可联动，就认定第三方 API 或 MCU 兼容已成立。5–6 岁儿童对自评、提示和积分的理解仍需观察。

本轮补充推断：AI应区分自动记录的阅读完成、用户明确确认、计划达标及整篇训练完成；中文辅助后复述、参考答案后作答和独立作答也应保留不同提示来源。词书删除风险需绑定具体数据对象，不能只用一个“重置学习”动作；这些是本项目建议，不是扇贝已提供的统一接口。

下一项最小观察：在当前四个App分别取得“我的→帮助与客服”内有版本标识的控制说明，优先单词误评/简单词恢复、阅读自动完成阈值、两种口语的录音提交和重录；再取得同一模式的退出重进说明。当前不安装或登录，未将这些观察写成完成。
