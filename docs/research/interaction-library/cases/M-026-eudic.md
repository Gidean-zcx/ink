## 结构化竞分（2026-10-28）

- 对象边界（导出/本地副本/云条目/阅读点/音频点）：
  - 资源与索引：复制 mdx/mdd 等资源并“索引就绪”仅代表可被检索，不等于入学习队列或自动生成生词（F‑M026‑09/12；E‑EUD‑10/15）。
  - 生词与同步：生词/词条笔记/标注可云同步；Android 本地周期性备份与云同步是不同对象，误删/冲突未证（F‑M026‑04/07；E‑EUD‑05/08）。
  - 导出与回导：新版日志声明 CSV/Anki 导出能力，但与云同步/本地备份各自独立；未有“导出件回导编辑后写回原对象”的证据（F‑M026‑10；E‑EUD‑12）。
  - 语境对象：词典原声例句→制作卡片 与 “文件阅读中的原句标注”分别保存；两者不应混写为同一“语境”（F‑M026‑02/03/04；E‑EUD‑02/04）。
  - 阅读/查词返回：解释页“上一词/搜索页返回”是页面导航；不自动等于加入生词或保存原句（F‑M026‑01/13；E‑EUD‑16）。
- 关键任务流（样例）：
  - “资源→索引→检索”：传入词库 → 目标词库建索引 → 全文搜索/解释页展示；与学习计划无直接绑定。
  - “查词→笔记/加词→同步”：解释页记录笔记/加入生词 → 手动/自动同步；与CSV/Anki导出独立。
- 失败与恢复（文档证据）：
  - Android 本地备份并非实时；误掌握“重新学习”为独立动作，不等于恢复历史备份（F‑M026‑07；E‑EUD‑08）。
  - 全文索引后台进行；删除与重建、强退、空结果与失败回执未证（F‑M026‑12）。
- 对 E‑Ink4 Plus 与 5–6 岁+成人家庭的启发：
  - 把“资源复制/索引就绪/加入学习/同步/导出”拆分为可感知状态；AI 不能把“看到释义”当作“已保存学习数据”或“已保留原句”。

## 数据、激励与本项目关系

资料区分词典资源、查询历史、词条笔记、阅读标注、原声例句卡、生词本分组、学习课本、熟悉度、练习错次、跟读评分与本地备份。正式学习、自由练习和“已掌握”是不同写状态动作；补练不改变正式计划是可借鉴的设计点。提醒与进度色能推动继续，但不能据此断言掌握效果。

关联 G-001/G-002、R-016/019/021、H-004/005：本项目AI需要读到每次作答的模式、来源句位置和是否影响计划，才能解释“为什么还要学”。从新闻/纸书进来的生词应保存用户原句，不能用通用例句替换而不说明；儿童的“跳过”与“我会了”宜区分，Plus输入可服务拼写与笔记。以上是本项目推断，不代表已选欧路算法或接口。

补证后的本项目推断：AI应分别报告“资源复制”“索引就绪”“返回释义”“加入学习”“同步结束”，而不是统一返回导入成功。显示隐藏与物理删除、笔记放弃与保存、当前进度与可回滚备份都需要不同动作及结果；这些是候选设计问题，不是新增需求。
