## 数据与本项目分析

关联G-001/G-002及R-014/015/019/021：已斩标记、当日作答、资源下载、待上传记录、日历打卡和铜板应是可分别核查的对象。帮助提供的列表恢复比“撤销刚才误判”范围更窄；补日历不代表重新学习，也不自动补活动资格。云同步不等于本地未上传记录已有备份。

**本项目推断**：AI需要识别刚才动作修改哪个对象、是否已保存/上传，以及“继续”恢复的是资源还是学习位置；解释单词应保留题型和已揭示提示。上述为研究建议，不是百词斩开放全部数据/API或本项目已确认实现。

商店的小学内容面向6–12岁，不等于本项目5–6岁适用性验证；记忆效果宣传也不是本项目实测结果。活动得分、日历连续天数与长期掌握仍须分别研究。

下一类证据仍是固定手机OS/构建的首学与复习连续说明，至少包含一次答错、提示、再答、误斩恢复、退出与断网。本轮不执行账号操作；未发现完整链不代表产品没有相应能力。

## 结构化竞分（2026-10-28）

- **对象与信息架构**
  - **学习对象**：词条/例句 与 题型（拼写/辨认/速听/押韵）分离；“已斩”“已学/熟悉”是标签状态，非统一“掌握”。
  - **计划与书**：词书/计划（日量/持续天数）独立于账户档案；删除当前词书会清掉该书学习记录，不等于清空账户累计。
  - **资源与记录**：离线资源包 与 当日上传/日历打卡/铜板奖励分离；“上传成功”≠ 页面停留时间提示。
  - **收藏与导出**：收藏到“单词本”后可导出 PDF，非“导入词表”；官方材料对“自定义上传词库”存在版本冲突，保持文档限度。

- **关键任务流（D2）**
  - 选书/设计划 → 学习若干题型 →（文档存在）误斩后在“已斩单词”列表恢复 → 当日上传/打卡（建议停留提示）→ 查看日历记录。
  - 收藏若干词 → 单词本 → 导出 PDF（字段/去重/失败未证）。
  - 离线：词书页云朵下载资源 → 断网学习（题型范围/失败回执未知）→ 回网补同步。

- **失败与恢复边界**
  - 离线编辑未同步即清缓存会一并清掉（帮助口径）；“恢复已斩”仅对指定词条，不等于撤销最近一次判定。
  - 删除词书清该书学习记录；累计天数/词量不一定清空。上传/奖励/学习完成为不同状态，失败/重试口径未给。
  - 题内“提示/揭答/再答通过”的完整链未见官方逐步说明，保持D2。

- **对 E‑Ink4 Plus 与 5–6岁+成人家庭的启发与风险**
  - 启发：将“资源下载/学习队列/上传打卡/奖励”分层呈现；对误斩提供明确“指定词恢复”入口；离线前置缓存与弱网补传的可见状态。
  - 风险：儿童场景对“误触/误判撤销”的期望高，而现口径仅提供列表式恢复；离线学习的题型覆盖、断点与失败回执未明，易造成“完成/上传”混淆。

- **证据状态**
  - 深度：D2（官方帮助/商店/公告文字链；无登录/作答/多媒体实操）。不声称任何 D4。
