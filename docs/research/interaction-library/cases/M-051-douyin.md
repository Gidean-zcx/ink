# M-051 抖音：连续内容中的显式控制与退出边界

## 范围与证据强度

初查2026-10-26，续查2026-10-27。对象是中国大陆抖音手机客户端；不将 TikTok、抖音精选、极速版或 Web 的界面直接移植到主应用。未安装，构建号和操作系统版本未知。当前隐私政策更新于 2026-09-11、09-18 生效；未成年人须知更新于 2026-06-12、06-19 生效。2025 年功能文章是历史发布说明，当前政策只能交叉确认其中仍有描述的部分。

**整体 D1、局部 D2：**有官方可复核的推荐管理、监护和 AI 笔记步骤；没有一段从启动、看完具体视频到退出重进的连续观察。全部 `hands_on=false`；初查未看图，续查静态图范围见下。未点击产品按钮、绑定账号、点赞、收藏或提交信息。不是以广告素材证明完整功能。

覆盖内容发现、负反馈、偏好、收藏意图、搜索、家长限制和知识视频工具；直播、电商、发布、私信、付费课程、创作者收益不在本次交互研究范围。

其他状态须保留未知：断网后的缓存可看范围、内容被删除、付费/地区限制、账号失效、强退前状态落盘、收藏恢复顺序。上述问题不以官方投诉入口替代操作恢复流程。

## 对儿童与成人学习的判断

对 5–6 岁、能自主阅读但偏好听书的孩子，**有条件借鉴局部机制，独立主信息流适配信息不足**。家长限制和内容池不能证明旁白连续性、听书式后台体验、认字难度或知识正确率。标题摘要可能减少寻找片段的成本，但“看过/收藏/阅读总结”不等于理解，更不等于迁移到新问题；官方“学习闭环”措辞不作为学习效果结论。

对成人 G-001/R-019，可借鉴低摩擦进入一个小任务、显式减少重复、带问题回访具体片段；本项目应由一个问题和证据边界规定结束。例如看完后能给出一条有出处的解释，并提供“结束本次/留待复核”，而非把浏览时长或连续滑动当成进展。这是建议，不是已确定需求。

对 G-002/R-007/R-021 的**推断**：AI 至少需要当前内容与作者/出处、视频时间码、摘要对应片段、内容权限、当前年龄/监护模式、偏好设置、反馈提交状态、收藏意图、播放位置和任务终点。推荐权重变化与知识掌握应分别记录；摘要不能替代原视频的证据。未发现可用于本设备集成的完整公开动作 API；下述安全中心 API 只用于读取公开文章。

## 结构化竞分（2026-10-28）

- 对象/信息架构
  - 首页推荐/关注/热榜、搜索、负反馈与管理助手（探索更多/减少/屏蔽关键词）、收藏/稍后再看、未成年人模式与亲子护航、AI 笔记为不同对象（F‑M051‑02/03/04/05/06）。
  - “关闭个性化推荐”“清除历史兴趣”“无痕搜索/阅读”与“删除浏览记录/收藏”边界不同（F‑M051‑03/04/05）。
- 关键任务流（已证与限制，D2）
  - 负反馈：不感兴趣/减少该类；管理助手调强度与关键词屏蔽（F‑M051‑02/03）。
  - 推荐开关与检索：关闭个性化推荐→仅保留部分入口；搜索与本地记录删除/无痕范围（F‑M051‑04/05）。
  - 监护与AI：亲子护航绑定/限时/订阅管理；知识视频 AI 笔记跳章节（F‑M051‑05/06）。
- 失败与恢复边界
  - 未证误触撤回、提交回执、弱网/跨端同步延迟；夜间锁定示图与须知文字存在冲突，保持“条件式限制”。
  - 收藏与稍后再看入口/回访存在，但精确续播/回到片段未证；不以“看完/收藏/点赞”推导学习掌握。
- 对 E‑Ink4 Plus 与家庭的启发与风险
  - 启发：以“负反馈/显式偏好/检索”组织一次小任务；以“出处与证据”为终点。
  - 风险：把多样性/观看比例当学习指标；把推荐权重变化当知识增长；把AI摘要当原始证据替代。

### 必须保留的冲突与适用范围

1月28日儿童指南的夜间锁定示图提到监护密码继续，但同图旁文称强制关闭、6月须知也写不能使用。入口截图没有交代年龄、实名与版本，不能合并为“所有儿童夜间可密码解锁”。退出模式同理，实名未满14岁的限制须保留。此处仅比较产品材料，不作实际账号操作承诺。

2月11日成人指南推荐看完、点赞、细评论与收藏，以改善偏好命中；其中观看比例不是学习掌握阈值，也不是本研究验证过的推荐公式。新建收藏夹示例缺中间导航，不因此新增一条完成的收藏任务。AI求真卡与官方身份验证助手分开：前者呈现平台核查，后者核验是否自称官方，不能互相代替。
