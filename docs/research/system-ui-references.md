# 系统界面：参考了哪些设计，学到什么

查阅日期：2026-11-04。用途：给第一版系统界面（主页、控制中心、设置、AI、电话等）定排版和视觉规则。

证据等级说明：

- **官方**：平台或厂商自己的文档。
- **二手**：媒体报道、论坛、第三方库的文档，只作线索。
- **本项目估算**：本仓库的仿真和指令级估算，没有实机测量。
- **推论**：助手据此得出的设计建议，不是任何来源的原话，需要用户确认和实机验证。

## 1. 来源与事实

| 来源 | 等级 | 说了什么 | 对我们的用处 |

## 2. 由此得出的规则（推论，待用户确认和实机验证）

1. **页面用白底。** GL16 是为白底设计的，项目调研也建议白底；整页灰底会在每次更新时多驱动大片像素，也压低本来就有限的对比度。
2. **会频繁变的只用黑白，基本不动的才用灰。** 按钮按下、开关、滑杆、页面指示点只用黑白，可以走最快的刷新。Dock、图标底圆、搜索框这类不动的东西可以用浅灰，增加层次。
3. **形状说明能不能按。** 圆角矩形（卡片）装内容；胶囊和圆形是可以按的控件。
4. **上面看，下面按。** 时间日期放上半，图标和 Dock 放下半。
5. **一张卡片只讲一件事。** 一到两个关键信息；更多内容进应用。
6. **留白要够。** 外边距约占屏宽 6%，比第一稿（3%）翻倍。
7. **圆角有档位，内外同心。** 内圆角 ≈ 外圆角 − 内边距。
8. **保留文字标签和熟悉的习惯。** 主屏图标带文字；Dock 是唯一不带文字的地方，只放最常见的图标。
9. **不跟手，但要有即时回应。** 手指一滑，指示点先变；松手后翻屏。Dock 和状态栏不重画。

## 3. 第一版的具体数值（屏幕 684×1216，1 dp ≈ 1.86 px）

| 项 | 值 |
| --- | --- |
| 外边距 | 图标区 44 px，卡片区 32 px |
| 卡片间距 | 20 px |
| 圆角 | 卡片 44 px，浮层 56 px，胶囊和圆形全圆 |
| 字号 | 时间 176，大标题 60，标题 44，强调 32，正文 30，次要 26，最小 24 |
| 字体 | 中文 Noto Sans CJK（常规、中等、粗体）；数字 Outfit（细、中等）。都是 OFL 授权 |
| 颜色 | 白 #F7F6F2，浅灰 #E6E5DF，次要文字 #5F5E59，黑 #161614（模拟面板观感，实机灰阶待标定） |
| 触控目标 | 不小于 82 px（44 dp） |

## 4. 没有验证的

- 所有刷新时间都是估算或来自其他面板。
- 浅灰在本机面板上和白底能否分清、Outfit 细体在实机上的观感，都要上机看。
- 手势阈值、“指示点先动”的实际延迟，要实机测。
- 没有查到鸿蒙服务卡片设计规范的具体边距，也没有读到 Material 官方网站上的间距正文（页面无法抓取）。
