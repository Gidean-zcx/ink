  - 主页列表：每日清单、百问 AI、阅读、壁纸、传输、设置，第二页还有 WorkBuddy。
  - 系统页面：待机（壁纸，或日期、农历、天气、待办）、系统更新、设置里的蓝牙、关机图。
  - 设置项：网络、主题、语言、震动、充电、功耗、屏幕、对话、蓝牙、测试、关于。
  - 全局下拉面板：Wi-Fi、前光亮度和色温。

## 分类

判断方法：系统不靠它就开不了机或用不了的，算系统壳；每台设备都该有、由系统统一维护数据的，算系统应用；体现产品目标、可以单独升级的，算内置应用。

| 类别 | 内容 | 说明 |
| --- | --- | --- |
| 系统壳 | 首次开机与配对、锁屏与待机、壁纸、主页（今日、主屏、全部）、Dock、控制中心与通知、确认卡与电源菜单、输入法、AI 面板、成员与 PIN、系统更新 | 不是应用，用户退不出去。AI 操作要确认时用系统确认卡 |
| 系统应用 | 设置、电话（含联系人）、短信、AI 助手、备忘与清单（含录音）、日历与提醒、时钟与闹钟、相机、相册、文件与传输、远程画面 | 时钟与闹钟是助手加的候选，出厂没有单独列出，请用户确认 |
| 内置应用 | 阅读、听（音乐并入）、个人报纸、单词、孩子的识字与百科（下一版） | 产品主要价值所在，可以单独升级 |
| 不进首版 | 通用浏览器与邮件、应用商店和安装器、计算器、天气、游戏、主题、语言切换、WorkBuddy、工厂测试页 | 浏览器走远程画面（R-048）；主题先固定一套；其余按需再议 |

## 不是应用、但跨应用的能力

文件、通知、剪贴板和输入法（R-052）的机制都放系统服务：通知栏和键盘属于系统壳，只有“文件”另有一个系统应用。分层和缺口见[底层依赖](../system/ui-dependencies.md)。

## 主页上放在哪

| 位置 | 内容 |
| --- | --- |
| Dock（固定） | 电话、短信、AI、阅读、备忘 |
| −1 屏“今日” | 继续读、听、单词、报纸、待办 |
| 主屏 | 时间日期、一行“接下来”，以及听、报纸、单词、日历、时钟、相机、相册、设置 |
| +1 屏“全部” | 搜索和全部应用 |
