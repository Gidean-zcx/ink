更新日期：2026-11-04。状态：用户已确认方向（“定了，铺开其余页面”）。设计稿在[私有画布](https://claude.ai/artifact/PtS48RHTy15aMKa4bgbRVJ)上，只有用户能打开，页面源文件也在那里，不在仓库。

相关文档：[界面参考](../research/system-ui-references.md)（依据和具体数值）、[系统应用分类](system-apps.md)、[底层依赖](../system/ui-dependencies.md)（每个界面还缺什么）。

## 1. 设计语言

卡片和胶囊合成一种（D-59）：

- **形状说明能不能按。** 圆角矩形（卡片）装内容；胶囊和圆形是能按的控件。
- **颜色只有四个。** 白底、浅灰、次要文字的深灰、黑。
- **会频繁变的只用黑白，基本不动的才用灰**（D-61）。按钮按下、开关、滑杆、分段选择、页面指示点、键盘都是纯黑白；Dock、图标底圆、设置分组、搜索框可以用浅灰。
- **上面看，下面按。** 主屏上半只放时间，操作都在下半。
- **一张卡片只讲一件事**，一到两个关键信息。
- **要用户决定的浮层背后铺点阵**（确认卡、电源菜单、选文件）。墨水屏没有半透明，点阵是黑白的，可以走快速刷新。AI 面板不铺，因为上半屏的页面还是上下文。

数值（字号、边距、圆角、颜色）见[界面参考第 3 节](../research/system-ui-references.md)和画布上的“基础”页。

## 2. 主页结构

D-60：三屏加固定 Dock。

| 位置 | 内容 |
| --- | --- |
| −1 屏“今日” | 继续读（黑色大卡，圆环显示进度），听、单词、报纸、待办四张小卡 |
| 主屏 | 日期、时间、一行“继续读”，8 个图标（2 行，靠下） |
| +1 屏“全部” | 搜索框和全部应用 |
| Dock | 电话、短信、AI（居中的黑圆）、阅读、备忘。翻屏时不重画 |

翻屏不跟手：手指一动，指示点先变；松手后翻屏。上一页、下一页键也一样。

## 3. 交互

| 操作 | 结果 |
| --- | --- |
| 左右滑 | 翻主屏 |
| 从顶边下滑，或点状态栏 | 控制中心，整块面板直接出现，不跟手、不回弹 |
| 从底边上滑，或 HOME 键 | 回主屏；锁屏上是解锁 |
| 从左边缘右滑，或左上角按钮 | 返回 |
| 按住 AI 键，或点 Dock 中间的圆 | AI 面板，只盖下半屏 |
| 长按图标 | 卡片和快捷操作 |
| 按下任何控件 | 立刻变黑（目标 0.35 秒内），再打开 |
| 应用里 | 翻页，不滚动，底部胶囊显示第几页 |

普通通知只改状态栏小图标，不弹横幅（横幅每次消失都要刷新）；来电、闹钟才占全屏。通话时长只到分钟，计时器也不显示跳动的秒。

## 5. 给实现的提醒

- 公共零件对应界面框架里的组件，先做它们，页面就是拼装。
- 图标是同一套几何的三种画法：`line`（关着、列表）、`duo`（应用图标，放在不动的地方）、`solid`（打开、按下）。需要把矢量转成各尺寸位图的工具。
- 字体：中文 Noto Sans CJK（常规、中等、粗体），数字 Outfit（细、常规、中等）。大字号只放数字子集，字库预算要重算（SP-05）。
- 系统浮层要有统一的层级和刷新规则：键盘、AI 面板、确认卡、来电。
- 每个页面都要对 AI 可见（G-002），和设计一起做，不是最后补。

## 6. 没有验证的

- 按画布的规则，设计稿没有逐屏自查渲染，可能有错位，由用户查看后反馈。
- 没有上过实机：浅灰和白能否分清、Outfit 细体的观感、点阵遮罩的效果、所有刷新时间。
- 页面上的书名、人名、号码、容量都是示意；二维码不是真的；相机取景和相册照片用的是占位图。
- 蓝牙、通话声音能否按图上实现，取决于实机验证（[底层依赖第 3、6 节](../system/ui-dependencies.md)）。
