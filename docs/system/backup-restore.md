# 设备端备份与恢复

2026-11-06；证据范围是模拟器、合成身份和模拟中枢，未在实机或真实服务器验证。执行和测试记录见[任务报告](../tasks/backup-restore/REPORT.md)。

## 范围和入口

当前成员的已注册数据集合、成员 Flash 状态（包括阅读位置）、存储卡个人文件形成一份一致清单。每个集合先等待落盘，再在数据锁内导出，保留记录编号、版本、删除记录、排序、来源、schema 和下一个编号；不同集合和文件有各自的采集时刻。原件一直保留。

按钮、应用和 AI 都通过能力表使用：

| 能力 | 行为 |
| --- | --- |
| `backup.now` | 在当前成员的隐藏暂存目录生成不可变清单，排队上传 |
| `backup.status` | 当前成员的阶段、已落盘偏移、中枢回执、云端持久性及错误 |
| `backup.manifest` | 对象、版本、大小；恢复时标出覆盖对象及未恢复项目 |
| `restore.preview` | 下载并校验这位成员最新清单，记录将被覆盖对象的本地哈希，发放预览编号 |
| `restore.apply {preview}` | 经过人工覆盖确认；设有家长密码时还要密码，再次检查预览及资料版本 |
| `backup.changed`、`backup.failed` | 按成员发出的进度与失败事件 |

处理在 `exec.bg`，共用定时器，不增加常驻任务。大缓冲均在 PSRAM；一个传输块 16 KiB，最多 128 个清单条目，目录深度最多 8；单个 Flash 文件/集合快照最多 1 MiB，卡上文件逐块传输。超限时报失败，保留原件，不静默截断清单。需要存储卡存暂存资料；拔卡或借给电脑时等待。暂存位于 `/content/.m/<成员>/.backup/`，成员删除和清空设备会一起清理。

## 回执与恢复事务

清单及所有正文都有 SHA-256。上传按最多 64 KiB 一段、16 KiB 一帧，只领先一个 ACK；ACK 丢失或重连后，重新 `blob/put.begin`，以中枢已落盘偏移为准。全部正文和清单提交成功才记“中枢已收到”，并确认对应集合版本。`durable` 单独表示内容及目录都已进云端；它为假时不称“云端已保存”。

下载每块先写卡并同步，再请求下一块；重启从文件实际长度继续，完整后校验哈希。授权恢复的阶段、清单哈希、预览内容哈希、成员及条目游标持久存入成员 Flash。恢复任务只在原成员空间开放时继续；切换成员不会借用新成员身份。确认之前或恢复中途的更新会使尚未安装的对应条目失效，要求重新预览。

集合使用临时文件加原子改名安装；安装期间拒绝写入，成功后换到不与旧日志重叠的代，失败保留原集合。普通 Flash 状态在存储队列内比较原哈希再替换，卡文件在文件服务修改锁内比较再改名。一次恢复跨多个条目，逐条提交，断电后继续；不是跨整台设备的单一事务。完成后 `restart_required` 为真，重新开机使已缓存的服务和页面状态重新加载。

不恢复的项目逐项可查：不认识的集合保留在备份中、显示 `collection_unavailable`；AI 操作日志备份但保留本机现有记录（`kept_local_audit`），避免用历史覆盖此次恢复的审计记录。设备设置、家人身份和密码、网络和家庭凭据不在当前成员恢复范围；家庭共享内容按需下载；系统、字体与缓存由系统提供。已发送的短信、外部动作、过期提醒不重放。备份清单以外的本地文件保留。

## 模拟中枢约定与边界

块传输沿用[设备协议 §3.8](../hub/device-protocol.md)：kind 7 上传、kind 6 下载、`sid=0`，与实时会话分别分发，后台优先级。模拟中枢检查成员及哈希，持久保存正文、进度和清单；`INK_SIM_BACKUP_DIR` 仅指定合成测试的宿主目录。

本任务补充两条整份备份协调消息：

| 请求 | 参数 | 回答 |
| --- | --- | --- |
| `backup/commit` | `member, blob, size, sha256`；`blob` 是清单对象 | `received, durable, snapshot`；同一哈希重试幂等 |
| `backup/latest` | `member` | 最新清单的 `sha256, size` |

该协调接口目前只有 `sim_hub` 替身。`hub/` 的第 1 步示例服务器没有同步/对象存储实现，不能把替身结果当作真实中枢备份。设计中的增量同步、`sync/status`、对账会话、每集合 `dataset`/`restore_token` 换代还没有接上；本任务以不可变整份备份独立恢复，不复用增量版本去重。此差异及设备级资料的覆盖缺口在任务报告中列出，未改写原设计。
