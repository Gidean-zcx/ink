# 系统需求（SRS）v0.1 草案

起草：2026-11-01。阶段：S2。范围：按 [PRD](../product/prd.md) 推荐方案 A 的 v0.1 平台底座与 v0.2 首个可自用版本。

**所有数字都是建议起点**，标“建议值”；S3 实机基线测出后改为“校准值”并记录日期。不把建议值当成已验证性能。时间指标一律按 p95 统计（20 次以上），同时记录 p50/p99。

## 1. 体验时间链（适用于所有交互）

| 编号 | 需求 | 建议值 | 验证 |
| --- | --- | --- | --- |
| SR-UX-01 | 按键/触摸到系统接受输入并有首次可见反馈（局部快刷或高亮） | ≤ 150 ms | SP-01 |
| SR-UX-02 | 阅读翻页到新页稳定可读 | ≤ 600 ms | SP-01 |
| SR-UX-03 | 打开 app 到首屏稳定可读（热启动） | ≤ 1.5 s | SP-01 |
| SR-UX-04 | 冷启动到主页可用 | ≤ 6 s | SP-01 |
| SR-UX-05 | 按 AI 键到开始录音的提示 | ≤ 300 ms | SP-04 |
| SR-UX-06 | 说完话到出现第一段回答（联网正常） | ≤ 4 s | SP-04 |
| SR-UX-07 | 任意长操作（> 1 s）显示真实阶段，可取消或返回 | 必须 | 设计审查 |
| SR-UX-08 | 残影：连续翻页 50 页后无影响阅读的残影（自动清理策略生效） | 主观评分 ≥ 4/5 | SP-01 |

## 2. 平台底座（v0.1）

| 编号 | 需求 | 关联 |
| --- | --- | --- |
| SR-PL-01 | 刷新调度器统一接收区域更新请求，按“快/清晰”意图选择波形，合并同一帧内的请求 | R-010、R-029 |
| SR-PL-02 | 音频播放期间翻页、打开菜单不产生可听见的断音（音频欠载次数 = 0，30 分钟测试） | R-029 |
| SR-PL-03 | 后台备份/下载在前台交互时自动让出资源，前台指标 SR-UX-01/02 不劣化超过 20% | R-029 |
| SR-PL-04 | 内存预算：长时间运行 8 小时后内部堆最小余量 ≥ 32 KB（建议值），无泄漏增长 | R-008 |
| SR-PL-05 | 每个 app 提供能力清单：页面数据（可读文本/选区）、状态、动作（含参数与回执）、事件 | R-007、R-009、R-021 |
| SR-PL-06 | 任何页面按 AI 键可取得当前页面的能力快照，大小 ≤ 8 KB（超出时按优先级截断） | R-021 |
| SR-PL-07 | 下拉控制中心：亮度/冷暖、音量、网络、手动全刷、儿童模式切换 | R-010 |
| SR-PL-08 | 掉电或重启后，最近一次已确认的进度/笔记不丢失（落盘延迟 ≤ 5 s） | R-023 |

## 3. 首版功能（v0.2）

| 编号 | 需求 | 关联 |
| --- | --- | --- |
| SR-RD-01 | 阅读 EPUB/TXT（PDF、MOBI 由中枢转换为设备格式），支持字号、行距、目录、书签、进度 | R-017 |
| SR-RD-02 | 选中文字后可：问 AI、查词、加入单词本、做笔记 | R-007 |
| SR-RD-03 | 说出书名，中枢查找可用来源并转换，书架显示“获取中/已就绪/找不到”真实状态 | R-017 |
| SR-AU-01 | 播放有声书/TTS 音频，后台播放时可锁屏、换 app | R-018 |
| SR-AU-02 | “继续上次的故事”能识别并从断点续播，误差 ≤ 5 s | R-018 |
| SR-AU-03 | 儿童读听切换：播放时屏幕显示对应文字，按段同步 | R-018 |
| SR-NW-01 | 个人报纸每天按设定时间生成，条目数有上限，读完显示“今天读完了” | R-020 |
| SR-NW-02 | 每条新闻可展开解释、查看来源、加入专题 | R-020 |
| SR-AI-01 | AI 回答分段显示，回看旧内容时不强制跳到末尾 | R-006 |
| SR-AI-02 | AI 执行动作必须返回回执；失败给出原因与重试 | R-007 |
| SR-AI-03 | 儿童模式下 AI 使用儿童策略（用语、内容范围），对话记录家长可见 | R-014 |
| SR-DT-01 | 账户登录设备；用户数据每日自动增量备份到中枢，手动备份随时可做 | R-022、R-023 |
| SR-DT-02 | 刷机后登录可整机恢复用户数据，并验证恢复完整（校验和一致） | R-023 |
| SR-TL-01 | 备忘：语音或手写/输入，支持提醒时间 | R-015 |

## 3a. 成员与切换（R-030，D-03 已定）

| 编号 | 需求 | 关联 |
| --- | --- | --- |
| SR-MB-01 | 锁屏显示成员列表；切换成员到新成员主页可用 ≤ 2 s（建议值） | R-030 |
| SR-MB-02 | 成人成员进入需要验证（默认 4 位 PIN）；儿童成员可直接进入自己的空间，不能进入成人空间 | R-030 |
| SR-MB-03 | 所有用户数据（进度、笔记、单词、备忘、偏好、AI 记忆）按成员隔离存储与备份；家庭共享书库的内容本身不重复存储 | R-030、R-023 |
| SR-MB-04 | 切换成员时，前一成员的前台与后台活动（播放、下载归属、AI 会话）被保存并暂停，不泄露到新成员的界面与 AI 上下文 | R-030、R-021 |
| SR-MB-05 | 儿童策略（可用 app、内容来源、AI 回答策略、可选使用时长）由系统代码执行，AI 无法通过动作调用绕过 | R-014、R-030 |

## 4. 非功能

| 编号 | 需求 | 建议值 |
| --- | --- | --- |
| SR-NF-01 | 续航：每天读 1 小时 + 听 1 小时 + Wi-Fi 待机 | ≥ 3 天（待测电池容量后校准，D-02） |
| SR-NF-02 | 离线可用：已下载的书、音频、备忘、单词 | 必须（D-05 定范围） |
| SR-NF-03 | 设备不保存模型 API 密钥；设备与中枢之间加密传输、设备令牌可吊销 | 必须 |
| SR-NF-04 | OTA 升级失败可回滚到上一版本 | 必须 |
| SR-NF-05 | 中文显示：常用字库覆盖 GB2312 + 常见生僻字回退 | 必须 |
