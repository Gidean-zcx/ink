# 技术风险与验证计划（spike）

起草：2026-11-01。阶段：S3。每个 spike 是“用最少的代码在实物上回答一个问题”，不是正式开发。全部需要 Plus 实物（D-00）；SP-04 和 SP-09 的服务端部分可先做。

## 建议顺序

SP-00 → SP-01 / SP-03 →（并行）SP-02、SP-12、SP-05 → SP-06、SP-10 → SP-04 → 其余按版本需要。到货前可做：用 `idf.py size` 取静态内存、在模拟器里按参数估算 SP-01/02/12、写好测量脚本；SP-04 的中枢部分可先写。
