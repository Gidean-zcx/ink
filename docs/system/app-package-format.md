# 声明页应用包格式（format 1）

2026-11-11。对应 R-008、D-08 第二阶段、D-111；只解释数据，不执行脚本。
示例见 [单位换算](../../examples/units/)。

## 安装、卸载和目录

存储卡根目录 `apps/<id>/`，系统 HAL 路径为 `/content/apps/<id>/`。
家长通过已有文件能力使用 `/apps/<id>/`，也可通过 `/family/apps/<id>/` 访问相同目录；无线传输先传到成员文件夹，再用文件能力复制完整目录。
复制完成的包、开机、拔插卡和 USB 磁盘归还会触发扫描。删除目录即卸载；应用页的系统“卸载”按钮调用 `file.delete`，沿用确认卡。
孩子只能读取包，不能写入 `/apps`；应用是否可见、可打开仍由现有孩子应用名单和使用时段决定。

## 清单

`manifest.json`：

```json
{"format":1,"id":"units","name":"单位换算","icon":"calc","version":"1.0","permissions":["calc.eval"],"pages":["main"]}
```

`id` 必须等于目录名，使用系统已有的文件名规则，最长 31 字节；不能覆盖内置应用。
`name` 最长 63 字节，`icon` 为现有系统图标名（15 字节内），`version` 为 23 字节内的显示版本。
`permissions` 最多 12 项，每项最长 47 字节：必须列出实际调用的能力 ID；能力另有 `permission` 时，也要列出该权限名。不支持通配符。
`pages` 按顺序列出最多 4 个页面的文件名主干（23 字节内），例如 `main` 对应 `main.json`。
每个 JSON 文件不超过 4096 字节，沿用系统解析器 128 个 token 上限；字符串超过字段容量则拒绝整包。
最多同时加载 8 个包，受应用目录总计 40 项上限约束；坏包跳过并记录日志，不阻止其他包。

## 页面与控件

```json
{"title":"米换算成厘米","nodes":[
  {"id":"expression","type":"input","label":"米数乘以一百","value":"2*100"},
  {"id":"convert","type":"button","label":"换算","capability":"calc.eval","args":{"expr":"$expression"}},
  {"id":"result","type":"text","label":"厘米","value":"等待换算","from":"result"}
]}
```

页面 `title` 最长 63 字节，每页最多 6 个节点，节点 `id` 唯一、最长 23 字节。
`label` 最长 95 字节；`value` 最长 127 字节。所有容量按 UTF-8 字节计，JSON 转义占用也计入字符串入口上限。

| type | value | 操作 |
| --- | --- | --- |
| text、list | 字符串 | 显示文字或列表行，可选能力绑定 |
| input | 普通字符串 | 复用系统短输入会话，AI 聚焦后使用 `text.*` 编辑；无密码字段 |
| toggle | 布尔值，默认 false | 点击切换；AI 提交布尔值 |
| slider | 整数 0～10，默认 0 | 点击档位；AI 提交整数 |
| segments | 整数选项索引，默认 0 | `options` 为 1～3 个字符串，每项最多 31 字节 |
| button | 可省略 | 调用 `capability`，参数来自 `args` |

`args` 是小于 256 字节的 JSON 对象，使用已有能力参数表和 schema 校验。
顶层字符串 `$节点id` 引用当前页节点值：普通输入为字符串，开关为布尔值，滑杆与分段为整数；不解释嵌套模板或表达式。
`from` 是能力成功回执 `result` 内的属性路径（支持点号），该字段更新当前页对应节点。例如 `calc.eval` 回执中的 `result` 字段显示为厘米数。
数据和操作结果只在当前成员、当前页面存活期间保留；离页、换人、卡移除时销毁，无应用私有持久格式。

页面使用现有主题、短输入框、开关、分段、滑杆和列表行。一屏最多 4 个节点，实体前后页键或页面箭头遍历其余节点及其他页面；返回沿用页面栈。

## 能力、权限和快照

触控和 AI 使用同一个 `app.page_action`，参数 `id` 为节点 ID，可选 `value` 用于开关、滑杆和分段。
输入框无 `value` 时聚焦；普通文本通过带会话身份的 `text.insert/submit` 修改。
`app.page_turn` 的 `direction` 为 -1 或 1。
应用包本身不能注册能力，不能指定调用来源、成员或确认结果，也不能绑定 `app.page_*` 形成递归，或绑定 `confirm.*`。
先使用 `ink_app_foreground_may` 检查能力和权限，并检查能力是否开放给应用；AI 和远端请求还必须满足各自的能力暴露范围。底层以 `INK_SRC_APP` 请求，由原有能力闸门检查成员、应用权限和确认规则；页面不能把点按变成受信任的业务确认。
系统卸载控件独立于包清单，只有家长可见，并沿用原有文件能力。

快照复用 `ink_ui_semantics_snapshot`，含稳定节点 ID、角色、标签、当前值、页面版本、应用对象和可用动作；分段值还列出全部选项与选中索引，滑杆值带范围。超出快照缓冲时明确失败。
输入、能力回执与绘制使用同一份页面模型。异步回执校验成员 epoch 和页面 generation，旧页面的结果不会写到新页面。

## 与框架设计的关系

这是有界的本地 JSON 目录，不宣称兼容 A2UI v0.9 传输协议。未增加脚本、原生动态库、图片目录或独立输入法。
[框架设计](app-framework-design.md) §4、§5 中的长文草稿、完整字段恢复和数据驱动更新协议仍不由此格式实现；本任务只落实受限页面描述。
包没有签名或授权安装器；清单是调用上限，不等同于内存沙箱。当前只加载明确复制到卡上的数据包。
