# 自动上机测量

测量固件加一条命令的流程：核对备份、写入 ota_1、跑完、复原、和备份比对、出报告。方案见 [第 2 步写入方案](../../docs/hardware/phase2-plan.md)。

| 文件 | 作用 |
| --- | --- |
| `main/bench.c` | 测量，每条结果一行 `BENCH {json}`，最后 `BENCH_DONE` |
| `build.sh` | 编译，不碰设备。屏幕驱动从本地的官方固件克隆编译，不进仓库；屏上的图用模拟器画的真实界面（先跑 ctest），不带残影 |
| `bench.py` | 全流程。不加 `--approved` 只核对备份和打印方案 |
| `report.py` | 把控制台日志变成报告，和模拟器的假设对比，过滤隐私。`tests/hw_bench/` 有样例和测试 |

写设备前必须有用户同意，见项目规则。**不要用 `idf.py flash`**：它会覆盖引导程序、分区表和出厂固件。
