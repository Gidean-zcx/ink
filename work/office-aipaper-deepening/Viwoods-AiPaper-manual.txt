Select Files to Encrypt or Decrypt
File encryption is available in both the Paper and Meeting modules. Long press a file to enter edit mode 
and apply encryption to one or multiple files. You may also click the encryption icon within the file 
toolbar to secure the current file. To remove encryption, click the icon again and enter the password. For 
user privacy, encryption is not linked to any account.
Set Encryption Password
When using the document encryption feature for the 
first time, you must set an encryption password. 
Passwords for Paper and Meeting are managed 
independently, although identical passwords may be set. 
Passwords must be 4–12 characters in length. 
Fingerprint access for encrypted files is also supported 
and can be enabled manually under [Settings] – 
[Security] – [Fingerprint].
Change Encryption 
Password
To change the encryption password, 
tap the encrypted file and select 
the password change option on the 
input screen.
Note: Passwords are stored locally 
on the device. Please remember 
your password, as files cannot be 
unlocked if it is forgotten.
