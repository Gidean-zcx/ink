 Note: The Split View function is not available for all models. Split View in NeoReader allows you to use two windows on a screen for multitasking, like reading, handwriting, and typing. Horizontal Mode & Vertical Mode Like the system Split Screen function, Split View of NeoReader can also split the screen in 2 different directions: Horizontal or Vertical. Split View Options Current Doc Here you can read different pages of a document simultaneously. The handwriting, highlights, annotations, and bookmarks will be synced after page refresh. Another Doc Here you can read two different documents simultaneously. Handwritten Notes/Text Notes Here you can read the document and write or type simultaneously. The note will be created with the same name as the document and will be associated with it. The notes can also be edited in the Notes app. Translate Here you can read and use different translation engines, including ONYX, Bing, and Google Translate. Note : Some translation engines may have word limits per day. AI Read Here you can use our AI Read to have a quick overview of the content, author, and related books. Note: Handwriting functions are only available for some models. There will be only one note associated with the document. Changing the name of this note will not remove the association. You can also use the system Split Screen function to open the Notes app instead to avoid association. AI Read is only available in some models. Swap Sides & Exit Split View 1.
