 The EinkWise is designed to switch between different Refresh Modes and adjust Color Mode, Layout , Contrast, etc. You can instantly apply a preset display theme with a single tap. Note: The BOOX EinkWise UI may vary slightly across different models. Please refer to your device’s actual display. Access EinkWise Method 1: Via the Control Center Swipe down from the top right corner to open the Control Center . Tap the EinkWise button. Method 2: Via the Gestures Swipe up from the bottom right corner to open EinkWise . Note: This shows the default setting. The Gestures Settings on your device may vary. Please refer to the Gesture page for more info. Method 3: Via the Navigation Bar Tap the EinkWise button on the Navigation Bar In some apps where the Navigation Bar is not shown by default, you need to swipe up from the bottom edge to call out the Navigation Bar first. Image Smoothing Mode In HD Mode and Regal Mode (within NeoReader and third-party apps), users can enable Image Smoothing for image-heavy content. This setting enhances image gradients and reduces mottling. High Contrast Mode High Contrast Mode is designed to provide a sharper visual display when you are using apps. Tap to turn on High Contrast Mode. Note : High Contrast Mode does not work with HD mode. High Contrast Mode is only available in some models. Please refer to the UI on your device for specific details. EinkWise Code A new Code has been added to EinkWise for third-party apps. Users can now input specific codes to apply display settings instantly for different needs. You can also share your config with others. Note : EinkWise codes vary by device models.
