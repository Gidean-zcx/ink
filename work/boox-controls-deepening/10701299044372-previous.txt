 In this article, you will learn how to optimize the display effects of third-party apps on your device. To access the app optimization settings of a third-party app, do the following: During the use of a third-party app, open the E Ink Center . Tap App Optimization . or In Home Screen, long press the app you would like to use. Choose Optimize . Display This tab contains some general display optimization settings for the app. DPI Setting: DPI means dots per inch. Here it is used to adjust the interface size of the app. You can decrease the value if you find some content of the interface cropped, or increase the value if you find the overall interface is too small. You can also toggle on "Use APP's original DPI" to use the default setting. Bold Fonts : Here you can embolden the fonts of titles, menus and body text to increase their clarity. Apply anti-aliasing to text: Here you can apply anti-aliasing to text to increase its clarity. Automatic full-refresh when switching pages: Here you can toggle to perform automatic full-refresh when turning pages. Cloud Config : Here you can manually search the cloud for the best optimization settings of this app. Note: The Cloud Config is not available for all apps. Reset All: Here you can reset all optimization settings to the original ones. Master Switch: Here you can enable / disable all your optimization settings instead of resetting them. Color This tab contains some contrast, color optimization settings and some alternative settings when some other settings do not work. Add strokes to text: Here you can drag the slider or input a value to add strokes to the text to increase their clarity. Background Color: Here you can drag the slider or input a value to lighten the background color. Sometimes it can be used to bleach the watermarks in the app. Other Color: Here you can adjust the icon and cover colors of the app, as well as some alternative settings to adjust webpage text color, webpage text size and embolden webpage text when some other settings do not work. Others This tab contains some advanced optimization settings for the app. Stay active in the background : You can enable this setting for certain types of apps such as alarms, notifications, download tools, time tracking statistics to be continuously run in the background. Note: Enabling this function will increase power consumption. Force to use system orientation : You can enable this setting for apps which do not auto adjust to the current screen orientation. But the layout of some apps may not fit the current screen orientation. Please turn off this option if the app continues to malfunction. Scrolling buttons: Here you can add 2 virtual buttons on the screen for scrolling pages. Note: If you enable virtual scrolling buttons, you can also customize the scrolling distance by setting the starting point and the end point of scrolling. Remove startup animation: Here you can skip the startup animation to access the main interface more quickly. Handwriting Note: Only available for apps with handwriting functions including OneNote, Evernote, WPS and more in the future. This tab contains some handwriting optimization settings for the app. Handwriting Optimization : Here you can enable/disable the handwriting optimization settings. Stroke width: Here you can customize the stroke width for preview only before applying it on the canvas. It will not affect the internal settings of the brush.
