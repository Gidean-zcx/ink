 Open the Control Center > Tap EinkWise > Choose refresh modes To balance display quality and refresh speed, we provide different refresh modes to give you the best experience in different scenarios. The refresh rate of each app can be independently set to achieve optimal performance without affecting the system-wide refresh settings. Here you will learn about them and how to select the most suitable one. Refresh Modes Display Quality Refresh Speed Usage HD Mode ⭐⭐⭐⭐⭐ ⭐⭐⭐ General reading, browsing books, and pictures Speed Mode ⭐⭐⭐ ⭐⭐⭐⭐ Browsing websites Smooth Mode ⭐⭐⭐ ⭐⭐⭐⭐⭐ Smooth in-app scrolling for third-party apps and watching videos Display Quality: HD > Speed = Smooth Refresh Speed: Smooth > Speed > HD Note: Smooth Mode is currently only available on specific devices such as Note Air5 C. Refresh Modes Explained The BOOX devices have several built-in Refresh Modes: HD Mode (System Default): For reading books and other static content. It can show the crispest texts with the least ghosting. Speed Mode : It offers ultra-fast refresh rates while significantly improving display clarity and reducing ghosting compared to previous versions. Smooth Mode : Smooth Mode is best for dynamic content such as web browsing, social media apps, scrolling-heavy apps, and video streaming. Manual Refresh You can choose one method to perform a manual full refresh if you find that the ghosting accumulates too much. 1. Open the Control Center ＞Full Refresh button. 2. Tap the Navigation Ball ＞Full Refresh button. 3. Set Bottom Gestures to perform a manual full refresh. 4. Set the Navigation Bar to perform a manual full refresh.
