Chauvet 3.31.45
Oct 20, 2026
Note: After updating to this version, if you experience unexpected behaviour with the eraser on a third-party stylus or any other standalone EMR eraser, go to Settings > Display & Input > Stylus > Stylus & Eraser and switch to Compatibility Mode.
Added:
[Note & Document] Added plugin functionality.
[Note & Document] Supports toolbar customization.
[Note & Document] Added content transform features:
Supports flipping selected handwriting horizontally or vertically.
Supports non-proportional scaling of shapes and images added via plugins.
Supports real-time angle display when rotating selected content; tapping the rotate button rotates it by 90° each time.
[InkHub] Added "Plugins" as a new resource type.
[System] Added side button support for the new Supernote × LAMY AL-star EMR Pen Plus and Supernote × LAMY safari vista EMR Pen Plus. If you do not update to this firmware version, the side button behavior may vary depending on the distance between the pen tip and the screen:
- Near: When the pen tip is ≤1 cm from the screen, press and hold the side button, then place the tip on the screen to trigger the mapped side button function, which can be set to either eraser or lasso.
- Far: When the pen tip is >1 cm from the screen, press and hold the side button, then place the tip on the screen to trigger the eraser.
After updating, the side button function will no longer be affected by the distance between the pen tip and the screen.
[Settings] Supports the Supernote EMR Eraser. (To use it, switch to the corresponding mode in Settings > Display & Input > Stylus > Stylus & Eraser.)
[Settings] Supports setting the side button of compatible styluses to “Regular Eraser”.
Adjusted:
[System] No longer automatically creates the device's default folders when using a USB drive or microSD card.
[Note & Document] Adjusted the toolbar:
Grouped similar tools into unified entries on the main toolbar.
Supports long-pressing different areas of the screen with the pen to quickly access corresponding frequently used tools.
[Settings] Replaced left/right hand selection with 8 common writing postures. (InkFlow needs to be updated to the latest version to support this change.)
[Settings] Optimized writing sensitivity and removed both "Balanced Mode" and "Sensitive Mode".
[Sync] When files are deleted via Supernote Cloud sync, their corresponding cloud copies will now be moved to the Supernote Cloud Recycle Bin. (To disable this feature, please go to https://account.supernote.com/ or
https://account.supernote.com.cn/)
[Sync] When files are deleted via Google Drive sync, their corresponding cloud copies will also be moved to the Google Drive Recycle Bin.
Optimized:
[System] Reduced instances of non‑contact writing with certain EMR pens on the Nomad.
[System] Reduced visual artifacts when moving the floating toolbar.
[Note & Document] Supports detecting and resolving files with sync conflicts.
[Note & Document] Supports multi-page preview in the quick page-turning window.
[Note & Document] Optimized keyword sorting for letters with diacritics.
[Note & Document] Reduced unintended exits when activating the Lasso/Region Eraser by pressing the sidebar with two fingers.
[Note & Document & Calendar] Supports real-time angle display when adjusting the direction of a straight line while drawing.
[Note] Improved the recognition accuracy when using "Re-recognize" or lasso-selecting handwriting.
[Handwriting] Optimized the calligraphy pen for different writing postures.
[Document] Improved keyword recognition accuracy.
[Document] Supports selecting right-to-left text in PDFs, including Hebrew.
[Document] Supports turning pages with media control buttons on Bluetooth page turners.
[Files] Optimized file path display to show more folder levels.
[InkHub] Optimized resource browsing and management.
Supports full-screen viewing of resource preview images.
Supports blocking resources.
Supports editing resources under review.
[Mail] Supports choosing whether to keep a copy of sent emails in "Sent".
[Settings] Supports adding recovery information (email address or phone number) to recover the lock screen password.
[Keyboard] Improved handwriting recognition accuracy.
Fixed:
[System] Fixed the issue where only 15 grayscale levels were displayed, restoring 16-level grayscale.
[System] Fixed the issue where some webpages could not be accessed properly in the browser.
[System] Fixed the issue where the Wi‑Fi icon remained visible in the top‑right status bar after Wi‑Fi was disabled and the screen rotated.
[System] Fixed inaccurate daylight saving time display in some regions.
[Note] Fixed the issue where preset line widths for the Needle-point Pen automatically reverted to default after waking from sleep.
[Note] Fixed the issue where turning to a page with many text boxes occasionally caused the app to crash.
[Document] Fixed the issue where handwritten annotations in exported PDFs (when "Original" was selected in Export Settings) displayed offset in macOS Preview.
[Keyboard] Fixed the issue where pressing Enter on some Bluetooth keyboards would insert line breaks at random positions.

[Digest] Fixed the issue where moving documents between the internal storage and a microSD card caused the loss of digest link relationships.
