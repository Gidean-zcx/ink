Learn how to organize your notebooks, documents, and folders using tags — making it easier to find and filter content on your paper tablet.
What are tags?
Tags let you add keywords to your notes, documents, and folders so you can easily:
Categorize your content
Filter and search by topic
Group related notes using multiple tags
Use tags like Important, Follow up, or create your own custom keywords. Tags appear in Page overview and the Tags overview menu.
Tag a page
Add a Tag to a Notebook or document page
Open the notebook or document.
Tap the Document settings icon in the toolbar.
Tap Tags.
Tap an existing tag, or tap +New tag to create a new one.
Use the on-screen keyboard or Type Folio to type the name.
Tap Create to save the new tag.
You can apply multiple tags to a single page.
Identified tagged pages
The Tags icon will change from white to black once a tag is added.
Tap the icon again to view or manage tags on that page.
Tag a file or folder
Add Tags to items in My files
Long-press the file or folder.
Tap More in the top action bar.
Tap Tag.
Select an existing tag, or tap +New tag to create a new one.
Enter the tag name and tap Create to save.
Remove a tag from a file or folder
Long-press the tagged file or folder.
Tap More in the top action bar.
Tap Tag.
Tap the tag you want to remove. The tag turns from black to white when removed.
Manage tags from page overview
You can add or remove tags directly from Page overview.
Tap Page overview in a notebook.
Long-press the page you want to tag or untag.
Tap Tag in the action bar.
Add or remove tags as needed.
Filter notes using Tags
View Tagged Content in Tags Overview
From My files, tap the Menu icon (☰) in the upper-left corner.
Tap Tags to open the Tags overview.
Tap All to see a list of all tags.
Select a tag to filter your content by that keyword.
Edit or delete tags
Rename a Tag
Tap Menu (☰) > Tags.
Long-press the tag you want to rename.
Tap Rename in the top action bar.
Use the on-screen keyboard to type the new name.
Tap Save.
Delete a Tag
Tap Menu (☰) > Tags.
Long-press the tag you want to delete.
Tap Delete.
Tap Yes, delete tag to confirm.
Note: Deleting a tag will remove it from all associated files and pages.
