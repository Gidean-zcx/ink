Release notes overview
Release-notes-overview
**Summary**: The release notes for reMarkable software versions from 3.16 to 1.0 detail various updates and improvements. These include new tools, enhanced features for sketching and note-taking, better PDF and document management, improved search functionalities, and user interface upgrades. Notable updates include contrast filter improvements, new pen tools, passcode options, and enhanced palm rejection for left-handed users. Each release aims to enhance the user experience, efficiency, and functionality of the reMarkable tablet.

**Keywords**: reMarkable, release notes, software update, contrast filter, pen tools, passcode, selection tool, PDF management, search, palm rejection, left-handed mode, user interface, document management, note-taking, sketching, capture tool.

Release 3.29

Meeting Notes Tool

We've upped the timeframe for displaying calendar events in the Meeting Notes Tool to three days, so you can see more of your meetings at a glance.

Copy text from PDFs with the apps 

You can now select text in PDFs and EPUBs, so you can copy/paste into your other work tools. Connect subscribers can also paste into new notebooks.

Web App updates

You can now search your files at app.remarkable.com. Multi-select, filtering and sorting are on the way.

Auto-delete trash

Files in the trash will now be deleted automatically after 30 days.

Released October 2026.

Release 3.28

Capture tool

The Capture Tool lets you circle content to create images, perfect for copying visuals from PDFs, planners, or other reference material to paste into your notes. 

Reading refresh 

We've updated the EPUB reading experience: changes include a Ul uplift, improved formatting, and expanded language support.

Share menu refinements

The share button is now in the main toolbar, making it easier to reach, and the share menu has been streamlined.

New shades of gray

Your paper tablet now has a few more pen color options to choose from. We also optimized the grays to make it a bit easier to tell them apart.

Grab images from the cloud

Convert to Notebook now lets you import.jpg and png files from Dropbox, Google Drive, or OneDrive, and manipulate them on your paper tablet. Included with Connect. 

Drag and drop in the Web App

It's now possible to drag and drop files in the Web App, making it easier to organize your work from any browser.

Other improvements

Minor bug fixes and adjustments.

Released September 2026.

 

Release 3.27

Create meeting note

Set up meeting notes with key details from your Outlook or Google calendar, to feel fully prepared, stay present in conversations, and capture ideas to revisit later. Included with Connect. 

See how to add your calendar

Convert and share, Al updates 

Convert and share (previously Create a link) summarizes and distills your thoughts into actionable next steps, with the help of AI. This feature is available for Connect subscribers. 

Read more about Convert and share

Focused reading

Convert to Notebook now works with Read on reMarkable, so you can import web articles as

Notebooks. It removes unnecessary clutter but keeps relevant images, letting you focus on reading and annotating. 

Add images to notebooks

Drag and drop your JPG or PNG files into the desktop app to add moveable images to your notebooks.

Screen Share on web

Screen Share has been added to the new web app, so you can share ideas in meetings without needing the desktop app.

Read more about Screen Share

Release 3.26

Introducing the reMarkable web app (beta):
The new home for Convert to Notebook, and Create a link is now live. Users will gain access to the web app over the next few weeks, and can start uploading, viewing, and organizing their work at app.remarkable.com.

Send to Miro
You can now send notebook pages to Miro via the share menu. A new Miro board is created, where you can develop your ideas with AI, and collaborate with your team. Get started at my.remarkable.com/integrations.

Send to Miro is available with a Connect subscription.  

'Shared with me' folder:
Incoming shared files in Google Drive now appear conveniently stored in their own folder.

Release 3.25

Convert to Notebook updates

You can now use Convert to Notebook from Google Drive, OneDrive, or Dropbox on your paper tablet. Just long-press your file and choose if you'd like to download it as a PDF or notebook.

Available with Connect.

So you can go from your pen to your laptop even more seamlessly, we’re working on a new web app. Going forward, this will make it easier for us to deliver exciting new features faster.

Release 3.24

Tags changes

You can now add tags while you’re creating a folder, making it faster and easier to add additional levels of organisation to your folders.

Previously, adding tags to folders was only possible via a long press on the given folder and tapping Tag.

Now, just create your folder as before by tapping the plus icon from the My files home screen, tap create folder and you’ll see options for adding existing tags or creating new ones for your folder. 

Auto scroll with selections

Software version 3.24 introduces the ability to automatically scroll up and down pages while moving around selections using the selection tool. 

Other improvements

Standard maintenance, bug fixing, and tuning to keep improving and developing the responsiveness of the user interface, and the overall user experience. 

Released December 2025.

Release 3.11

The selection tool just became a lot more useful, especially when switching between using a Marker and keyboard.

Selecting typed text works a little differently to outlining handwritten notes and sketches. Draw a line through text to select it  — whether it’s single words or whole sections — then move it up and down the page, cut or copy it, or change the style.

Make a single word bold, or change the order of your paragraphs, with a flick of the pen.

With the launch of Type Folio, our slim, focused keyboard for reMarkable 2, we’re updating our software to support handwriting and typing. Giving you the best note-taking experience — however you like to work.

Release 3.2

This release coincides with the launch of mobile note-taking. Now, Connect subscribers can use our mobile and desktop apps to tap into the distraction-free qualities of paper on the go. We’ve also added several new features and polished many of the changes introduced in 3.0.

You can now select, cut, copy, and paste typed text using touch gestures. 

We’ve reintroduced sending converted handwritten notes or typed text as the body of an email. 

We also improved pinch to zoom to make navigating continuous pages smoother, and added options for quick sheets so that they’re easier to organize. And you can also personalize your sleep screen by adding your contact info.

Released February 2023.


Release 3.0

Welcome to the start of a new chapter for reMarkable. We’re rolling out major changes to our software. We’ve improved the pages in your notebooks, upgraded the writing experience, added new gestures, and enhanced the options for sharing and converting handwritten notes.

These changes will gradually enable seamless note-taking and editing across your other devices using our apps. For the first time, you’ll be able to mix typed text with handwriting, save converted handwritten notes to your paper tablet, and much more.

Rollout started December 2022.
