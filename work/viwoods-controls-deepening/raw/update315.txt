V3.15
System Update for AiPaper & AiPaper Mini
Your Notes and Reading,
Now Connected.
Viwoods V3.15 introduces
Viwoods Cloud
, more flexible note and Memo management, improved file workflows, and enhanced system stability and performance.
Built to Evolve
Five meaningful upgrades to the way you write, think, and organise, built specifically for how people actually use an e-ink writing tablet.
Update Available Now
See What's New ↓
viwoods Cloud Is Here
: Sync Notes, Reading, and Knowledge Across Devices.
viwoods Cloud brings
secure synchronization
to your notes, reading content, and knowledge across devices—while keeping cloud use flexible and optional.
10GB of
Free Cloud
Storage
Viwoods Cloud is off by default. Enable it when needed to receive 10GB of free cloud storage.
Sync the Apps
You Choose
Paper, Meeting, Knowledge Base, Memo, and Daily support automatic sync, with sync settings managed separately for each app.
Continue Reading
Across Devices
Upload selected books in Learning to sync reading progress, bookmarks, highlights, and annotations across devices.
Access Your Content
on the Web
Visit cloud.viwoods.com to preview and download notes or import books from your computer.
Your Content,
Kept Separate
Content is linked to each Viwoods account, keeping different accounts independent. Paper and Meeting share one note password, managed under Settings > Security Settings.
Paper: Structure,
Reuse, and Reorganize
Your Notes.
Paper now offers more flexible ways to structure notebooks, reuse content, move pages, and organize PDFs.
Share
Move
Rename
Lock
Favorite
Tag
Copy
Delete
Share
Move
Rename
Lock
Favorite
Tag
Copy

01
Build Deeper Outlines
Add sublevels beneath existing outline entries to create clearer structures for long notes, projects, meetings, and study materials.
02
Duplicate an Entire Notebook
Copy a complete notebook together with its pages, content, and structure for templates or recurring workflows.
03
Move Pages Between Notebooks
Move individual pages from one notebook to another without rewriting or manually copying the content.
04
Import PDFs Into Selected Folders
Choose a destination folder when importing a PDF into Paper, keeping documents organized from the start.
Knowledge Base
Capture, Save, and Find Content More Easily.
Clearer
Save Paths
The save path for notes created from image collections has been optimized for easier access and management.
Faster
Screenshot Workflow
The floating-button screenshot process has been improved, allowing you to return to reading more quickly.
Automatic
Image File Names
Saved images can now receive automatically generated file names.
Memo: Create Multi-Page Memos and
Turn Handwriting Into Action.
More You Can Do
Multi-Page Memos:
Create, add, delete, and manage multiple pages within one Memo.
Handwriting to To-Do:
Circle handwritten content and turn it directly into a To-Do.
Transparent Background Handwriting:
Write on a transparent background for more flexible content use.
Handwriting-Based File Names:
Generate file names from handwritten content for easier identification.
New Ways to Organize
More Backgrounds:
Choose from new dotted and striped handwriting backgrounds.
List View and Sorting:
Browse and organize saved Memos more easily.
Refined Experience:
Enjoy an optimized interface and smoother overall Memo experience.
File Management: Import and Organize Files
in Fewer Steps.
01
Import Into
Any Paper Folder
Import files from local storage or third-party cloud drives directly into any Paper folder.
02
Clearer
Folder Displays
Folder display logic has been optimized across applications for a more consistent browsing experience.
03
Complete
Daily To-Do
Content
Fixed an issue where To-Do content could be missing when Daily was exported or synchronized in note format.
System-Wide Improvements:
More Ways
to Share, Write, and Manage.
Share PDFs to Paper or Learning
Send a PDF directly to Paper for note organization or to Learning for reading, bookmarks, highlights, and annotations.
More Pen Colors
Use additional pen colors to distinguish key points, edits, tasks, annotations, and different content types.
More User Guide Videos
New operation videos provide clearer guidance for system features and workflows.
Multi-User Permissions
Advanced Settings now supports permission management for different users and shared-device scenarios.
App Market
Google Tasks Is Now Available.
Google Tasks has been added to the Viwoods App Market, allowing users to continue their existing Google task workflow.
Stability and Performance
A Smoother, More Reliable Experience.
Version 3.15 fixes known issues and improves system stability, performance, fluidity, and reliability across everyday use.
