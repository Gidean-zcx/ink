System Update Version 3.12
This update introduces new features, resolves known issues, optimizes the application’s interface design, and enhances user experience and system performance.
System Optimisation & Rebranding
“Picking” has been upgraded to
Knowledge Base
with a clearer structure and improved system performance. Content has been reorganised into dedicated sections, including
PickNotes
and
VisualNotes
, enabling faster access and better content separation.
PickNotes (File Management)
PickNotes now supports
multi-level folders
with full management actions such as moving, renaming, and deleting. Enhanced sorting options, folder status indicators, and
Grid/List views
make large note collections easier and faster to manage.
VisualNotes (Image Management)
VisualNotes allows direct
handwriting annotation and editing on images
, turning visual content into structured knowledge. Flexible sorting and
Grid/List views
improve browsing efficiency and organisation.
Annotation & Crop Workflow
The new
annotate-first, crop-to-save
workflow enables more precise content capture with fewer steps. Unified save logic and an optimised floating menu deliver a smoother, more responsive editing experience.
Control Center
A new
Quick Refresh mode
has been added to significantly improve screen refresh speed and overall system fluidity, delivering a more responsive and stable user experience.
App Display (Upgraded from “Contrast”)
App Display now supports an
independent refresh mode toggle
, allowing each app to either use its own refresh settings or follow the system-wide mode for greater control and consistency.
Light Color Removal
enhances visual clarity, while the refined adjustment bar with
“+ / –” controls
enables precise, efficient fine-tuning.
Settings
Added the Unbind account from AiPaper option when performing a Factory Reset.
File Management
Added the AiNotes folder under My Files > Knowledge Base, supporting export and other file operations.
AI
Optimized response latency for faster AI interactions.
AI Command now supports model switching for greater flexibility.
Optimizations and Fixes
Resolved known issues to improve overall application performance and system stability.
