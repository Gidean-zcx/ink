# API & URL Scheme

API 和 URL Scheme 提供了词典与其他软件直接交互的可能性，需要您对软件开发有一定程度的了解。

### API

欧路词典提供了调用方便的 API。

详情可见： <http://my.eudic.net/OpenAPI/Doc_Index>

如果您在使用时遇到问题，欢迎[联系我们](/1/zhi-yin-wen-dang/lian-xi-wo-men.md)。
