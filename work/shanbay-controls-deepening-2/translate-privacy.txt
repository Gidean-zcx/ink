第一章 我们如何收集您的个人信息
根据 GB/T 35273 《信息安全技术个人信息安全规范》，个人信息是指以电子或者其他方式记录的，能够单独或者与其他信息结合识别特定自然人身份或者反映特定自然人活动情况的各种信息。 扇贝翻译在以下情形可能会收集和使用您的个人信息：
1.1 您主动向扇贝翻译提供的信息
1.1.1 账号登录信息。
扇贝翻译
复用您已有的扇贝账号体系
。 当您选择登录扇贝账号时，您将通过扇贝账号系统完成登录（登录流程由扇贝账号系统提供，本政策不重复列举其登录方式相关的细节）。 扩展不会单独存储您的扇贝账号密码；账号会话基于扇贝账号系统下发的 Cookie 鉴权。
1.1.2 用户反馈信息。
当您主动通过邮件、客服等方式联系我们时，您可能向我们提供您的姓名、联系方式（手机号、邮箱）、问题描述与相关附件， 以便我们核实身份并答复您的请求。如您拒绝提供必要信息，我们可能无法处理您的具体请求。
1.1.3 候补名单（Pro Wait List）登记信息。
如您在扩展或网站中主动登记加入扇贝翻译 Pro 候补名单，我们将记录您的扇贝账号 ID 以及您可选填写的电子邮箱、来源场景（例如设置页 / 翻译服务页），用于在 Pro 计划开放时通知您。
1.1.4 本页对话信息。
当您使用扩展中的"本页对话"功能，就当前网页内容向扇贝翻译提问时，扩展会将
您输入的问题
、
当前网页的正文与标题
、
您从网页中引用的句子
（如有），以及
本次对话最近几轮的问答记录
（最多 10 轮）发送至扇贝翻译服务端（域名：sse.shanbay.com），用于生成回答。
对话内容在服务端生成回答后不予保存
，保存规则详见第八章。
1.2 您在使用扇贝翻译时，我们自动收集的信息
1.2.1 翻译请求相关信息（仅限"扇贝基础翻译模型"路径）。
当您使用扇贝翻译扩展中的"扇贝基础翻译模型"对网页进行整页翻译时，扩展会将
当前页面中需要翻译的可见文本段落
及您选择的目标语言上传至扇贝翻译服务端（域名：sse.shanbay.com）。 为支持复用与计费，服务端会临时缓存翻译请求所涉及的原文段落与对应译文。 为生成、监控与优化服务，服务端的
应用层使用日志
记录用于计费、限流与排障所必需的元数据， 包括但不限于：扇贝账号 ID、请求 ID、模型名、Token 用量、段落数量，以及来源页面的
域名（host）
。 此外，为保障接口安全、稳定运行与故障定位， 网络网关、访问日志、性能监控与链路追踪等基础设施层日志可能记录请求与响应的部分元数据 （如客户端 IP、请求路径、响应耗时、错误堆栈等）；该等基础设施日志按合理期限留存，并通过访问控制与最小化原则降低风险。 有关上述信息的存储期限请见第八章。
1.2.2 查词与生词本相关信息。
当您在网页中通过扇贝翻译进行划词查词时，扩展会将您所查询的
单词或短语
发送至扇贝（apiv3.shanbay.com）以获取释义、音标、例句等结果。 当您主动选择"加入扇贝单词生词本"时，扩展会将该单词对应的词条标识与当前来源页面的 URL 上传至扇贝单词的生词本服务，以便您在扇贝单词 App 中复习时定位语境； 在部分场景下，也可能上传来源页面标题等可选语境信息。 上述生词本数据归属于您的扇贝单词账号体系，受扇贝单词的相关政策与本政策共同保护。
1.2.3 设备与网络信息。
为了提供稳定的服务、保障接口安全并定位故障， 在您发起翻译、查词、登记 Pro 候补名单等服务请求时，扇贝翻译服务端可能记录请求所必需的元数据， 包括但不限于：浏览器自动携带的 User-Agent（浏览器与系统类型/版本）、Referer、IP 地址（由网络基础设施自动记录，用于接口安全、限流、风控与故障排查），以及您主动配置的目标语言偏好等。 上述信息会随通用网络请求自动到达服务端，仅用于本政策所述目的。
1.2.4 错误监控信息。
扇贝翻译辅助页面网站使用
Sentry
进行错误监控与性能采样，以便及时发现并修复问题。 当页面出现错误时，Sentry 可能会采集错误堆栈、浏览器与系统信息、当前 URL 及您的扇贝账号 ID 用于关联同一会话的问题。该等数据仅用于排障、不会用于身份识别以外的其他用途。
1.2.5 使用统计与产品改进信息。
为了解功能使用情况并改进产品，扇贝翻译可能记录扩展内的关键功能事件 （例如：触发整页翻译、切换翻译服务、保存翻译服务配置、点击 Pro 候补名单按钮等）以及对应事件元数据 （例如：所使用的服务商类型、目标语言、错误类型）。
上述事件不会包含您配置的 API Key、Base URL、模型名等用户凭据
；扩展通过统一的脱敏白名单对相关字段进行过滤后再上报。
1.2.6 订阅与交易信息（仅在您通过 Apple App Store 开通会员时）。
当您在扇贝翻译 macOS / iOS 客户端内通过 Apple App Store 开通会员时，Apple 会向客户端返回一份
购买收据
。客户端会将该收据上传至扇贝服务端， 由扇贝提交 Apple 的收据校验服务核验，并据以为您开通、续期或撤销会员权益。为此我们会记录： 订阅商品标识（如 translate_vip_month_renew / translate_vip_year_renew）、Apple 交易标识 （transaction id 与 original transaction id）、购买时间与订阅到期时间、是否处于试用期、 订单金额与币种，以及与该笔订阅绑定的扇贝账号 ID。
扇贝不收集也无法获取您的 Apple ID、银行卡号或任何支付账户信息
——该等信息由 Apple 处理，扇贝仅从 Apple 获得上述交易结果数据。有关保存期限请见第八章。
1.2.7 语境测词相关信息。
当您在网页上开始"语境测词"时，扩展会将当前页面中
含有您在学单词的中文句子
，以及当前页面的
域名（host）
发送至扇贝翻译服务端（apiv3.shanbay.com），用于从中选句并生成填空题目； 页面域名仅作为元数据记入第 1.2.1 条所述的应用层使用日志。
生成的题目（含题目所用的页面原句）会与您的扇贝账号关联并长期保存于服务端
，保存期限详见第八章。
1.3 第三方向我们收集的信息
1.3.1 当您使用"基础翻译模型"时
，扇贝翻译服务端会将相关请求转发至扇贝内部 LLM 网关 （llm.shanbay.com）所对接的底层模型供应商；该等供应商以服务我们的形式参与请求处理， 仅依据与我们的约定，在为您提供翻译结果所必需的范围内处理相关数据。

1.3.3 内容安全审核。

仅用于生成回答 / 题目以及内容安全合规检查
，不用于其他目的；
对扇贝基础翻译模型路径的请求进行计费、限流与额度核算；
核验您通过 Apple App Store 完成的订阅交易，据以开通、续期或撤销会员权益，并进行退款对账；
排查接口错误、定位故障、改进翻译质量与产品体验；
对产品功能使用情况进行统计与分析（仅基于脱敏后的事件元数据）；
履行法律法规要求的义务。

2.3

不会包含您的任何身份识别信息
。
2.4
当我们要将您的个人信息用于本政策未载明的其他用途时，或将基于特定目的收集而来的信息用于其他目的时， 我们会主动事先征求您的明示同意。
2.5

第三章 浏览器权限及用途说明
扇贝翻译为浏览器扩展，运行需要浏览器授予以下权限。 每项权限仅用于实现对应功能；如您拒绝授予，相应功能将无法工作，但不影响其他功能的使用。
3.1 storage（本地存储）
用于在您所使用的浏览器本地保存扇贝翻译的设置、扇贝账号会话快照、翻译服务商配置及译文缓存； BYOK（自带模型）功能下线前写入的凭据密文亦保存于同一处，现已停用、不再被读取。
该数据存储于您本机的浏览器中，不会上传至扇贝服务器
（本政策另有说明的除外）。
3.2 alarms（定时任务）
用于在后台按预定间隔执行轻量任务，例如周期性刷新您的扇贝账号会话与免费额度信息， 确保产品状态及时更新。
3.3 activeTab / tabs / scripting（页面交互能力）
用于在您主动触发整页翻译或划词查词时，向当前活动标签页注入翻译/查词脚本， 读取需翻译的可见文本段落，并把译文渲染回当前页面。 扇贝翻译
仅在您主动触发翻译或查词的页面读取相应内容
， 不会在后台对其他标签页的内容进行扫描或上传。
3.4 host_permissions（域名访问权）
扩展声明对以下域名拥有访问权，分别用于：
apiv3.shanbay.com
— 扇贝账号会话校验、查词、加入生词本；
sse.shanbay.com
— 调用扇贝基础翻译模型的流式接口；
web.shanbay.com
— 跳转扇贝账号登录页与扇贝翻译辅助页面；
<all_urls>
— 为支持您在
任意网页
上发起整页翻译或划词查词， 扩展需要在您主动触发功能时向当前页面注入翻译/查词脚本。
未触发功能时，扩展不会读取页面内容
。
您可以在浏览器扩展管理页面随时查看、更改或撤回上述权限， 权限的具体显示与关闭方式因浏览器而异，请参考浏览器开发方的说明或指引。
第四章 BYOK（自带模型）凭据如何处理
本章所述 BYOK（自带模型）功能已下线。
扇贝翻译已停止提供使用
自带的大语言模型供应商凭据
（即"BYOK， Bring Your Own Key"）进行翻译的能力，全部翻译统一由扇贝官方模型提供。 本章说明该功能下线后，您此前配置的凭据将如何处置。
4.1
您此前输入的 API Key 曾在浏览器本地通过 Web Crypto API 以 AES-GCM 算法加密后写入浏览器的本地存储； 按当前设计，
API Key 明文与密文自始仅保存在您本机的浏览器中，未作为业务字段发送至扇贝服务器
。功能下线后，该等凭据
仅被停用
——扩展不再读取、不再用于发起任何请求； 您可通过扩展"关于"页面提供的"清空所有配置"入口自行清除，或卸载扩展由浏览器一并清除。 我们也会尽合理措施避免错误监控、统计与日志采集等非业务通道意外采集到该等凭据；如发生异常，我们将依本政策第七章约定及时处置。
4.2
功能下线后，扩展会将翻译路径统一切回扇贝官方模型，
不再从本地解密凭据
，也
不再由浏览器直接向第三方模型供应商发起请求
。
4.3
就下线之前您所选择的模型供应商如何收集、使用与处理您当时的请求与凭据， 请以该供应商发布的隐私政策与服务条款为准；扇贝对此不承担相应责任。 您此前自行配置 BYOK 凭据所产生的费用与合规义务，仍由您自行承担。
4.4
扇贝翻译扩展中的使用统计事件、错误监控数据
均不应包含 API Key、Base URL、模型名等用户凭据
； 扩展自始使用统一的脱敏白名单对该等字段进行过滤后再上报，功能下线后亦然。 如您发现上述凭据出现在我们的统计或监控数据中，请通过本政策第十二章载明的方式联系我们，我们将按事故响应流程处置。
第五章 如何使用 Cookie 和同类技术
扇贝翻译扩展依赖
扇贝账号系统下发的 Cookie
（由 apiv3.shanbay.com 域签发）完成账号身份识别与请求鉴权。 扇贝翻译辅助页面网站可能使用浏览器 Cookie 与本地存储等同类技术保存您的偏好与会话状态。 您可以通过浏览器自身的设置管理或清除上述 Cookie， 但这可能导致您需要重新登录或部分功能不可用。
第六章 如何共享、转让、公开披露您的个人信息
共享

第七章 如何保护您的个人信息
7.1
扇贝采取符合行业标准的安全防护措施保护您的个人信息，防止数据遭到未经授权的访问、公开披露、使用、修改、损坏或丢失：
您的浏览器与扇贝服务器之间的网络通讯采用 HTTPS / TLS 进行传输加密；
BYOK（自带模型）功能下线前您输入的 API Key 在浏览器本地以 AES-GCM 加密存储， 扇贝服务器自始不存储该等密钥；
扇贝内部仅允许有必要知晓的人员访问相关个人信息，并设置严格的访问权限控制与监控机制。
7.2
扇贝会采取一切合理可行的措施，确保不收集与提供产品或服务无关的信息。
7.3
请您理解，由于技术的限制以及可能存在的各种恶意手段，在互联网行业， 即便竭尽所能加强安全措施，也
不可能始终保证信息百分之百绝对安全
。 您接入扇贝翻译产品或服务所用的系统和通讯网络，有可能因扇贝可控范围外的其他因素而出现问题，在此情形下，扇贝会依法尽力协助解决。
7.4
