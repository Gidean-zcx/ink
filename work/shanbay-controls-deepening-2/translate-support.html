扇贝翻译帮助与支持

更新日期：2026-09-14

扇贝翻译是一个浏览器扩展，把「读英文」和「学英文」接在一起：读网页时顺手翻译，遇到生词当场查、当场收进扇贝生词本。本页汇总安装、登录、会员订阅与常见问题；没有找到答案时，请通过页尾的方式联系我们。

一、安装与启用

1.1 Safari（Mac App Store）

  1. 从 Mac App Store 安装「扇贝翻译 Safari浏览器插件」并打开一次。
  2. 在 Safari 菜单栏选择「设置」→「扩展」，勾选「扇贝翻译」。
  3. 点击 Safari 工具栏上的扇贝翻译图标，选择「在所有网站上允许」——Safari 对网站权限逐站授权，不做这一步扩展无法读取网页内容。

1.2 Chrome / Edge

在 下载页选择对应商店安装；安装后工具栏会出现扇贝翻译图标，无需额外授权步骤。

1.3 开始使用

打开任意英文网页，点击页面上的悬浮球或工具栏图标即可整页翻译；把鼠标停在单词上弹出词卡，选中一段文字弹出划词翻译。

二、登录与账号

2.1 登录

整页翻译、查词与生词本同步需要登录扇贝账号。点击工具栏图标，在弹窗底部选择「登录扇贝账号」。Safari 版在登录页额外提供「通过 Apple 登录」。

2.2 会员与账号的关系

会员是账号型服务：每日积分按扇贝账号计算，网页版与浏览器扩展通用，换电脑登录同一账号即可继续使用。

2.3 注销账号

扩展内路径：工具栏图标 → 齿轮「设置」→「账号」→「注销账号」；也可直接打开账号注销页。注销会删除扇贝账号及全部学习数据；若已通过 App Store 订阅会员，请先在 Apple ID 的订阅设置中取消续订，否则 Apple 仍会按周期扣费。

三、会员与订阅

3.1 通过 App Store 订阅（Safari 版）

  • 购买入口：工具栏图标 → 弹窗头部「升级会员」，会弹出扇贝翻译 App 的购买窗口，在其中用 Apple ID 完成购买。订阅名称、周期、当地价格与自动续订说明都在该窗口展示。
  • 管理与取消：打开 Apple ID 的订阅设置，或 App Store →「账户设置」→「订阅」。取消后当期权益保留至到期日。
  • 退款：通过 App Store 完成的交易由 Apple 依其政策受理，扇贝无法直接操作，请在 Apple 的「报告问题」页面提交申请。
  • 恢复购买：换电脑或重装后，在扩展「设置」→「账号」点「恢复购买」，或在购买窗口页脚点「恢复购买」；需已登录购买时使用的扇贝账号。

3.2 通过网页购买（其他浏览器）

在 会员页按套餐一次性购买，到期不会自动扣费。

3.3 两种渠道同时存在

同一账号在不同渠道购买的会员，到期时间取较晚的那个，不叠加天数。规则详见会员服务协议。

四、常见问题

4.1 页面上看不到悬浮球 / 翻译没有反应

请先确认扩展已启用并已允许访问当前网站（见第一章），然后刷新页面再试。

4.2 提示积分不足

每日积分在北京时间每天 04:00 重置；需要更高额度可开通会员。积分是按模型折算的额度，不等于字符数。

4.3 购买后会员没有生效

请确认已在扩展内登录扇贝账号：购买发生在 App，会员绑定在账号上，登录后会自动绑定并刷新。如仍未生效，点「恢复购买」；同一笔交易只能绑定一个扇贝账号，若已被其他账号使用请联系我们。

4.4 生词本没有同步

生词本与扇贝账号绑定，请确认扩展内登录的账号与扇贝 App 一致。
