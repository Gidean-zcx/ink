 How To Send SMS and MMS Messages on Mudita Kompakt
 Modified on: Fri, 2 Oct, 2026 at 2:16 PM
Send SMS Message to a contact:
Tap SMS
Tap the Pencil icon
Select the contact you want to message
Enter your message*
Tap the Send icon
*If the keyboard does not appear, tap the blinking cursor
Send SMS Message to a new number:
Tap SMS
Tap the Plus icon
Enter the phone number
Tap send to: xxxxxxxxxxx
Enter your message*
Tap the Send icon
*If the keyboard does not appear, tap the blinking cursor
Send MMS Message to a contact:
Tap SMS
Tap the Plus icon
Select the contact you want to message
Tap the Image icon
Select the image you want to send
Tap Send
Send MMS Message to a new number:
Tap SMS
Tap the Plus icon
Enter the phone number
Tap send to: xxxxxxxxxxx
Tap the Image icon
Select the image you want to send
Tap Send
How to delete conversations:
Tap SMS
Tap the Pencil icon
Select the conversations you want to delete
Tap Delete
Tap Delete
