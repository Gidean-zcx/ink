MuditaOS K 1.6 
The latest update to MuditaOS K (version 1.6) introduces a range of meaningful 
improvements focused on usability, system stability, and user privacy. Staying true 
to its minimalist philosophy, Mudita continues to refine the experience while 
adding features that enhance everyday use.   
 
 
MuditaOS K 
●​ Added security patches, including fixes for vulnerabilities related to privilege 
escalation, cross-profile information disclosure, media parsing. 
●​ Added a global "Notification vibration" toggle in the Vibration and Haptic 
section that lets you turn off vibration for text messages, calendar and 
third-party alerts with a single switch 
●​ The documents in the legal section are now displayed with the improved 
formatting 
●​ Fixed the save button for hotspot setting without a hotspot name 
●​ Fixed the possibility to make factory reset with incorrect password 
●​ Fixed the PIN requirement when restarting phone with Offline+ turned ON 
●​ Fixed the FCC ID missing name and logo 
●​ Fixed the keyboard behavior when crash popup is displayed 
●​ Fixed the Cancel button for double SIM card enabling scenario 
●​ Fixed the overflow of the optional eSIM deletion option 
●​ Fixed the screen brightness when the device is turned off and battery 
charge is 100% 
●​ Fixed the message after the incorrect PUK attempt 
●​ Added information about remaining attempts of PUK code 
 
Alarm
