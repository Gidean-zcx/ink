 Mudita Center Software Release Notes
 Mudita Center 4.0.0
 Modified on: Thu, 17 Sep, 2026 at 1:12 PM
With this release, the Mudita Center introduces below changes:
The users will be able to download or delete a photo from the preview screen. 
In the backup and restore feature we added the Calendar events.
In the files manager the Apk files now have the status showing if the application is already installed or ready for install.
When sending the customer support ticket, the user is now able to download the log file that is attached to the ticket by default.
Coming with the MuditaOS K 1.5.0 - In the Contacts, we added the dedicated section to identify and merge the duplicated contacts.
We also have rebuild the application from scratch, so the code is based on the newest solutions providing stable and improved support for new operating systems, native support for MacOS with M series chips, improved Kompakt interface that allows faster data transfer, and some small interface improvements.
