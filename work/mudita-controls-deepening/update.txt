 How To Do System Updates on Mudita Kompakt
 Modified on: Sat, 3 Oct, 2026 at 8:43 AM
How to update MuditaOS K on Kompakt
When an update is available for Kompakt, you will see a notification at the top of the Control Center screen. You can also manually check for updates.
Tap New MuditaOS K update is available
Tap Update
If needed: read, Tap the Check box and tap Agree to the licence agreement
The update will download and configure automatically
Tap Restart phone
How to manually check for MuditaOS K updates on Kompakt
Make sure Kompakt is connected to the internet
Touch the Control Center button
Tap the Settings icon
Tap About
Tap Software Update
If an update is available, you can update MuditaOS K
An OS (Operating System) update fails on Kompakt
There are a few things you can try if an update fails, a factory reset should be the last resort!
Try the update again
Check you have a stable internet connection
If you don't have Wi-Fi, check that you allow downloads using data
Restart the the device
Do a factory reset
If none of the above fix the problem, contact customer support
