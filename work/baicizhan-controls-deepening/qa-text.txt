TEXT 1.积分获取方式
TEXT 可以通过充值、完成每日阅读计划、每日知识点练习题全对、邀请好友获得积分。
TEXT 2.积分用途
TEXT 积分可以解锁文章的官方翻译、查看深度讲解、兑换优惠券、兑换爱阅读会员，还可以用于补打卡。
Q 29 如何邀请好友？
TEXT 如何邀请好友？
TEXT 将爱阅读页面下方【我的】- 【好友邀请】中的邀请码复制发送给好友，好友在爱阅读页面下方【我的】 - 【好友邀请】 -【 填写邀请码】里填写大侠的邀请码并确认后即为邀请成功。

Q 30 如何查看我的会员期限？
TEXT 如何查看我的会员期限？
TEXT 在爱阅读页面下方【我的】 - 【Scholar会员】中查看会员剩余天数和到期时间。
IMAGE https://7n.bczcdn.com/qa/img/qa_1587365887_585.png
Q 31 会员权益有哪些？
TEXT 会员权益有哪些？
TEXT Scholar会员拥有官方翻译、深度讲解、会员专属专辑、专属朗读评分、积分获取加速、商城代金券六大专属权益，各权益的详细内容可以在爱阅读页面下方【我的】 - 【Scholar会员】中查看。
IMAGE https://7n.bczcdn.com/qa/img/qa_1587365887_275.png
Q 32 如何重新评定我的阅读水平？
TEXT 如何重新评定我的阅读水平？
TEXT 在爱阅读页面下方【我的】 - 【阅读水平】中点击【重新测试】。再次完成词汇量测试后，系统会根据大侠的测试结果重新评定阅读水平。
IMAGE https://7n.bczcdn.com/qa/img/qa_1587365887_299.png
Q 33 如何调整阅读界面背景颜色/字体大小？
TEXT 如何调整阅读界面背景颜色/字体大小？
TEXT 在文章阅读页面下方点击【A】按钮，跳出工具栏，可以根据所处环境和使用习惯自行修改阅读页面的背景颜色和字体大小。
IMAGE https://7n.bczcdn.com/qa/img/qa_1587365887_410.png
Q 34 如何修改头像/昵称？
TEXT 如何修改头像/昵称？
TEXT 爱阅读APP中暂时不支持修改头像和昵称，大侠可以在百词斩APP中登陆同一个帐号，点击百词斩主页面下方【我】 - 右上方【头像】，进入【个人资料】页面进行修改，修改完成以后爱阅读的头像会同步更改。
