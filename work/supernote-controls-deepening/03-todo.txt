Supernote is all about boosting your productivity. To help you do just that, we are introducing a new app: To-Do. It allows you to effortlessly track and manage your tasks. In this article, we will delve into how to maximize the To-Do app's potential.
Create a To-Do list
Slide down on the right sidebar (assuming you are in the right-handed mode) to open the sidebar menu.
Tap the
To-Do
app to open it.
At the bottom left corner of the screen, tap

New List
popup window.
Write a description for your list in the text entry field.
Tap
Create

To-Do lists you create will show up under the Completed
list in the left pane where up to 13 lists can be displayed. Once you've created 13 lists, a scrollbar will appear on the right side of the pane. It allows you to easily navigate through all your To-Do lists, especially helpful when you add additional lists after the initial 13.

Create a To-Do task
You can do this directly in the To-Do app.
Open a list you've created yourself or open one of the three predefined lists, including Inbox, Planned and All.
In the text entry field, enter a name for the To-Do task you are about to create. Make sure not to include special characters, such as emojis, in the name.
Set a due date for the task by tapping the Calendar
icon to the right of the task name.
This opens the date picker where you can proceed to select the due date.
Tap
Add
to create the To-Do task.
If you create a task from the Planned
list without setting a due date, it will not be displayed in the Planned
list, but instead will appear in the All
list.
Alternatively, you can follow these steps to create a To-Do Task.
Open a notebook.
Start handwriting. (This step may be skipped if there is already handwriting in the notebook.)

Tasks created this way will be marked with a Note

The Inbox

Edit To-Do tasks
Mark a task as Completed
Open a list that contains the task you want to mark as completed.
Tap
to the left of the name of the task.
This moves the task to the Completed
list. And there will be a strikethrough across the task name indicating the completed status as well.
To undo the Completed status, simply tap

Hide or display completed tasks
Take the Completed
list for example:
Tap the Completed
list in the left pane.
To hide the completed tasks in a specific list, tap the Down arrow
.
To display them, tap the Right arrow
.
Tasks that you mark as Completed from the other lists (excluding Planned and All) will be displayed in the Completed section in those respective lists. You can follow the same steps above to hide or display them.
If the completed tasks (and the uncompleted tasks) fill one full page, adding more tasks to the same list will make a scrollbar appear on the right side, allowing you to scroll up and down to navigate to your desired task quickly.

Move a task to a different list
There are two ways you can do this.
Method 1:
Open a list that contains the task you want to move.
Locate the task and long press it to open the top function bar.
Tap the Move
button.
In the popup window that opens subsequently, select a list you want to move the task to.
Method 2:
Open a list that contains the task you want to move.
Tap the task you want to move to select it.
Tap
.
In the popup menu, select a list you want to move the task to.
Set a due date for your tasks
Open a list that contains the task you want to set a due date for.
Tap the task you want to set a due date for to select it.
Set a due date for the task by tapping the Calendar
icon.
This opens the date picker where you can proceed to select the due date.
Tap OK.
Tasks with a due date will be listed in the Planned
list,  with their status set to “Today" if the due date is the current date, or “Overdue” if the due date has already passed, or “Upcoming” if the due date is still in the future. This can help you quickly prioritize your work and stay on top of deadlines.
