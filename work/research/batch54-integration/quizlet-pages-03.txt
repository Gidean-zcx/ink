L13: # Studying with Study Groups
L14: 
L15: Study Groups allow you to collaborate with classmates or friends directly on Quizlet. You can create or join a group to track your progress, invite others, and study together in real time.
L16: 
L17: To create a study group
L18: 
L19:   1. 【9†Log in†quizlet.com】 to your account.
L20:   2. Open a set.
L21:   3. Select Groups at the top of the set page.
L22:   4. Select Create group.
L23:   5. Enter a name for your group.
L24:   6. Copy the invite link and share it with friends or classmates.
L25: 
L26: To join a study group
L27:   1. Select the invite link you received.
L28:   2. If logged out, 【9†log in†quizlet.com】 to your account.
L29:   3. Review the invitation pop-up.
L30:   4. Select Accept Invite to join the group.
L31: 
L32: To add a set to an existing group
L33: 
L34:   1. From any set page, select Groups.
L35:   2. Select the group(s) you’d like to add the set to.
L36:   3. Select Done.
L37: 
L38: Settings and options
L39:   * Groups are limited to 8 members.
L40:   * Use the Groups dropdown to move between study groups.
L41:   * From the group details page, select the three-dot menu next to your name and choose Leave group.
L42: 
L43: Tips
L44: 
L45:   * With 【10†Track Progress】 enabled, you can see how group members categorized cards into Know and Still Learning.
L46:   * Study Groups are currently only available for 【11†public sets】.
L47:   * You can join more than one study group and switch between them as needed.
