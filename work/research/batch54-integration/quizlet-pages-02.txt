L13: # Trouble accessing a set
L14: 
L15: All flashcard sets on Quizlet are created by individual students and teachers.
L16: 
L17: When you create a set, you can make it 【9†password-protected】 or 【10†visible only to certain people】. When you search for sets, you may see some that are only visible to select people.
L18:   * If the set you're trying to access is part of a class you're in, you may need to 【11†log in†quizlet.com】 to your account to access it.
L19:   * If the set is password protected, you can ask the creator for the password.
L20:   * If a set is private and visible only to the creator, then it's unavailable to other Quizlet users. In this case, you may want to 【12†search for public sets】 on your topic of interest.
L21:   * If you’re trying to access a set on your mobile device that you created on the website, or vice versa, it must be published to sync across devices. If you created a set but can’t see it, make sure it’s published before you try to study or edit it from a different device. Find out more about 【13†editing draft sets】.
