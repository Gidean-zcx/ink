L14: 
L15: 【8†IOS】 【8†Web】 【8†Android】
L16: 
L17: Embedding sets into a website students or other learners already visit regularly is a great way to share study content. You can embed public sets in Match, Learn, Test, Flashcards, and Spell mode.
L18: 
L19: To embed a set
L20:   1. 【9†Log in†quizlet.com】 to your account.
L21:   2. Select Your library.
L22:   3. Select Flashcard sets.
L23:   4. Open the set you want to embed.
L24:   5. Select【10†Image: More_menu_-_iOS_-_Resized.png】 (more menu).
L25:   6. Select Embed.
L26:   7. Select the activity you want to embed.
L27:   8. Select Copy HTML.
L28:   9. Add the copied HTML to your class website or LMS page.
L29: Once you've embedded the set, others can study it in the activity you selected, or they can study the set with any other activity by clicking Choose a Study Mode. They can also select View this flashcard set to see and study the set on Quizlet.
L30: 
L31: Embedded sets include the Quizlet logo, and that cannot be removed.
L32: You can currently only get the embed code for a set on the website. Log in to your account from your mobile browser and then click the Web icon above and follow the instructions for embedding a set.

L20:

L22:   1. Go to System preferences.

L25:   4. Select the microphone you want to use.
L26:   5. Test your microphone.
L27: Make sure that Use ambient noise reduction is turned on.
L28: 
L29: Windows
L30:   1. Open your sound settings and choose the microphone you want to use.
L31: In Windows 7, select the Speaker at the bottom of the screen, and select Recording devices.
L32: In Windows 8, select the Control Panel and then select More settings.
L33:   2. Select Properties.
L34:   3. Select Levels to check and adjust the input volume.

L37:
