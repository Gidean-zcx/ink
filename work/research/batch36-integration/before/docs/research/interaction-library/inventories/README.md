字段约定：

- `entry_id`：稳定目录项编号；同一上游数字在不同栏目出现时保留类型前缀。
- `scope`、`entry_type`：适用范围与入口类型；目录当前可见不等于内容所示版本当前有效。
- `title`、`upstream_id`、`url`：短标题、原站编号与原始定位。
- `evidence_id`：支持目录项存在或正文结论的证据，多个编号以分号分隔。
- `review_status`：只读目录、已读带型号条件的文字等实际状态；没有连续观察就不能记为已观看。
- `related_flow_ids`：已有相关任务，不表示任务或所有分支已完成；空值表示尚未映射。
- `checked_on`：本次查阅日期。
