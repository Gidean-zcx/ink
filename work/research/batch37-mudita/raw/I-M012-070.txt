How to Allow or Stop Downloads Using Mobile Data?
Modified on: Sat, 3 Oct, 2026 at 8:34 AM
If you stop Kompakt from using mobile data, downloads will only work over Wi-Fi. This is useful if you have a limited data plan or want to avoid high data charges.
Open Control Center and tap Settings.
Go to Network & Internet.
Tap Mobile Network.
Toggle Mobile Data on or off to allow or stop Kompakt from using mobile data.
