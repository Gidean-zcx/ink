L13: # Create flashcard sets directly in ChatGPT
L14: 
L15: The Quizlet app in ChatGPT makes it easy to turn a conversation into flashcards in seconds – so you can go from learning something new to studying it effectively without breaking your flow.
L16: 
L17: Whether you’re exploring a new topic, preparing for a test, or working through homework, Quizlet meets you right where your learning starts.
L18: 
L19: With the Quizlet app in ChatGPT you can:
L20:   * Use ChatGPT to explore concepts, break down topics, or ask questions
L21:   * Instantly turn that information into organized flashcards
L22:   * Continue studying on Quizlet using tools designed for long-term learning and retention

L24: How it works
L25:   1. 【9†Connect the Quizlet app in ChatGPT†chatgpt.com】.
L26:   2. Start your prompt in ChatGPT by typing “@Quizlet” and then the flashcards you need (e.g. “@Quizlet create flashcards for my microbiology exam.”)
L27:   3. ChatGPT automatically converts your conversation into a complete Quizlet flashcard set
L28:

L30: When you’re ready to study further, select the option to open your set in Quizlet. From there, you can:
L31:

L27: ## Error checking options in Learn
L28: 
L29: When you’re studying on the website, error checking options are available in sets that have three or more cards and with terms and definitions in English, French, German, or Spanish in Learn.
L30: 
L31: Relaxed
L32: 
L33:   * The general meaning of your answer is accepted as correct. Synonyms, rephrasing, and typos are also accepted.
L34:   * This level is selected by default if the set meets the error checking options requirements and both sides are in your default language.
L35: 
L36: Moderate
L37:   * An exact match is required, but minor misspellings such as accent mark errors or missing letters are accepted.
L38:   * Available when both sides of the set are in the same language and the language is not one that is graded strictly (Chinese, Japanese, math, chemistry, Akkadian, or photo-only sets).
L39:   * This level is selected by default if Relaxed isn’t available and the set doesn’t default to Strict.
L40: 
L41: Strict
L42:   * An exact match is required. Only small stylistic mistakes like case or punctuation differences are accepted.
L43:   * Always available.
L44:   * This level is selected by default if the set has different languages on each side (for example, language learning sets).
L45: 
L46: To choose a Error checking option in Learn
L47: 
L48:   1. 【11†Log in†quizlet.com】 to your account.
L49:   2. Open a set.
L50:   3. Select Learn.
L51:   4. Select Options.
L52:   5. Select Error checking options.
L53:   6. Choose an error checking option.
L54:   7. Select Save.
L55: ## Error checking options in Test
L56: 
L57: If a set includes terms that have multiple definitions or answers, you can change your error checking settings to require one or all answers in Test.
L58: 
L59: To choose a Error checking option in Test
L60: 
L61:   1. 【11†Log in†quizlet.com】 to your account.
L62:   2. Open a set.
L63:   3. Select Test.
L64:   4. Select Options.
L65:   5. Select Error checking options.
L66:   6. Check Require 1 answer only.
L67: This will mark answers correct if they contain at least one of the correct options included in a definition.
L68: Multiple correct answers in a definition must be separated by a comma, slash, or semicolon for single-answer error checking to work.
L69: ## Settings and options
L70: 
L71:   * Single-answer error checking is available for Test.
L72:   * Once you turn on single-answer error checking for a set, that preference is also set for all other activities. To disable it, click Options and then uncheck Require 1 answer only.
