L13: # Create flashcard sets directly in Claude
L14: 
L15: The Quizlet connector for Claude makes it easy to generate flashcards in seconds — so you can go from learning something new to studying it effectively without breaking your flow.
L16: 
L17: Whether you're prepping for a test, squeezing in a quick review, or creating a classroom game for your students, Quizlet meets you right where you are.
L18: 
L19: With the Quizlet connector in Claude you can:
L20:   * Create a flashcard set and start studying directly in your Claude conversation
L21:   * Continue studying on Quizlet using interactive study modes for deeper learning
L22:   * Turn your flashcard set into an activity for your students (by opening the set in Quizlet)
L23: 
L24: How it works
L25:   1. Connect Quizlet in Claude (Settings → Connectors → Quizlet, or add it when prompted).
L26:   2. Ask Claude for flashcards (e.g. "Create flashcards on photosynthesis.") or upload a file or your notes to have Claude and Quizlet build the cards from your class
L27:   3. Claude automatically creates a complete Quizlet flashcard set which can be reviewed in Claude or opened in Quizlet for more study modes
L28: Once your set is created, you'll see your flashcards directly in Claude that you can flip through and begin studying.
L29: 
L30: When you're ready to study further, select the option to open your set in Quizlet. From there, you can:
L31: 
L32:   * Edit and personalize your flashcards
L33:   * Study your flashcards in any of the study modes
L34:   * Practice, review, and build mastery
L35:   * Share your flashcard set with others or turn it into a group activity
L36: For teachers, select the option to open your set in Quizlet. From there, you can:
L37: 
L38:   * Review and edit flashcard content
L39:   * Turn your flashcard set into a free in-class or at-home assignment in seconds
L40:     * Choose between flashcard review, games, or practice tests
L41:     * Afterwards, easily monitor class performance in Quizlet

L13: # Combining flashcard sets
L14: 
L15: 【8†IOS】 【8†Web】 【8†Android】
L16: 
L17: You can study several topics together or make a new set by combining several existing sets. Saving a combined set just creates a new set and doesn't delete the original sets.
L18: 
L19: To combine sets
L20:   1. 【9†Log in†quizlet.com】 to your account.
L21:   2. Go to the first set you want to use.
L22:   3. Select 【10†Image: More_menu_-_iOS_-_Resized.png】 (more menu).
L23:   4. Select Combine.
L24:   5. On the Combine sets page, add sets by selecting the + icon.
L25:   6. Select Create a set from the dropdown menu on the left.
L26:   7. Select Go to save your combined set.
L27: To start studying the two sets without saving them as a new set, select the study activity you want from the dropdown menu, and select Go. Once you exit that study activity, the combination is not saved.
L28: 
L29: Tips
L30:   * As you combine sets, their titles show up in the left column.
L31:   * You can make combinations from your sets, folders, or classes by choosing one from the Combine dropdown menu. You can also search for sets in that menu if you want to add new content.
L32:   * If you're using the free version of Quizlet, you can only combine sets that use basic features. To combine sets that have 【11†premium subscriber features†quizlet.com】 (like rich text editing or custom audio and images), you must be subscribed to 【11†Quizlet Plus†quizlet.com】 or 【12†Quizlet Plus for teachers†quizlet.com】.
L33: Currently, you can only combine sets on the website. Once you've created and saved a new combination, you can study and edit it in the iOS app.
L34: 
L35: Currently, you can only combine sets on the website. Once you've created and saved a new combination, you can study and edit it in the Android app.
