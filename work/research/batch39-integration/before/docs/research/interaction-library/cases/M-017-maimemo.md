## 分支与证据冲突

- **离线**：现行专页只承诺个别功能可离线，获取新词、同步需联网；没有列出完整离线可用题型。不能由旧印象写成“全部背词可离线”。E-MMO-06。
- **跨书与删除**：同一词在不同书共享记忆状态，换书不代表清空历史。删除清除记忆历史，与不再安排复习不是一回事。E-MMO-03、07。
- **旧规则修正**：旧 help30 写认识最长间隔一年；本轮新 FAQ 写最长间隔无固定。保留旧证据 E-MMO-12，按新 FAQ 描述本轮行为；未推断服务端何时切换。新日学习量帮助也不足以穷尽日志中“固定值/最大值”等设置。
- **版本日志**：iOS 日志本轮顶部止于 5.4.40；不能因此断言当前最高仅 5.4.40。5.3.86 记录固定/最大复习量，5.3.80/96 记录多设备不同步提示，说明相关体验变过，但不揭示合并策略。E-MMO-11。
- **版本不齐**：2026-10-27 复查 iOS 日志顶部仍为 5.4.40，非现行最高版本证明。HarmonyOS 日志顶部是 5.5.19.0069（2026-10-10）；2025-04-22 曾增加暂停、回顾中英/英中/听写，2025-07-08 增加滑回上词，2026-07-31 增加分散压力及时区控制。日志没有写错评如何撤销、暂停是否持久保存或跨日怎样恢复。E-MMCD-12。
- **负荷口径**：固定新学量 FAQ 表达建议，而旧 iOS 日志明确记录过固定量设置；不能把“为什么不设定”标题解释成产品不提供。E-MMCD-13、E-MMO-11。
- **签到与奖励**：历史最长连签大于当前连签时，签到右侧才显示补签卡入口；文档描述补缺日后重算连续天数。签到失败建议换网络，再走失败页客服或帮助中心人工客服。补签修复的是记录，不能证明补学、掌握或获得相同奖励；发卡、日界线与奖励消耗仍未知。E-MMCD-03/04。
- **声音故障（iOS）**：“我的→更多设置→音效震动开关”可设静音时发音；蓝牙多端连接造成动画有而偶无声的情况，官方建议断开其他端后重进 App 测试，并对比外放。只是排障建议，没有本轮恢复成功记录。E-MMCD-11。
- **PDF 的不同失败范围**：开头笼统写设备故障等损耗不补偿，第八节又给闪退保留资格，判定边界没有解释。内容优先取自本地加载/自选，缺少时使用默认内容；例句的三种显示方式与笔记区互斥；不能把预览当全本，也不能把生成当已保存。E-MMCD-08。
- **内容变化与冲突**：自动选中的内容会随赞值/作者/标签变化；固定选择与筛选不同。超级释义介绍同时写已有考点与未来频次计划，专页明确现有考研范围；不把计划扩展为其他考试已可用。AI 辅助中文注释可能与例句不匹配，例句三点有“标翻译”反馈入口，处理结果未知。E-MMCD-06/07。
- 空词本、断网保存、进程中断、跨日处理与拼写误判，仍无完整状态转换证据。墨墨记忆卡的暂停/反馈教程和单词机的误按处理都未用于填补这些空白。

## F07 的公开契约边界

依据 E-MMCD-10 的 `info.description`、`paths` 及 `components.schemas`，只读 `OpenAPI 3.1.0 / v1` 文件。登记的 24 个软件方法不含记忆卡。

| 对象/条件 | 可核定的契约与缺口 |
| --- | --- |
| 内容与词本 | 词汇、释义、助记、例句、词本有独立对象。建/改词本的 status/content/title/brief/tags 与入学习计划分开；删除不证明可恢复 |
| 学习读写前提（公测） | 读写均需自动同步；Progress、TodayItem、Record 分开；当天未打开 App 初始化时今日数据不准或不可取。finished 是完成数；study_count 每日最多计一次，不能解释为答题总次数或掌握度 |
| 学习写入（公测） | add_words 最多1000词；advance=true 无等级限制。单独 advance_study 则需 LVL10，未加入词会影响返回数量。两种入口条件不能合并 |
| 频控 | 20次/10秒、40次/60秒、软件2000次/5小时；释义/例句/助记合计每日最多创建600条。数值是文档限制，不是实测吞吐量 |

平台指南另说明按被授权用户跨应用合计限流，应用需审核；前端 PKCE 与后端 Auth Code 路径分开，同一人的 sub 在不同应用不同。精确 scope 以申请页为准，本轮未进入。E-MMCD-09。规范多数方法只列 200；释义/助记删除甚至没有响应结构。失败码、重试等待、空结果、事务回滚、过期和幂等仍未知，不能把接口文档升级为“全功能 AI 可执行”或“恢复已验证”。

## 数据与学习激励（分析及推断）

事实：词条跨书共享，词本负责组织；学习好友帮助互看进度而不发额外奖励。自评标签和预估记忆图不是独立能力测试。好友功能与组队不能合并分析。E-MMO-03、08。

关联 G-001、G-002、R-016/019/021、H-004/005：AI 处理阅读生词时，应区分“整理为词本”“加入计划”“立即追加今日任务”；后三种行为的学习负荷不同。恢复误操作需要明确影响的是词本、选择状态还是记忆历史。给 AI 暴露一个“删除”按钮不够，需要返回删除范围和可恢复性。以上为本项目推断，不是选定墨墨 API 或算法。

补证后的本项目推断：AI 应把内容版本、固定偏好和本地缓存分开，导出前确认实际使用的内容；完成统计、主观自评和连续记录不能归并成“掌握”。API 提供返回字段只是执行后核对的依据，调用完成仍须检查成功数量、对象状态及同步边界。本轮没有选定这些设计。

下一项最小观察：固定平台和构建，以三词记录自评后返词、拼写错误、暂停跨日及离线恢复；再检查导出未保存退出与闪退是否区别处理。开放 API 的后续验证须另获账户授权，仅使用测试词本。本轮均未执行。
