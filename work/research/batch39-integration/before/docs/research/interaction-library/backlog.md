# 竞品研究缺口与后续取证

更新：2026-10-27。准确登记数量与当前案例见 [案例与覆盖索引](case-index.md)，逐流程的未解决分支见 [coverage.csv](coverage.csv)。**全部产品完整功能清单仍未核定；已查看静态图不等于连续流程或亲自操作。** 这些数量是覆盖台账，不是市场穷尽率或研究质量评分。

## 先补什么

优先补与两个核心目标及 5–6 岁使用者直接相关的交互：中文识字/背词的错题与提示、儿童游戏的一次完整回路、成人连续学习的恢复、个人新闻的选题与反馈、AI 跨应用执行。电子纸系统手势/显示、音频盲操、数据恢复并行保留。以下排序是研究安排建议，不是首版功能排序。

每个产品先确定具体型号、平台、地区、版本，再从目录/手册建立逐功能清单，标记“未查/文档/观察/实测”。目录中 seed_topics 只是线索。不能只收录容易找到材料的成功路径，也不能把没有找到的功能写成不支持。

## 每次取证怎样避免只剩宣传

1. 建目录：列功能及可见入口、前置设置、型号差异；保留未研究条目。
2. 找规则：优先手册/帮助/版本日志；宣传只负责功能发现，论坛/评测作为问题线索且核对版本。

4. 验分支：空数据、失败、离线、误操作、中断恢复、删除/更新；不能只录一条顺利路径。
5. 分析机制：学习的提示/反馈/奖励、新闻的筛选与去重、音频的状态归属，以及可供 AI 读取和执行的对象。
6. 形成可复用条目：更新 F 流程、E 证据和覆盖表，记录变更原因；实际设计引用编号而非印象。
