# 已知产品详细分析：目标与覆盖审计

开始：2026-10-26。用户目标：**完成目前已知产品的详细分析**。目标保持进行中；不能把完成一个批次或新增若干案例等同于完成目标。

## 当前深度，一眼看清

当前登记产品均为部分覆盖，尚无一组可称全部功能分析完成。实时数量统一取[生成的案例索引](case-index.md)，避免多份手工“当前统计”随批次更新而互相矛盾。下表解释证据的用途；后面的批次数字保留为历史快照。

| 证据层次 | 后续设计可怎样使用 |
| --- | --- |
| D1：发现功能，核心过程仍缺 | 只作候选和待查线索 |
| D2：依据文档等重建任务 | 比较有来源的步骤、条件和状态；不能声称已经操作产品 |
| D3：连续视觉过程 | 须连续观察同一任务；离散截图、剪辑或零散视频帧不足 |
| D4：有日志的实际操作 | 仅适用于记录的环境和动作；当前有界样本为公开网页，不能外推原生App或实体设备 |

尚无本项目手机/电子纸实机测试，未验证儿童实际使用效果。最明显的缺口仍是同型号/版本的完整主流程、错误与中断恢复、持久保存和实际操作体验。原目录正文读完也不能关闭这些缺口。

2026-10-27第38批的具体补证：The Week Junior原导航/搜索/书签任务续查，新增缩放和重排听读两条有限D4；37个状态包含同页关闭重开、两次浏览器重启、窄屏菜单及失败。音频未听取声音，第二次重启没有取得接续结果，原生App仍D1。已在[设计参考指南](design-reference-guide.md)增加跨新闻/音频的问题入口与恢复条件表。Tonieplay一次403获取失败单独登记，未计新增行为证据。全部产品仍部分覆盖。

从[按设计问题查依据](design-reference-guide.md)沿“问题 → 产品/版本 → F任务 → E证据 → 画面或日志 → 限制”取用。逐产品查漏看[功能目录](inventories/README.md)和[待核清单](backlog.md)；不需要按时间顺序读完全部简报。

## 范围基线

主目录 M-001～M-052 全部纳入，包含最初七个部分案例。此前待补目录中已经点名的 13 组已登记为 M-053～M-065：掌阅 Ocean/Smart/Tango、墨案 inkPalm/Mini/大屏、海信 A9/TOUCH/Hi Reader、小猿学练机/彩墨、Meebook、Tolino、Sony DPT、Fujitsu QUADERNO、华为电子纸、联想电子纸、山灵、iBasso、Astell&Kern。具体型号不明确的对象先取得官方产品/手册目录，再按型号和平台拆分；不能直接删去或用同品牌另一种产品代替。

听力专用机等仅有品类、没有具体产品名称的扩展线索继续保留，但不能虚构成已研究对象。当前数量不是市场穷尽率；后续用户补充或研究发现的新对象须显式记录。

## 什么证据能支持详细分析

| 项目 | 需要留下的内容 | 不足以证明完成的情形 |
| --- | --- | --- |
| 对象范围 | 型号/代际、平台、版本适用范围、地区、账户/套餐条件 | 把整个品牌或多个 app 合成一台设备 |
| 功能目录 | 按官方目录、设置、帮助及版本记录列功能域，逐项标注覆盖和出处 | 只选几个容易查到的卖点 |
| 完整任务 | 入口、前置条件、动作、反馈、状态/数据变化、结束和返回 | 仅写“支持阅读/学习/同步” |
| 分支 | 空内容、误操作、提示/重试、中断/重启、离线、删除与同步等适用分支 | 从常识补出竞品没有证据的行为 |
| 机制与代价 | 学习的提示/奖励/进阶，新闻的选题/反馈，音频的队列/位置，系统的手势/后台等 | 用活跃或宣传效果代替机制分析 |
| 可复用依据 | F/E 编号、短摘记、章节/页码、日期、来源方式，事实与推断分开 | 堆链接、不说明链接支持哪项行为 |
| 视觉与实际体验 | 对依赖布局/手势的判断，取得相应图像/连续演示或操作记录；说明观察方式 | 读图片说明即宣称看过；看视频即宣称亲自体验 |
| 项目关联 | 对成人、5–6 岁儿童、AI 全面访问/操作与 Plus 的启发及限制 | 把参考自动升级为需求，或提前做完整系统设计 |

没有公开依据的细节明确标未知，并记录已查来源和下一种取证途径。公开资料可以支持有边界的分析，不能证明触摸手感、实际时延、学习效果或所有异常。某个产品关键流程仍缺资料时，不以“已建文档”冒充详细分析完成。
