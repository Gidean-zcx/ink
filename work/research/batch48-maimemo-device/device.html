墨墨单词机

1、常见问题 / 快速上手

Q1：墨墨单词机如何进行开机激活与网络绑定？

单词机首次绑定激活请按以下步骤操作：

  1. 开机解锁：长按单词机右上方【电源键】开机并解锁屏幕；
  2. 准备网络：请确保手机连接至 2.4GHz 频段的 Wi-Fi（如无路由器，也可开启手机 2.4G 个人热点）；
  3. App 扫码绑定：打开手机「墨墨背单词 App」（请先升级到 5.5.96 或以上版本），依次点击【我的】页面 ➔ 右上角【单词机图标】 ➔ 选择【绑定单词机】，扫描单词机屏幕上的二维码即可完成绑定。

温馨提示：绑定成功后设备将自动同步词书数据，过程需数分钟，请确保蓝牙及网络连接稳定，切勿中途退出。

Q2：如何在单词机上更换想要背诵的词书？

更换词书需在手机端进行设置：

  1. 打开手机「墨墨背单词 App」，点击进入【我的】页面；
  2. 点击右上角【单词机图标】进入设备管理页面，选择【更换词书】并挑选您需要学习的词书；
  3. 选定后，单词机会自动同步新词书内容。同步期间请保持设备与手机的网络/蓝牙连接通畅。

Q3：如何让 APP 和单词机只学同一本书？

🌟 温馨提示：墨墨背单词 App 支持多本词书同时学习，而单词机仅支持单本词书学习。

更改【单词机】词书:

  1. 打开「墨墨背单词 APP」进入【我的】➔【单词机】，点击【更换词书】选择书籍完成换书；
  2. 「单词机」连接 Wi-Fi 后，进入【设置】➔【资源更新】即可。

更改【App】词书：

  1. 进入【选词】，在书籍列表找到「单词机当前正在学的书籍」，该书籍右侧【...】选择【学此词书】；
  2. 在【选词】页面，点击当前书籍右侧【...】选择【只背此书 - 移出记忆】；
  3. 进入【我的】➔【单词机】，点击【合并数据】；
  4. 使用「单词机」连接 Wi-Fi 后，进入【设置】➔【同步数据】即可。

Q4：如何调整每日学习量，或修改复习/新学分开模式？

可以直接在单词机上进行调整：

  • 调整学习量：
    • 若为合并模式：在「词书总览」页面，按【↑ / ↓】方向键即可增加或减少「每日学习量」；
    • 若为分开模式：在「词书总览」页面，按【← / →】方向键即可调整「新学量」。
  • 切换合并/分开模式：
    • 在单词机主界面，进入【设置】 ➔ 【学习设置】 ➔ 【每日复习量和新学量】进行切换设置。

Q5：如何切换“英中”或“中英”背词模式？

切换学习模式的路径为：

  • 在单词机主界面，依次进入【设置】 ➔ 【学习设置】 ➔ 【记忆模式】，即可根据您的习惯自由选择「英中模式」或「中英模式」。

Q6：背词时遇到已经掌握的词（熟知词）或不想背的词，如何处理？

可以在背词过程中通过长按对应按键进行标记：

  • 标记为熟知（不再安排复习）：长按【 〇 】键；
  • 标记为不想背（移出学习规划）：长按【 ✕ 】键；
  • 添加至收藏：长按【 △ 】键。

若不小心误标，如何恢复？

  • 请前往【主菜单】 ➔ 【单词回顾】 ➔ 进入对应单词的【单词详情页】，再次长按对应的按键即可取消该标记。

Q7：换书后，为什么显示新书籍里有 已学/熟知/不想背/暂停/收藏 的单词？

这是因为在单词机换书后，当新书籍的词汇中包含上本书已学的单词，依然会保留并显示该单词的学习状态。

如需清空单词状态：可在单词机或 APP 里对/熟知/不想背/暂停/收藏的单词进行取消标记（APP 操作后记得同步至单词机哦~）

如需移除单词记忆数据，可查看下面 Q8 的操作。

Q8：如何移出记忆？如何清空单词数据？如何重置？

🌟 温馨提示：当前版本单词机只支持词书里的单词设置为【不想背】，暂不支持把已学单词【移出记忆】，所以移出记忆、清空单词数据、重置单词数据操作需在 APP 里完成。

单个单词移出记忆【无等级限制】：

在 APP 复习页面或单个单词详情页的右上角 “…” 更多按钮，选择【移出记忆】，该单词的记忆数据会被清除。

批量移出单词 【 LVL 13 等级】：

4、核心功能

1. 【记忆算法】

墨墨记忆算法是基于心理学中的「间隔重复」理论，并结合大数据统计优化而成的记忆体系，通过海量真实记忆数据，精准评估单词难度和个人记忆能力，从而为用户定制更优复习时间，减少复习压力，提升抗遗忘效率。

了解更多记忆算法内容详见：

https://memodocs.maimemo.com/docs/2021_study

墨墨记忆算法核心学术论文，发表于数据挖掘顶会 ACM SIGKDD、期刊 IEEE TKDE：

A Stochastic Shortest Path Algorithm for Optimizing Spaced Repetition Scheduling

Optimizing Spaced Repetition Schedule by Capturing the Dynamics of Memory

2. 【今日复习】

用户可选择两种学习模式：英中模式和中英模式。英中模式侧重根据英文回忆中文释义，中英模式侧重根据中文回忆英文单词，从不同方向加深记忆。

每次复习时，用户将对单词进行记忆反馈：认识 / 模糊 / 忘记。墨墨记忆算法会结合反馈结果，自动安排后续复习时间，降低熟悉单词的复习频率，让易遗忘单词及时重复出现，从而达到更高效的抗遗忘效果。

复习页面会集中展示单词的核心学习内容，帮助用户在复习时快速回忆和理解。页面内容包括单词、音标和发音，方便用户掌握单词读音；同时提供单词例句，帮助用户理解单词在语境中的用法；还会展示单词助记，通过记忆提示辅助用户加深印象，提高复习效率。

调整学习模式路径：在单词机主界面，找到【设置 - 学习设置 - 记忆模式】，即可调整。

3. 【词书总览】

词书总览可查看当前学习词书的整体情况，包括词书单词详情、学习进度和相关学习数据，方便了解自己的背词状态。还可根据个人学习节奏，调整每日学习量、复习和新学为合并 / 分开。设置后，系统会按照新的学习量安排每日任务。

调整学习量路径：

合并模式下，在「词书总览」页面【点击 ↑、↓ 按键】调整「每日学习量」；

分开模式下，在「词书总览」页面【点击 ←、→ 按键】调整「新学量」。

修改复习和新学「合并 / 分开」路径：在单词机主界面，找到【设置 - 学习设置 - 每日学习量和新学量】 ，即可调整。

更改书籍：打开「墨墨背单词 App」，进入【我的页面 - 右上角单词机图标】，在单词机设置页找到「更换词书」即可换书。

4. 【随身听】

该功能通过播放单词内容的方式，让用户在聆听中回顾单词，帮助用户利用碎片时间进行复习，加深对单词内容的印象。

5、更多功能

1. 【遗忘曲线】

根据用户对单词的记忆反馈，结合墨墨记忆算法，生成个人遗忘曲线统计图，帮助用户了解自己的记忆变化和遗忘规律。

坚持使用墨墨的时间越久，系统积累的学习数据越丰富，遗忘曲线统计也会越精准，从而为后续复习安排提供更可靠的参考。

2. 【学习情况】

该功能会统计用户当日对单词的记忆反馈，包括认识、模糊、忘记三种情况。

通过统计图可直观查看当天学习单词的掌握分布，了解自己的记忆状态和复习效果。

3. 【记忆持久度】

该功能会根据用户已规划学习的单词，统计单词的记忆持久度，并以统计图形式展示不同持久度档位下的单词数量分布。

通过该统计图可以直观了解已规划单词在不同记忆持久度区间中的分布情况。

4. 【单词回顾】

该功能用于对已规划的单词进行回顾复习，帮助用户在正式复习之外再次熟悉单词内容。

回顾过程中不会记入单词反馈数据，不影响后续复习安排。目前单词机提供三种回顾模式：中英、英中、随身听，用户可以根据自己的复习习惯选择不同方式进行单词回顾。

5. 【设置单词状态】

用户可在「复习页面」/「回顾页面」/「单词详情页」通过长按反馈按钮设置单词状态：

标识熟知：长按「 〇 」按钮可将单词标识为「熟知单词」，标识为熟知的单词将不会再次安排复习。已熟知的单词在「单词详情页」长按「 〇 」按钮取消熟知。

添加收藏：长按「 △ 」按钮可将单词添加到「我的收藏」，已收藏的单词长按「△」按钮取消收藏。

标记不想背：长按「 X 」按钮可将单词标识为「不想背」，不想背的单词在选词时将不会被选入学习规划。已不想背的单词在「单词详情页」长按「 X 」按钮取消不想背。

复习页面【主菜单 - 今日复习】；回顾页面【主菜单 - 单词回顾】；单词详情页【主菜单 - 单词回顾 - 今日已学 / 我的收藏 / 全部词汇 - 按 进入单词详情页】。
