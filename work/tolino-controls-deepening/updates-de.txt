Software-Updates für Ihren tolino eReader
Wir arbeiten kontinuierlich an der Verbesserung unserer eReader Software und freuen uns, Ihnen regelmäßig Software-Updates zur Verfügung stellen zu können. Damit Sie stets das bestmögliche Leseerlebnis mit ihrem tolino eReader genießen können, sollten Sie die Software ihres tolino eReaders stets aktuell halten. Nutzen Sie dazu einfach unsere automatischen Software-Updates. Sobald Sie Ihren tolino eReader über WLAN mit dem Internet verbunden haben, werden Ihnen vorhandene Software-Updates direkt auf Ihrem Gerät angezeigt.
Die Tabelle unten zeigt Ihnen, welches Software-Update für Ihr eReader-Modell das zur Zeit gültige ist. Bitte überprüfen Sie vor dem Download anhand Ihrer Modellbezeichnung, über welchen Downloadlink Sie das für Ihr Modell passende Software-Update runterladen können. Bitte beachten Sie: andere eReader-Modelle würden durch die Verwendung einer falschen Software-Version beschädigt werden!

Manuelle Installation von Software-Updates
Um Fehler zu vermeiden, sollten Sie die manuelle Installation von Updates über den Computer nur in Ausnahmefällen vornehmen. Falls Sie doch einmal ein Software-Update ohne WLAN Verbindung auf Ihrem tolino eReader installieren möchten, gehen Sie wie folgt vor (für alle Geräte außer dem tolino shine – abweichende Anleitung unten*):
Klicken Sie auf den Download-Button und speichern Sie die Datei mit dem Namen update.zip auf Ihrem Desktop ab. Bitte beachten Sie, dass die Datei von Ihrem tolino eReader nur unter diesem Dateinamen als Update-Datei erkannt werden kann.
Verbinden Sie ihren tolino eReader mithilfe des mitgelieferten USB-Kabels mit dem Computer und öffnen Sie im Datei-Explorer die Verzeichnisansicht TOLINO des eReaders.
Kopieren Sie nun die Datei update.zip von Ihrem Desktop bzw. individuellen Speicherort direkt in das Hauptverzeichnis ihres tolino eReaders. Trennen Sie danach die USB-Verbindung, indem Sie den tolino eReader am PC auswerfen.
Bitte warten Sie nun ca. 10 Sekunden, bis das Software-Update auf dem eReader verarbeitet wurde und starten Sie das Gerät nun neu, indem Sie den An-/Ausschalter für ca. 2 Sekunden drücken. Sobald das Kontext-Menü erscheint, bestätigen Sie hier bitte mit Neu starten. Das Software-Update wird nun automatisch installiert.
*Ausnahme: manuelles Software-Update für den tolino shine color und tolino shine (5. Generation)
Bitte notieren Sie sich die aktuelle Software-Version, so das Sie später überprüfen können ob das manuelle Update erfolgreich war.
Stellen Sie sicher das Ihr tolino eReader mehr als 20 % aufgeladen ist.
Verbinden Sie ihren tolino eReader mithilfe des mitgelieferten USB-C Kabels mit dem Computer und tippen auf Ihrem tolino eReader im Dialog „Computer erkannt“ auf „Verbinden“.
Klicken Sie auf den Download-Button der für Ihren tolino eReader passenden Software und speichern die heruntergeladene Datei auf Ihrem Computer ab.
Öffnen Sie im Datei-Explorer die Verzeichnisansicht des tolino eReaders. Ihr tolino eReader wird Ihnen als „eReader“  Laufwerk angezeigt.
Kopieren oder verschieben  Sie nun die heruntergeladene Update Datei (KoboRoot.tgz’ oder update.tar) in den Ordner „.kobo“. Um das Verzeichnis „.kobo“ auf Ihrem PC anzeigen zu lassen, ist es notwendig, dass Sie die Option „versteckte Ordner anzeigen“ auf Ihrem PC aktiviert haben.
Nachdem die Update Datei (KoboRoot.tgz’ oder update.tar) erfolgreich in den Ordner „.kobo“ kopiert wurde, trennen Sie die USB-Verbindung indem Sie den tolino eReader am PC auswerfen.
Einige Sekunden nach dem Auswerfen sollte Ihr tolino eReader automatisch neu starten und das Software Update durchführen.
*Ausnahme: manuelles Software-Update für den tolino shine
Klicken Sie auf den Download-Button und speichern Sie die Datei mit dem Namen update.zip auf Ihrem Desktop ab. Bitte beachten Sie, dass die Datei von Ihrem tolino eReader nur unter diesem Dateinamen als Update-Datei erkannt werden kann.
Verbinden Sie ihren tolino eReader mithilfe des mitgelieferten USB-Kabels mit dem Computer und öffnen Sie im Datei-Explorer die Verzeichnisansicht TOLINO des eReaders.
Kopieren Sie nun die Datei update.zip von Ihrem Desktop bzw. individuellen Speicherort in den extsd-Ordner ihres tolino eReaders. Trennen Sie danach die USB-Verbindung, indem Sie den tolino eReader am PC auswerfen.
Bitte warten Sie nun ca. 10 Sekunden, bis das Software-Update auf dem eReader verarbeitet wurde und starten Sie das Gerät nun neu, indem Sie den An-/Ausschalter für ca. 2 Sekunden drücken. Sobald das Kontext-Menü erscheint, bestätigen Sie hier bitte mit Neu starten. Das Software-Update wird nun automatisch installiert.
