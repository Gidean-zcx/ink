Onleihe auf tolino eReader einrichten
tolino unterstützt als offenes System die Onleihe. Im Folgenden erklären wir, wie Sie die Onleihe auf dem
tolino eReader nutzen können.
Bevor Sie mit der Einrichtung beginnen, stellen Sie bitte sicher, über welche tolino-Gerätegeneration Sie verfügen. Folgen Sie anschließend der entsprechenden Anleitung (A oder B).
Sollte Ihnen nicht bekannt sein, welches Modell Sie besitzen, können Sie diese Information im Menü unter „Einstellungen“ → „Geräteinformationen“ einsehen.
Aktuelle Geräte-Generation (Punkt A): Falls Sie eines der folgenden Modelle besitzen, nutzen Sie bitte die Anleitung für die neueste tolino-Generation:
tolino shine 5. Generation
tolino shine color
tolino vision color
Frühere Geräte-Generation (Punkt B): Alle anderen tolino-Modelle gehören zu den früheren Geräte-Generationen. Bitte folgen Sie in diesem Fall den Schritten unter Punkt B.
So stellen Sie sicher, dass Sie die für Ihr Gerät passende Anleitung nutzen, damit die Einrichtung reibungslos verläuft.
Klicken Sie einfach auf die passende Anleitung, um alle Schritte anzuzeigen:
Hier finden Sie die Anleitung A: Aktuelle Geräte-Generation:
I. Onleihe öffnen
Tippen Sie auf dem Startbildschirm auf „Mehr“ und wählen Sie dann den Menüpunkt „Onleihe“ aus.
Stellen Sie sicher, dass eine aktive WLAN-Verbindung besteht. Falls nicht, verbinden Sie sich zuerst mit dem Internet.
Der Startbildschirm der Bibliotheksauswahl öffnet sich. Tippen Sie auf den Knopf „Bibliothek auswählen“.
Geben Sie den Namen Ihrer Stadt oder Ihrer Bibliothek in das Suchfeld ein. Tippen Sie auf den richtigen Namen in der Liste, um sie auszuwählen. Sie werden nun zur Anmeldemaske Ihrer Bibliothek weitergeleitet.
II. In der Onleihe anmelden
Melden Sie sich mit Ihren Zugangsdaten an. Tippen Sie zur Eingabe in das jeweilige Feld und geben Sie Ihre Kennung und Passwort Ihres Bibliothekskontos ein.
Tippen Sie nach der Eingabe aller Anmeldedaten auf „Anmelden!“.
Je nach Bibliothek bietet Ihr tolino an, die Zugangsdaten zu speichern, um spätere Log-ins zu erleichtern.
Ihre Bibliothek ist jetzt gespeichert. Wenn Sie die Onleihe-App das nächste Mal öffnen, können Sie Ihre Bibliothek direkt unter „Zuletzt ausgewählt“ antippen.
Hinweis: Sollten Sie Ihre gespeicherte Bibliothek einmal wechseln oder löschen wollen, geht das über das Menü „Mehr“ → „Einstellungen“ → „Konten“ → „Web-Browser-Daten“ → „Löschen“.
III. eBooks ausleihen, lesen und zurückgeben
Nach erfolgreicher Anmeldung aktualisiert sich die Seite. Sie sollten jetzt eingeloggt sein.
Über das Lupen-Symbol können Sie nach Titeln suchen. Hinter den Titeln ist jeweils angegeben, ob sie direkt ausleihbar sind oder auf die Merkliste gesetzt werden können. Sie können Titel auch vormerken, damit Sie diese direkt bei Verfügbarkeit erhalten. Ihre Bücherei berät Sie dabei gern. Wenn Sie einen Titel leihen möchten, tippen Sie auf die Schaltfläche „Ausleihen“ und bestätigen mit „OK“
Von der Bestätigungsseite über die erfolgreiche Ausleihe können Sie zurück und weitere Bücher leihen oder Sie können das Buch direkt öffnen und loslesen.
Titel zurückgeben: Tippen Sie in der Auswahl auf die „drei Punkte“ nun haben Sie die Möglichkeit diesen Titel zurückzugeben. Sie können das eBook aber auch direkt auf der „Startseite“ Ihres tolino bzw. innerhalb der Ansicht „Meine Bücher“ zurückgeben. Tippen Sie hierzu lange auf das jeweilige Buchcover. Im Menü, das sich öffnet, wählen Sie einfach „Zurückgeben“.
Hinweis: Auf dem tolino eReader steht derzeit die Ausleihe von eBooks zur Verfügung. Hörbücher, ePaper und eMagazine werden aktuell nicht unterstützt.
IV. Kopierschutz beachten
Die meisten Titel aus der Onleihe sind mit dem LCP-Kopierschutz versehen. LCP wird seit Mitte 2019 durch den tolino unterstützt. Die Adobe ID wird nur noch für PDF-Titel benötigt.
Stellen Sie sicher, dass Sie die aktuellste Softwareversion auf dem tolino installiert haben. Nähere
Informationen zum Softwareupdate-Prozess finden Sie hier: Aktuelle Softwareversion
LCP-Kopierschutz:
Zum Öffnen der LCP geschützten eBooks wird einmalig der sogenannte eBook-Reader Code benötigt. Es handelt sich dabei um einen individuellen, vierstelligen Code bestehend aus Buchstaben und/oder Zahlen. Er muss eingegeben werden, bevor das Buch geöffnet werden kann.
Notieren Sie den vierstelligen Code, der unter „Buch direkt lesen“ angezeigt wird.
Geben Sie den Code beim ersten Öffnen des Buches ein (wird für zukünftige Leihen gespeichert).
Adobe DRM:
Einige eBooks sind mit Adobe DRM kopiergeschützt. Um diese Titel auf Ihrem tolino lesen zu können, benötigen Sie eine Adobe-ID (ein kostenloses Benutzerkonto bei Adobe) und einen PC.
So funktioniert die Einrichtung:
Erstellen Sie eine kostenlose Adobe ID (unter adobe.com).
Nach der Registrierung erhalten Sie eine Bestätigungsmail mit einem Link.
Klicken Sie auf den Link, um Ihr Konto zu verifizieren.
Ihre E-Mail-Adresse und Ihr Passwort sind nun Ihre Adobe ID.
Laden Sie das eBook auf Ihren PC, übertragen Sie es mit dem kostenlosen Tool Adobe Digital Editions via USB auf den tolino. Während des Übertragungsvorgangs wird Ihr tolino automatisch mit der gleichen Adobe ID autorisiert, die Sie auf Ihrem Computer verwendet haben.
OverDrive-eBooks ausleihen
OverDrive nutzt den Kopierschutz Adobe DRM. Folgen Sie daher bitte der Anleitung unter: Adobe DRM
Hier finden Sie die Anleitung B: Frühere Geräte-Generation:
I. Web-Browser öffnen
Tippen Sie auf die „drei Striche“ oben links im Startbildschirm.
Wählen Sie „Web-Browser“.
Stellen Sie sicher, dass Sie mit dem Internet verbunden sind.
II. In der Onleihe anmelden
Rufen Sie den Onleihe-Bibliothekenfinder unter
https://mytolino.de/onleihe/ auf.
Der Startbildschirm der Bibliotheksauswahl öffnet sich. Tippen Sie auf den Button
„Bibliothek auswählen“.
Geben Sie den Namen Ihrer Stadt oder Ihrer Bibliothek in das Suchfeld ein.
Tippen Sie auf den passenden Namen in der Liste, um ihn auszuwählen.
Sie werden nun zur Anmeldemaske Ihrer Bibliothek weitergeleitet.
Melden Sie sich mit Ihren Zugangsdaten an.
Tippen Sie nach der Eingabe aller Anmeldedaten auf „Anmelden!“.
Je nach Bibliothek bietet Ihr tolino an, die Zugangsdaten zu speichern.
Ihre Bibliothek ist jetzt gespeichert. Beim nächsten Öffnen können Sie sie direkt unter
„Zuletzt ausgewählt“ antippen.
Unser Tipp: Hinterlegen Sie die URL
https://mytolino.de/onleihe/ direkt als Lesezeichen.
Tippen Sie oben rechts auf das „Lesezeichen-Symbol“.
Über das Plus-Symbol können Sie ein neues Lesezeichen anlegen.
Beim nächsten Besuch können Sie dieses Lesezeichen nutzen, um die Seite schneller aufzurufen.
III. eBooks ausleihen, lesen und zurückgeben
Nach erfolgreicher Anmeldung aktualisiert sich die Seite, Sie sind nun eingeloggt.
Über das „Lupen-Symbol“ können Sie nach Titeln suchen.
Es wird angezeigt, ob Titel direkt ausleihbar sind oder vorgemerkt werden können.
Wenn Sie einen Titel leihen möchten, tippen Sie auf „Ausleihen“
und bestätigen mit „OK“.
Nach der Ausleihe können Sie das Buch direkt öffnen oder weiterstöbern.
Titel zurückgeben: Tippen Sie auf die „drei Punkte“.
Alternativ können Sie eBooks auch über „Meine Bücher“ oder die Startseite zurückgeben.
Halten Sie das Buchcover gedrückt und wählen Sie „Zurückgeben“.
IV. Kopierschutz (DRM) beachten
Die meisten Titel nutzen den LCP-Kopierschutz, der seit 2019 unterstützt wird.
Die Adobe ID wird nur noch für PDF‑Titel benötigt.
Infos zum Softwareupdate-Prozess:
Aktuelle Softwareversion
LCP-Kopierschutz:
Zum Öffnen vieler eBooks wird der vierstellige „eBook-Reader Code“ benötigt.
Dieser muss einmalig eingegeben werden.
Notieren Sie den Code, der unter „Buch direkt lesen“ angezeigt wird.
Geben Sie ihn beim ersten Öffnen eines Buches ein.
Adobe DRM:
Einige eBooks sind mit Adobe DRM geschützt.
Dafür benötigen Sie eine kostenlose Adobe ID.
So richten Sie Adobe DRM ein:
Erstellen Sie eine Adobe ID unter adobe.com.
Sie erhalten eine Bestätigungsmail.
Klicken Sie auf den Link zur Verifizierung.
E-Mail-Adresse und Passwort bilden Ihre Adobe ID.
Hinterlegen Sie die Adobe ID unter „Meine Konten“ → „Adobe DRM“.
Hinweis zu ausgeliehenen eBooks:
Nach dem Download finden Sie ausgeliehene Titel unter „Meine Bücher“.
Wenn Ihr Gerät bereits autorisiert ist, können Sie das eBook sofort öffnen.
OverDrive-eBooks ausleihen:
OverDrive nutzt Adobe DRM. Folgen Sie bitte der Adobe‑DRM-Anleitung.
