Software updates for tolino eReaders
We are continuously working on improving our tolino ereader software. To ensure that you always enjoy the best possible reading experience with your tolino, you should always keep the software of your tolino product up to date. Please use our automated software updates for this purpose. Simply connect your tolino to the Internet via WLAN and follow the instructions on the screen. To avoid errors you should only install software updates manually via your computer if absolutely necessary.
The table below shows you which software update is currently valid for your eReader model. Before downloading, please check your model designation to see which download link will allow you to download the appropriate software update for your model. Please note: other eReader models would be damaged by using the wrong software version!

Update your tolino eReader manually
Click Download in the software overview and save the file update.zip to your desktop. Please note that the file will only be recognized as an update file by your tolino if it is named update.zip. Please rename the file locally on your computer if version numbers have been appended here (e.g. update_1.zip).
Connect your tolino shine 3 to your computer with the supplied USB cable and open the eReader directory view under MY TOLINO in your computer’s file explorer.
Copy the file update.zip from your desktop or individual storage location directly to the main directory of your tolino shine 3 and then disconnect the USB link by ejecting the tolino from your computer. Please wait approx. 10 seconds until the update has been processed on the eReader, then restart your device by sliding and holding the on/off switch for approx. 2 seconds. As soon as the context menu appears, please confirm with Restart – the update will now be automatically installed.
*Exception: manual software update for the tolino shine color and tolino shine (5th generation)
Please note the current software version to check later if the manual update was successful.
Make sure that your tolino eReader is more than 20% charged.
Connect your tolino eReader to the computer using the supplied USB-C cable and tap on “Connect” in the “Computer detected” dialog on your tolino eReader.
Click at the download button of the appropriate software for your tolino eReader and save the downloaded file on your computer
Open the directory view of the tolino eReader in the file explorer. Your tolino eReader will be displayed as an “eReader” drive.
Copy or move the downloaded update file (KoboRoot.tgz’ or update.tar) to the “.kobo” folder. To display the “.kobo” directory on your PC, it is necessary that you have activated the “Show hidden folders” option on your PC.
After the update file (KoboRoot.tgz’ or update.tar) has been successfully copied to the “.kobo” folder, disconnect the USB connection by ejecting the tolino eReader from the PC.
A few seconds after ejecting, your tolino eReader should restart automatically and perform the software update.
*Exception: manual Software-Update for the tolino shine
Click on the download button and save the file with the name update.zip on your desktop. Please note that the file can only be recognized by your tolino eReader as an update file under this file name.
Connect your tolino eReader to the computer using the USB cable supplied and open the TOLINO directory view of the eReader in File Explorer.
Now copy the update.zip file from your desktop or individual storage location to the extsd folder of your tolino eReader. Then disconnect the USB connection by ejecting the tolino eReader from the PC
Please wait approx. 10 seconds until the software update has been processed on the eReader and then restart the device by pressing the on/off switch for approx. 2 seconds. As soon as the context menu appears, confirm with Restart. The software update will now be installed automatically.
