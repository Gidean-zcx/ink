# M-042 Gemini／Android：页面上下文、应用动作与可停止的任务

查阅：2026-10-26。对象是 Android 上的 Gemini，不是统一 Android 原生功能。帮助依设备、语言、地区、账户和灰度开放而变；未固定安装构建。屏幕自动操作资料明确为 beta，个人成人账号与指定设备/地区限制不能省略。未登录、授权、发消息或创建订单；全为文档分析。

## 功能目录与边界

| 机制 | 取得的细节 | 尚缺的范围 |
| --- | --- | --- |
| 当前页面上下文 | 唤起、建议入口、发送方式、截图/文本设置 | 每个 app 的提取范围、滚动外内容、图像理解准确性 |
| Connected Apps | 发现支持动作、指定应用、连接/断开、账户与平台差异 | 各连接器全动作、批量部分失败与重试规则 |
| Device assistance（旧称 Utilities） | 闹钟、计时、设备设置、通知权限与锁屏条件 | 各厂家时钟的实测行为、失败后是否重复写入 |
| Screen automation | 任务计划、后台进度、停止、特定设备接管、单 app 权限 | 所有受支持应用和真实任务时延/成功率 |
| Live、电话等其他入口 | 官方目录可发现 | 尚未做完整任务分析，不将它们算成已覆盖 |

## 任务流程

| F 编号 | 前置、入口、动作 | 状态与分支 | 证据 |
| --- | --- | --- | --- |
| F-M042-01 就眼前内容问 AI | 在网页/受支持 app 上以手势或唤醒词打开浮层 → 点建议入口 → 补充问题并发送。 | 内容可含截图、文件或 URL。长按建议可改自动提交；自动推断何时读取屏幕的功能另限英语，文本与截图开关分别设置。 | E-GEM-01 |
| F-M042-02 发现并调用应用动作 | Connectors 查看可用 app → 详情看支持/不支持动作和例句 → 对话中用 @ 指定 app，或让系统选用 → 按提示连接与执行。 | 可见目录随账户/平台而变；关闭 Keep Activity 后 Android 仍保留部分设备/通信连接器，不能照搬到 iOS/web。 | E-GEM-02 |
| F-M042-03 修改闹钟和计时状态 | Gemini 对话中设定、查询或更改具体闹钟/计时器；可基于前文事件再提要求。 | 时钟实现按厂家/Google/第三方不同；停响、停用、删除不是同一动作。具体失败反馈与确认卡尚未观察。 | E-GEM-03 |
| F-M042-04 取得并撤销设备权限 | 在系统设置授予 Google 通知访问；部分设置动作还需默认数字助理；锁屏通知另有开关。 | 缺这些授权时仍可做其他支持动作，不能理解为全有或全无。已保存密码、重置设备等不在该文档支持范围。 | E-GEM-03 |
| F-M042-05 让 AI 代做一项 app 任务 | 在受支持设备/地区用个人成人账号提出任务 → 补充条件 → 查看/修改计划 → 需要时按指示完成最后一步。 | 可在后台推进；若有 Connected App 会优先使用。尚未完成的订单可能已经留下购物车内容，停止不等于撤销全部修改。 | E-GEM-04 |
| F-M042-06 查看、停止与接管 | 从对话或实时通知进入 View progress；可 Stop task；支持的设备可 Take control。设置中为每个 app 选总是允许/每次询问/不允许。 | Pixel 10、Galaxy S26 在所查说明中只能停止，不能照搬新设备的接管行为。两份官方索引的支持设备/地区列表不同，不能拼成通用承诺。 | E-GEM-04、E-GEM-05 |

## 不能混淆的四个问题

1. **看到页面**不意味着读到了 app 数据库、历史任务或屏幕外内容；本项目 G-002 的范围比截图问答更广。
2. **发现某 app**不等于能操作它的每个功能；公开列出支持/不支持动作有助于形成准确预期。这与 R-009 渐进式披露相关，但不是已选协议。
3. **任务已停止**不等于此前动作回滚。购物车例外提供了具体反例；“取消”“恢复原状”“重新尝试”需要分别研究。
4. **助手获准访问**不等于系统已完成动作。需取得真实结果和对象状态，不能以聊天文本代替执行证据。

这些是由案例归纳的项目设计问题，不表示 Gemini 已提供完整事件日志或所有对象的统一 API。Plus 的资源与运行环境不支持直接推定兼容该 Android 机制。儿童版只借鉴上下文连续性和明确反馈；所查屏幕自动操作有成人条件，不是直接给 5–6 岁儿童接入该服务的建议。

待观察：受控资料中，让 AI 设置一个闹钟，再在拒绝权限、已有同名闹钟、用户中途取消的情况下重复；记录真实时钟状态与对话是否一致。屏幕任务单独测部分完成、停止、重复发同一请求和切回原 app。当前没有执行。
