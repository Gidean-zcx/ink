高效背单词工具对比：扇贝单词、墨墨背单词、百词斩、不背单词产品分析

FuzzFace
2021-03-26
4 评论 50260 浏览 99 收藏 54 分钟

编辑导读：学英语，最基础的就是背单词。掌握了足够多的词汇量，英语学习才能如鱼得水。但是单词背了忘，忘了背，因此很多人会依赖背单词软件来帮助自己记忆。本文以扇贝单词为例，对其进行竞品分析，希望对你有帮助。

一、分析目的

本竞品分析的主要目的是找出扇贝单词英语版与市场主流产品的差异，分析可迭代方向。

二、选择竞品

在教育类产品中选择以单词记忆为核心业务的产品，选择[扇贝单词][百词斩][墨墨背单词][不背单词]作为竞品进行对比分析。

扇贝单词英语版（以下称扇贝单词）业务体系庞大，以单词学习为核心业务融合了社交、电商、在线课程等业务。

百词斩以图像学单词为卖点，同样融合了社交、电商、在线课程等业务，在业务上高度重合因此将百词斩作为主要竞品。

墨墨背单词中单词学习业务与扇贝单词同样采用遗忘曲线的学习方式，墨墨背单词在遗忘曲线方面发展较专注垂直度极高，作为单词学习类第二名的产品有一定的分析价值。

不背单词页面简洁，对单词内容和表现形式富有特色。

将墨墨背单词和不背单词作为次要竞品。

图片来源：七麦数据

三、竞品对比

3.1 产品定位对比

体验设备：Pihon6Splus

体验系统： IOS 13.6.1

体验时间： 2021/3/19

 

  1. 四款产品都是以单词学习为核心功能单词学习工具。
  2. 扇贝单词在90天内更新频率最高每周更新0.8次，为四款产品中跟新频率最高。
  3. 单词的主标签扇贝单词和墨墨背单词都强调了四六级考研信息，不背单词强调了真实语境学单词，百词斩则通用型话术。
  4. 副标签扇贝单词和墨墨背单词强调单词记忆效果，记得住抗遗忘。
  5. 百词斩在副标题和引导页slogan“英语考试大杀器”加入了英语考试的信息，表明了英语考试市场的定位，范围依然很广并未强调是哪类型考试，同时单词学习和训练功能的核心就是针对考试题型。不背单词则强调了真实语境的的基础“百万原声例句”。
  6. 引导页的slogan 扇贝是知道你在改变，强调了单词打卡，重点在于鼓励用户养成打卡和学习习惯。墨墨背单词的“更懂你的记忆”，以艾宾浩斯为基础，通过数据分析为每个用户定制的遗忘曲线和复习频率，重点强调科学记忆。

小结：

  • 扇贝单词定位：针对四六级考研市场，以艾宾浩斯为基础的高效单词记忆打卡工具。
  • 百词斩定位：可离线使用，以图片背单词的形式，针对英语考试的单词记忆、英语学习工具。
  • 墨墨背单词定位：针对四六级考研市场，以艾宾浩斯为基础高效抗遗忘单词记忆工具。
  • 不背单词定位：在海量有声例句创造的真实语境中，借助智能记忆算法，科学高效地单词记忆工具。

3.2 商业策略对比

3.2.1 商业模式对比

  1. 扇贝单词和百词斩：上游主要由单词版权、课程视频、文章攻略、实物商品等生产商，由平台运营学习内容和商品供用户消费，下游用户除了作为消费者学习和获取商品外，作为生产者产生文章和话题在社区互动；
  2. 不背单词：上游主要由单词版权商，不背单词平台运营学习内容，下游消费者学习；
  3. 墨墨背单词：上游主要由单词版权商和商品生产商，下游消费者学习和购买商品；

3.2.2 产品业务生态对比

 产品主要业务表

  1. 在核心业务上：不背单词采用4选1的方式记忆效率较高，而百词斩以看图记单词为特色，学习过程富有趣味。扇贝单词与墨墨背单词有较为相似，都是再认的方式标记单词熟悉程度，再通过数据分析以记忆曲线为基础，安排单词的复习时间和出现次数，过程稍显枯燥，对用户的自律性要求较高缩小了用户范围，竞争中处理劣势；扇贝单词词组/短语学习模块则独立出来，设置听写训练、拼写训练、复述训练3种方式；
  2. 在课程业务上：相较于其他产品扇贝单词课程更加具有多样性和针对性，包含四六级考研、阅读、听力、编程课程。其余产品课程内容还稍显单薄，扇贝单词在课程业务方面具有一定优势；
  3. 在社区业务上：不背单词和墨墨背单词还未发展，扇贝单词和百词斩都是以文章互动、组织学习小班以及活动的形式，生态都较为平衡，有完善的评论互动机制；
  4. 在家族产品中：扇贝单词发展最为全面，衍生出扇贝阅读，扇贝口语，扇贝听力，扇贝编程，，百词斩也发展了百词斩爱阅读、芝士派英语、薄荷阅读、夜曲编程家族几乎一致；
  5. 奖励机制方面：扇贝单词和不背单词的发展了打卡奖励虚拟币业务，对用户能造成一定的鼓舞；
  6. 在电商业务方面：百词斩与扇贝单词都内置商城，出售纸笔书本等学习工具和资料，同时也发展自己的定制产品颇具特色，但扇贝的商城业务入口太深影响转化率；
  7. 在付费权限方面：扇贝单词设置了会员、大会员体系，用户可以根据自己的需要选择单一权限和会员权限。墨墨背单词的新用户只有600单词学习量，需要付费购买单词上限和例句真人发音权限。不背单词则需要购买词根、词缀和柯林斯词典等权限。
  8. 在4款app中除墨墨背单词外，部分专用书籍和全部词组类书籍需付费使用。

小结：

4款产品都以单词学习为核心业务，墨墨背单词和不背单词业务生态较为垂直，专注于单词学习业务。扇贝单词、百词斩和不背单词业务重合度较高，以单词学习为核心业务衍生出电商，课程，社区业务，家族产品等不断的扩大业务范围，多赛道平行发展。百词斩和扇贝单词对消费者的开发更彻底，同时作为消费和生产者，增加用户的使用场景作为学习者和学习内容输出者，增加用户粘性，提高使用时长，用户与用户之间形成闭环。

扇贝单词盈利模式主要靠付费权限、会员体系、收费课程、收费词书和电商；百词斩依靠收费课程、和电商；不背单词主要靠付费权限盈利；墨墨背单词靠单词上限付费和例句发音盈利，以及淘宝电商引流；

3.3 产品策略对比

产品迭代瀑布

3.3.1 扇贝单词

  1. 从进入市场从定位单词短语学习到力求听说读写全面发展，再到之后针对四六级考研市场定位一直在变化，一直在不停的增加和扩宽渠道，导致扇贝内容繁多而单词学习的核心功能发展滞后，最终扇贝单词重新定位为以四六级考研为主要市场的单词学习记忆软件。
  2. 2013年9月扇贝单词进入市场，上线初期以单词记忆和短语作为核心业务，在版本1.2上线课程购买功能，之后在1.4版本上线社区业务，至2.16版本上线扇贝商店，扇贝单词在初期业务布局和盈利模式基本成型。在内容上“扇贝英语考试保险”“柯林斯”的权限获取，为扇贝收获大量用户。
  3. 2016年3月2.0版本上线，将页面改版并增加了全新的小组模块。标签也改为“英语短语和句型特训，强化你的口语跟写作能力”标志着转而成为以口语、听力、阅读学习为重心不断的优化和丰富课程内容。此时的扇贝单词随着用户的不断增加，需求多样化，进入转型和业务拓展期。2016年7月在通过扇贝单词造势之下扇贝口语上线。
  4. 2019年4月， 随着3.0版本扇贝单词做出战略调整，更名为扇贝单词英语版，主标签变更为“学英语背单词备战四六级考研”，主要用户群向四六级考研人群靠拢，发展方向也以四六级考研学习内容为主。扇贝编程上线，意味着扇贝单词开始布局其他语种的学习产品。由于之前转型和业务的拓展导致“背单词和单词训练”功能发展滞后，
  5. 自5.1.6版本后重点更新单词学习和单词测试功能，slogan也变“单词真的记得住”属于补充薄弱环节。

3.3.2 百词斩

  1. 与扇贝单词不同之处在于，百词斩一直以单词记忆和英语学习，作为产品定位主要针对英语考试。
  2. 百词斩2012年上线初期就以图文学习模式进入市场，此模式为百词斩特色模式，背词过程更有趣味性，同时帮助记忆。之后根据当时的社会背景在3.8.4版本上线了电台功能，在4.0版本上线了离线版本，针对当时所处的网络环境扩宽使用场景。
  3. 2014年4.0.3版本上线社区业务（单词PK、好友圈等），随后在5.1.1版本推出与必胜客的美食券活动，吸收了大批的用户，一举奠定了行业第一的位置。
  4. 2016年的6.0版本将训练模块独立出来放在主页，开始针对考试进行功能的迭代和内容扩充。2018年2月上线百词斩爱阅读，标志着百词斩开始其他业务的探索。
  5. 2020年3月7.0上线对社区和训练模块进行了改版，之后对功能和UI优化。百词斩在发展期间单词学习、训练、课程、社区等功能和内容也完全围绕产品定位“英语考试大杀器展开”展开，发展较为成功。

3.3.3 默默背单词

  1. 默默背单词则保持单词记忆为定位，“高效抗遗忘”一直作为slogan。
  2. 上线初期就以单词记忆为核心功能，专注于单词记忆算法的研究和功能的优化，以艾宾浩斯为基础发展记忆矩阵垂直度极高，占有一定的市场份额。
  3. 而在近期更新的V3.7.18版本中上线了淘宝图书链接，对电商业务也开始探索。

3.3.4 不背单词

  1. 定位为“真实语境学单词”。
  2. 虽然与上述产品同期上线但未发展社区业务，在2014年的V1.6版本上线了“分享到朋友圈”增加了社区属性。
  3. 在2020年5月的V3.4版本上线了“不背学堂”业务，开始发展课程业务，开拓新业务。对于考频、考义等考试内容和页面展现形式则比较重视以页面简洁、原声例句为卖点。

3.4 运营策略对比

图片来源百度指数

  1. 根据百度关键词搜索趋势结合运营活动和版本迭代进行数据分析2014年4.0版本百词斩的离线版上线，对于当时流量无比珍贵的时代，对用户自然造成吸引力。
  2. 百词斩在2015年11月有一高点原因在于百词斩通过与必胜客的美食券活动带来一波热度，而其他三款产品在此阶段运营表现平平，此时百词斩与其他产品已拉开差距。
  3. 2016年底百词斩针对初中生群体新增随课词表一波针对性的内容添加给百词斩带来高点，扇贝则靠新增发现页面（包括论坛、小组、活动、竞选、课程、扇贝商店）增加社区活跃度为扇贝单词带来一波高点。
  4. 2018年初百词斩依靠春节答题活动又为自己带来一高点，其他3款产品则无表现。
  5. 扇贝单词依靠2019年9月上线“单词对战”功能为为自己带来一波小小的热度。

小结：

四款APP都通过打卡分享拉新，百词斩与扇贝单词都有打卡挑战功能，而百词斩在运营策略上更重视与第三方的合作和与社会形态的跟进，如与必胜客的合作、2018年春节答题活动，但作为学习教育类软件春节放假期间则无法激起用户的浓厚兴趣。扇贝单词主要靠产品内部活动和社区交流增加用户粘性，利用签到分享获取贝壳可以换取实物商品，商城入口太深影响转化率。不背单词和墨墨背单词则靠自然增长，缺乏拉新手段。

3.5 用户人群对比

 图片来源百度指数

 图片来源百度指数

  1. 从地理位置来看：根据百度人群画像分析，人群地理位置分布4款app都趋于一致，用户主要集中在发达城市，相比一般的城市发达地区教育和各行各业发展更加迅猛，对应于英语学习的需求更加强烈。
  2. 从年龄来看：百词斩年龄分布更显均衡，这表明百词斩学习方式和内容对年龄适应性更强，适应年龄范围更广。而扇贝单词、墨墨背单词、不背单词主要集中在20~29岁，扇贝单词20~29岁人群比例更是达到58%。
  3. 从性别上看：4款app中百词斩男女比例女性用户稍高于男性用户，但男女比例差距不大。墨墨背单词男女比例几乎持平，不背单词同扇贝单词一样男性比例高于女性，但扇贝单词的男女比例差异更大相差超过10%。
  4. 综合4款app的百度指数年龄分布和用户量看来，百词斩的年龄较其他3款产品更均衡用户量也最多。百词斩0~49岁最高和最低占比差异约百分之10%，而扇贝单词、墨墨背单词0~49岁最高和最低占比差距近5成，不背单词约为25%都远高于百词斩。

小结：这3款产品与百词斩形成年龄平衡差异的原因在于，对于四六级考研等应试英语的市场倾斜，而四六级考研的主要年龄段为20~29岁，缩小了用户范围。而百词斩的以看图的学习形式和通用型学习内容，对需求者的身份和使用场景局限性较低用户范围更广。总结来看用户较年轻化以学生为主。

3.6 用户需求对比

3.6.1 用户需求


3.6.2 用户画像

  1. 基础需求：能背单词，单词信息准确；
  2. 期望需求：内容丰富，能学习更多知识；
  3. 兴奋需求：学习过程高效有趣，能获取学习以外的收获；

小结：

4款APP都能够满足基础需求，在期望需求上，业务范围更广的扇贝单词和百词斩则能够在课程、学习资料、电商方面给用户更多的期望。

兴奋需求百词斩满足学习过程高效有效的需求，而对于额外收获扇贝单词学习获得贝壳，百词斩获得铜板都能够在商城换取商品。

多维度的使用场景，用户除了作为使用者学习单词、观看课程、购买商品外，还作为内容生产者最大化用户价值。

3.8 产品视觉体验

  1. 扇贝单词家族系列页面设计都统一，超大字体显示打卡天数激励用户打卡学习，同时对今日学习任务作出明确提示，有较强的鼓励意味，绿色的悬浮按钮也比较突出。但底部家族产品和对战、随身听、短语排列在一起，按钮色彩不明显极易忽略。
  2. 百词斩以卡片的展现形式为主，比较简洁，蓝色调更显严谨。百词斩也已加黑加粗字体提醒今日学习任务，用来督促用户学习，学习按钮蓝色饱和度高非常醒目，点击欲望强烈。
  3. 墨墨背单词底部按钮红绿配色冲击感强，提醒用户学习未复习数量令人产生强烈的消除欲望。但页面亮度较案，按钮以灰色调为主UI设计不够精美；
  4. 不背单词页面最简洁，将极简风做到极致。两个高明度的透明按钮非常柔和，但未学习单词数的颜色不够醒目，提示效果不如左上角的消息提示，拉低了学习的优先级。
  5. 操作上扇贝单词、百词斩、不背单词都需要用户点击按钮开始学习。而墨墨背单词有未学单词进入主页后直接就开始学习，操作上少了一步让用户免于思考，缩短用户的犹豫期。

四、竞品总结

4.1 扇贝单词

4.1.1 扇贝单词优点

  1. 单词测试方式全面，包括看英选中、听音辨意、看中选英、拼写测试等能对听说读写进行练习，还可以通过影视例句和随声听回顾当日单词。
  2. 扇贝单词词书类别丰富，除了应试类词书，还提供大学专业类和实用类词书，如：旅游英语、医学英语、计算机、文学作品等；
  3. 助记手段丰富，引入权威的柯林斯词典，提高产品的专业度；针对不同词书提供不同类别例句，如针对考研英语提供真题例句；提供派生联想单词和单词笔记功能，用户可以创建和收藏笔记，学习过程中遇到生词可点击查看释义并加入生词本；
  4. 扇贝英语业务生态全面，包含扇贝听力、扇贝阅读、扇贝口语、扇贝编程等，满足用户听说读写全方位需求；
  5. 打卡奖励收益高，完成学习任务后给予贝壳奖励，鼓励用户每天打卡，帮一大批用户养成了好习惯，贝壳可以用来购买app词书、柯林斯词典、词根词缀权限外还可以换取扇贝定制礼物，极大的提高了用户的积极性；
  6. 社区内容丰富，推出同桌和小组功能，让用户组队学习，相互监督；话题功能里用户可以发布和查看动态，并进行评论互动；在经验贴中，用户可以查看学习经验；在你问我答中，用户可以提问以寻求帮 助；还包括特色的考研咨 询、本周之星、小挑战、成长计划、每日一句、影视例句等功能，尽乎 满足用户所有需求。
  7. 贝壳电商内容丰富，有专门用于贝壳兑换的定制礼物，以及扇贝自研纸笔书本等周边产品；
  8. 每日学习数据可视化，分享海报页面美观。

4.1.2 扇贝单词缺点

  1. 背单词的方式比较传统枯燥，缺乏乐趣；
  2. 缺少变形单词，形近词等扩展知识，对于单词的变化和用法学习缺失；
  3. 例句较少，部分单词只有一个例句，不利于单词用法的掌握；
  4. 主要用户针对考研人群，但是考研单词书欠缺；
  5. 内容体系庞大，功能繁多，拆分的过于零散，显得界面比较复杂花哨，部分重要功能容易被忽略；
  6. 产品种类过于分散，独立app过多，存在分流出产品的可能并且可能劝退部分不愿意下载过多app的用户；
  7. 课程种类少，流程繁琐。主要针对四六级考研、听力口语、阅读、编程等内容，没有针对中小学学生和实用英语的课程；
  8. 付费项目太多，易劝退；
  9. 半夜学习至12点后，系统会更新当日学习数据导致当日学习记录重置。
  10. 分享流程繁琐。

4.2 百词斩

4.2.1 百词斩优点

  1. 背词方式百词斩则采用4选1拟词图片的单词学习方式（产品特色），每个单词精心挑选有趣的配图和例句辅助记忆学习效率高，学习过程有较强趣味性，对用户的定位较广泛，适应各个年龄的段学习。除此之外可以选择听音选意、拼写、中文选词；
  2. 单词训练方法多样对听说读写训练有利，多维度单词快速复习与深度复习，包括单词速听、单词自检以及英文选义、中文选词，听音选意、填空拼写、组合拼写、全拼默写、选词填空等；单词TV可以看真人视频和单词电台可以听单词音频、真题音频；
  3. 百词斩内置商城，出售的学习资料、纸笔书本、生活用品等都是百词斩自研自产的原创商品，独居特色。同时运营app内商城和百词斩天猫旗舰店；
  4. 社区业务内容丰富，小讲堂和考试秘籍提供单词知识讲解的优质文章；
  5. 创建或加入小班，和班级一起打卡学习，每日班级排名，并可领取铜板，能带动用户的积极性；
  6. 单词PK娱乐性单词练习,包括排位赛与练习赛，在游戏对战中记忆单词，游戏结束生成生词本帮助查漏补缺；
  7. 每月推出斩家活动活动挑战，完成活动挑战奖励铜板用于百词斩商城商品和课程，激发用户的学习热情；
  8. 家族产品丰富推出百词斩爱阅读、芝士派英语、薄荷阅读、夜曲编程等家族产品，包含听力课程、口语课程和编程课程为百词斩其他业务宣传引流，全方位布局英语教育。
  9. 支持离线使用，不用流量背单词，节约流量同时也能够适应无网络环境，如地铁等，有助于碎片化学习，支持锁屏背单词（仅限安卓）

4.2.2 百词斩缺点

  1. 部分单词配图与意思不够贴合，导致记忆模糊；
  2. 单词详情中变形词无扩展信息，也无法通过链接传送，简单显示对变形词的学习帮助不大。
  3. 单词读音单一不可选，只有美音；
  4. 书库种类较丰富但书库资源较少，教材类和四六级考研考试类专用词书较少；
  5. 社区内容更新频率低；
  6. 课程不够丰富；
  7. 斩家活动少，每个月仅一次铜板的获取手段单一；
  8. 学习数据不可视，没有对用户学习过程和学习结果的数据统计，用户对自己的学习情况不明确；
  9. 不能添加个人笔记，加入助记信息

4.3 墨墨背单词

4.3.1 墨墨背单词优点

  • 单词学习：墨墨背单词以单词再认的学习方式为基础，根据用户在使用过程中的点击记录、页面反应时长等对单词熟悉程度标记，从单词的掌握情况、难易程度、记忆持久度为出发点，为每个单词建立一个记忆矩阵，安排每个单词的复习时间和出现次数，在单词遗忘的临界点到来之前安排复习，记忆效果科学高效。
  • 词书非常全面：涵盖了市面上各类单词工具书和教材，更新频繁，在单词书库方面几乎没有死角；
  • 词条内容简短易记：每个词条都经过人工编辑，并通过四重审核，力求做到例句短小精悍，有助于理解单词，且例句中不会包含比单词本身更难的生词。
  • 内嵌墨墨搜词、金山、有道、海词、必应词典，无需付费达到等级还可以开通柯林斯、建桥、牛津、谷歌等等市面上知名的在线英语词典；
  • 助记功能：用户达到一定等级可以创建助记，未达到等级可以引用别人的助记，帮助单词学习；
  • 支持创建自己的词库，也可以公开自己的词库和保存他人上传的词库，再一次丰富词书内容，部分书籍为默默背单词原创，支持内嵌淘宝店购买。
  • 学习数据统计：以图表的形式记录用户学习上数据，包括的包括遗忘曲线、学习情况和 记忆持久度学习过程可视化。

4.3.2 墨墨背单词缺点

  • 学习过程枯燥，用户需要一定自制力；
  • 墨墨背单词新用户免费的单词学习上限只有600，到上限后只能复习学过的单词。与同类产品免费相比，会导致劝退；
  • 除新用户外每次打卡签到只能新增一个单词上限打卡收益低，打消用户的积极性；
  • 再次复习功能的人口太深，导致部分用户尤其是新用户误以为没有单词复习功能，复习方式较少；
  • 盈利模式单一，仅靠购买单词上限充值和淘宝商店购物。购买图书的入口深，按钮小；
  • 页面和配色不够美观；
  • 选单词过程比较繁琐；
  • 收藏单词和自定义单词发音等功能需一定等级，对新用户不友好，但对于墨墨背单词来说也是鼓励用户坚持打卡的一种方式；

4.4 不背单词优点

4.4.1 不背单词优点

  • 界面简洁美观没有广告，十个一组的背单词方式减轻压力感与焦虑感，容易使人坚持；可以听音选义学习的同时拼写练习帮助记忆；
  • 在单词学习过程中自由切换英音/美音做到学习中进行发音对比，对发音学习更友好，单词拆分分段记忆的方式帮助记忆；
  • 磁条内容优质 ，有考义，词根，派生词，原声例句，真题等；
  • 单词书种类丰富，贴合教材，还提供词组书和实用英语书籍；
  • 提供日常口语课程和学习攻略等内容帮助学习；
  • 奖励机制：可以通过签到、学习复习、参加活动等奖励酷币，酷币可以用来兑换词根词缀，付费词数课程等；

4.4.2 不背单词缺点

  1. 学习过程中不能总览单词全部信息，只能单独对例句、词根、派生词等单一信息查询，对单词用法掌握不利；
  2. 没有添加笔记功能，不利于对单词拓展知识的整理；
  3. 复习方式等单一，只能听音填词和随声听；
  4. 查词功能比较隐蔽，不能在单词学习时使用，不利于相似单词之间的查询和对比；
  5. 学习数据不可视，没有对用户学习过程和学习结果的数据统计，用户对自己的学习情况不明确；

五、扇贝单词改进建议

从竞品分析的结果来看，每个产品都有自己的定位和发展策略，通过对市场分析结果经济背景教育投入减缓，头部产品融资，吃掉大部分资源和竞品分析扇贝单词优缺点提炼，对优化方向进行整合和梳理，做出以下优化建议。

根据优化模块将方案分为6个部分：

  1. 单词学习模块：单词学习页结构优化，精简单词学习页面内容，削减软件冗余，消除多余内容；
  2. 分享模块：优化分享流程，缩减操作步骤；
  3. 测试模块：增加单词测试模块，增加测试方式。增加学习场景，适应碎片化学习；
  4. 课程模块：提升商城页面层级。将商城模块相同内容整合，增加商城曝光度；
  5. 发现模块：优化话题页面，增加玩法。增加用户对话题的操作（分享、点赞、评论、转发），增加对用户的操作（关注、邀请加入同桌）；
  6. 我的模块：增加打卡日历按钮，增加个人主页信息。

优化信息

下文将从如上四个部分进行优化方案的阐述与功能分析。

5.1 单词学习模块

5.1.1 需求背景

原页面包含“学习时长”“单词测试”“生词本”“轻松回顾”按钮，内容冗余，用户选项过多。

5.1.2 优化措施

  1. 取消“学习数据”“打卡日历”“学习档案设置”入口，“打卡日历”放入“我的模块”。“学习数据”“打卡日历”不是单词学习前的必要操作，可以降低优先级不在首页展示；
  2. 在首页只做“目标倒计时”或“宣言”展示，设置在“我的模块”进行。单词学习是一个长期过程学习档案不会频繁更新，用户可以在“我的模块”设置；
  3. 在我的模块增加“打卡日历”图标按钮；
  4. 取消学习完成后的单词学习按钮，改为文字入口；
  5. 增加学习完测试按钮；

  2. 将分享方式增加为“图片分享”“成就海报”“链接分享”3种方式。

5.3 增加单词测试模块

5.3.1 需求背景

多数用户表示使用扇贝背单词是预留出一大段时间来背，不能完成当日打卡的原因也是因为忙导致最终没时间去背。

另一方面用户均表示有碎片化学习需求，例如在饭前饭后或公交地铁上原测试模块需要再单词学习任务往后才能后才可以加入。用户如像改变学习方式对单词进行其他方式的联系，必须完成打卡。但有时候又不想去点开背单词，觉得一背就要好长时间于是产生了抗拒；

5.3.2 优化措施

  1. 增加今日回顾和阶段测试选项，选项测试方式相同，今日回顾为当日单词，阶段测试为近期单词。
  2. 将影视例句回顾放入测试模块；
  3. 增加测试模块：读词测试、例句填词、听写测试。

5.4 话题页优化措施

5.4.1 需求背景

话题主要作用在于用户之间的经验交流和分享，可以从中获取很多有用的知识。在学习过工程中遇到问题可以发布在话题中，其他用户可以通过评论做经验分享和指导帮助。减少学习过程中存在的疑问，提高学习兴趣。或者用户学习收货颇丰，感受颇多也可以选择分享，并形成个人的风格和体系获得关注。

遇到高质量或感兴趣的话题内容，可以选择分享、评论、点赞、收藏等操作，加强话题的曝光度。

如某用户频繁发布高质量内容，选择关注他翻阅他的话题，反之遇到不良信息或不喜欢的信息可以投诉举报屏蔽。

5.4.2 优化措施

  1. 话题标签分为推荐、关注和收藏，推荐中的内容展示主要依靠后台规定的内容分发机制和个性化推荐机制，关注中的内容为用户关注者发布的话题，收藏则为用户收藏过的话题；
  2. 用户可以对话题进行分享、点赞、收藏、评论操作。
  3. 用户可以对其他用户关注和邀请加入同桌。
  4. 设置投诉按钮，防止不良信息的产生，维护社区的良好氛围。

5.5 课程模块

5.5.1 需求背景

原商城模块层级较深，需要在“我的”模块中的“贝壳”入口进入。而作为考研学生来说需要大量的实物学习资料和工具，而商城层级较深影响转化率或者用户很难发现还有商城模块；

5.5.2 优化措施

  1. 将商城模块增加至课程主模块中名称为“扇贝商城”；
  2. 将商城与贝壳兑换页面合并，设置分组。

个人主页的改版主要是为了配合话题模块，作为用户间个人信息展示。

5.6.2 优化建议

  1. 增加关注按钮，用户间互相查看信息后志同道合选择关注，按钮状态切换关注他/已关注；
  2. 增加邀请同桌按钮，根据系统条件设置是否可以邀请成为同桌；
  3. 增加口号信息，增加个性口号暂时，方便用户之间了解；
  4. 增加话题、点赞、粉丝、关注数；

六、总结

本文以扇贝单词英语班为分析对象，选取百词斩、墨墨背单词和不背单词作为竞品进行分析，分别从产品定位、商业模式、产品策略、运营策略、用户人群、用户需求、产品功能、产品家族数据分析、产品视觉等方面进行分析，最后提出了六点优化迭代建议作为宏观调整，并生成初步迭代方案。
