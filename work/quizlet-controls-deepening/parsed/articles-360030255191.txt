# Changing a set's visibility

【8†IOS】 【8†Web】 【8†Android】

Quizlet flashcard sets are public by default*, and you can adjust your set's visibility.

To change a set's visibility
  1. 【9†Log in†quizlet.com】 to your account.
  2. Select Your library.
  3. Select Flashcard sets.
  4. Select Created from the drop-down menu.
  5. Open the set you want to change.
  6. Select 【10†Image: More_menu_-_iOS_-_Resized.png】 (more menu).
  7. Select 【11†Image: Edit_-_Resized.png】 (edit).
  8. At the top of the set page, select the visibility label.
  9. Choose the new visibility setting.
  10. Select Save.
  11. Select Done.

Who can see your sets
  * Everyone
Your set is public, meaning anyone can see it. It even shows up in search engine results.
  * Certain classes
Your set can only be viewed by people in classes you've created or administered.
  * People with a password
Your set can only be seen by people who have the password.
  * Just me
Your set is private and is only visible to you.
*If you're under the required age, you can only create private sets until you reach your region's age of consent. From then on, any new sets will be public by default. You can then update the visibility of any sets that were created before. Find out more about 【12†younger users' account limitations】.
  1. Select Library.
  2. Select Created from the drop-down menu.
  3. Open the set you want to change.
  4. Select 【13†Image: More_menu_-_iOS_-_Resized.png】 (More menu).
  5. Select 【14†Image: Edit_-_Resized.png】 Edit set.
  6. Select the Settings gear.
  7. Select Visible to.
  8. Choose who can see your set.
  9. Select Done.
