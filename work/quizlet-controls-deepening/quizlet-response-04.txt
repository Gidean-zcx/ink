L27: ## Grading options in Learn
L28: 
L29: When you’re studying on the website, grading options are available in sets that have three or more cards and with terms and definitions in English, French, German, or Spanish in Learn.
L30: 
L31: Relaxed
L32: 
L33:   * The general meaning of your answer is accepted as correct. Synonyms, rephrasing, and typos are also accepted.
L34:   * This level is selected by default if the set meets the grading options requirements and both sides are in your default language.
L35: 
L36: Moderate
L37:   * An exact match is required, but minor misspellings such as accent mark errors or missing letters are accepted.
L38:   * Available when both sides of the set are in the same language and the language is not one that is graded strictly (Chinese, Japanese, math, chemistry, Akkadian, or photo-only sets).
L39:   * This level is selected by default if Relaxed isn’t available and the set doesn’t default to Strict.
L40: 
L41: Strict
L42:   * An exact match is required. Only small stylistic mistakes like case or punctuation differences are accepted.
L43:   * Always available.
L44:   * This level is selected by default if the set has different languages on each side (for example, language learning sets).
L45: 
L46: To choose a Grading option in Learn
L47: 
L48:   1. 【11†Log in†quizlet.com】 to your account.
L49:   2. Open a set.
L50:   3. Select Learn.
L51:   4. Select Options.
L52:   5. Select Grading options.
L53:   6. Choose a grading option.
L54:   7. Select Save.
L55: ## Grading options in Test
L56: 
L57: If a set includes terms that have multiple definitions or answers, you can change your grading settings to require one or all answers in Test.
L58: 
L59: To choose a Grading option in Test
L60: 
L61:   1. 【11†Log in†quizlet.com】 to your account.
L62:   2. Open a set.
L63:   3. Select Test.
L64:   4. Select Options.
L65:   5. Select Grading options.
L66:   6. Check Require 1 answer only.
L67: This will mark answers correct if they contain at least one of the correct options included in a definition.
L68: Multiple correct answers in a definition must be separated by a comma, slash, or semicolon for single-answer grading to work.
L69: ## Settings and options
L70: 
L71:   * Single-answer grading is available for Test.
L72:   * Once you turn on single-answer grading for a set, that preference is also set for all other activities. To disable it, click Options and then uncheck Require 1 answer only.
L73: 
L74: Grading options let you choose how strictly Quizlet checks your answers so you can focus on understanding concepts at the level that works best for you.

L13: # Editing draft sets
L14: 
L15: 【8†IOS】 【8†Web】 【8†Android】
L16: 
L17: Quizlet automatically saves your work as you create or edit a set. Unpublished sets are saved as drafts that only you can see.
L18: 
L19: To open and edit a draft set
L20:   1. 【9†Log in†quizlet.com】 to your account.
L21:   2. Select Your library.
L22:   3. Select Flashcard sets.
L23:   4. Select a draft set in the In Progress section.
L24:   5. You can keep working on the set, discard it by clicking the pop-up window in the bottom left, or publish it by selecting Create.
L25: If you discard a draft, it can't be restored :(
L26: Published sets are available on any of your devices, but drafts don't sync across the Quizlet website and the mobile apps. That means that if you made a draft set on the website, you won't be able to see it in the app and vice versa. It's best to publish your sets first so you can edit them anywhere.

L34:   * If you lose your internet connection and Quizlet can't save your work, you'll see a warning icon next to any terms that haven't been saved. If this happens, keep the page open so Quizlet can save your terms once you reconnect.
L35:   * You can see how many terms have been successfully autosaved at the top of the page.
